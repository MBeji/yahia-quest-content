# 📜 Résumé : Matrices et systèmes

- **Matrices** : une matrice d'ordre n × p a n lignes et p colonnes ; aᵢⱼ est à la ligne i, colonne j (la ligne d'abord : a₂₁ est en ligne 2, colonne 1). Matrices ligne, colonne, carrée (diagonale), unité Iₙ, nulle O. Deux matrices sont égales si elles ont le même ordre et les mêmes coefficients aux mêmes places : (1 2) ≠ (1 ; 2).
- **Somme, différence, produit par un réel** : A + B et A − B exigent le même ordre et se font case par case ; kA multiplie chaque coefficient par k. Un prix TTC pour une TVA de t % vaut (1 + t/100) × P : 0,19P n'est que la TVA. A + B = B + A et k(A + B) = kA + kB.
- **Produit** : A × B (A d'ordre n × p, B d'ordre p × q) est d'ordre n × q ; le coefficient (i ; j) est la ligne i de A fois la colonne j de B, terme à terme puis somme. Il n'existe que si colonnes(A) = lignes(B). Jamais de produit case par case ; A × B ≠ B × A en général ; associatif, distributif, Iₙ neutre ; A² = A × A.
- **Déterminant** : dét(a b ; c d) = ad − bc ; à l'ordre 3, développement par la première colonne (ou ligne) avec les signes + − +. dét(Iₙ) = 1. Un déterminant nul ne signifie pas une matrice nulle : dét(2 3 ; 4 6) = 0.
- **Inverse** : M est inversible si et seulement si dét(M) ≠ 0, et M × M⁻¹ = M⁻¹ × M = Iₙ ; trouver M' avec M × M' = Iₙ suffit. Ordre 2 : M⁻¹ = (1/dét) × (d −b ; −c a), en changeant le signe de b et de c. Ordre 3 : dét, matrice des cofacteurs Δᵢⱼ = (−1)ⁱ⁺ʲ dét(Mᵢⱼ), échange lignes/colonnes, puis 1/dét. Si M² − aM + bIₙ = O avec b ≠ 0, alors M⁻¹ = (aIₙ − M)/b.
- **Écriture matricielle** : un système s'écrit A × X = B (matrice du système, colonne des inconnues, colonne des constantes). Si dét(A) ≠ 0, la solution est unique : X = A⁻¹ × B, avec A⁻¹ à gauche de B (B × A⁻¹ n'existe pas). On contrôle dans les équations de départ.
- **Problème économique** : nommer les inconnues, une équation par contrainte (coefficients dans l'ordre des inconnues), A × X = B, dét(A) ≠ 0, X = A⁻¹ × B, puis contrôler que la solution est admissible (positive, entière si ce sont des objets).
- **dét(A) = 0** : jamais une solution unique, ni A⁻¹. Par élimination, 0 = 0 donne une infinité de solutions, 0 = k avec k ≠ 0 aucune : le déterminant seul ne décide pas entre les deux.
