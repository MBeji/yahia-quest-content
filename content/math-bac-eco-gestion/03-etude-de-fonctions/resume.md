# 📜 Résumé : Étude de fonctions

- **Asymptotes** : x = a est asymptote verticale si f tend vers ±∞ en a ; y = b est asymptote horizontale si f tend vers le réel b en +∞ ou −∞ ; y = ax + b est asymptote oblique si f(x) − (ax + b) tend vers 0. Le dénominateur nul ne suffit pas ((x² − 4)/(x − 2) tend vers 4 en 2). Le signe de f(x) − (ax + b) donne la position relative.
- **Branches paraboliques** : si f tend vers l'infini, f(x)/x → 0 donne la direction de l'axe des abscisses, f(x)/x → ±∞ celle de l'axe des ordonnées ; f(x)/x → a ≠ 0 impose de calculer f(x) − ax : réel b, asymptote y = ax + b ; infini, branche parabolique de direction y = ax. Le quotient seul ne prouve pas l'asymptote.
- **Symétries** : paire si f(−x) = f(x), impaire si f(−x) = −f(x), sur un domaine symétrique par rapport à 0 ; axe x = a si f(2a − x) = f(x) ; centre I(a ; b) si f(2a − x) = 2b − f(x). On vérifie d'abord que 2a − x reste dans le domaine ; une fonction impaire définie en 0 vérifie f(0) = 0. Une fonction est périodique de période t si f(x + t) = f(x) : on l'étudie sur une période, puis on translate de vecteur t i.
- **Translations et valeur absolue** : f(x) + k translate la courbe de k j ; f(x − k) la translate de k i, vers la droite si k > 0, pas vers la gauche. La courbe de |f| replie vers le haut les arcs sous l'axe des abscisses, avec un point anguleux là où f s'annule avec f′ ≠ 0, pas si f touche l'axe sans le traverser.
- **Plan d'étude** : domaine, parité et symétries, limites et asymptotes, dérivée et son signe, tableau de variation, tracé. Pour une fraction, on lit la monotonie sur chaque intervalle de définition, jamais à cheval sur la valeur interdite ; pour une racine, on réécrit sous la racine pour trouver l'axe de symétrie, et on utilise le conjugué pour l'asymptote oblique.
- **Coût moyen et bénéfice** : B = px − C, donc B′ = p − Cm ; le maximum est là où Cm = p (B′ change de signe) et se confirme en comparant aux bornes ; on n'annule pas C′. Le coût moyen CM = C/x est minimal là où CM = Cm ; à ce prix, le bénéfice maximal est nul.
- **Offre, demande, satisfaction** : le prix d'équilibre est l'unique solution de O(x) = D(x), prouvée par la stricte monotonie de O − D et un changement de signe ; la quantité d'équilibre est la valeur commune. Avec E = S′, l'envie (E > 0) signifie S croissante, le rejet (E < 0) S décroissante : E décroissante n'empêche pas S de croître.
