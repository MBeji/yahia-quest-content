# 📜 Résumé : Logarithme et exponentielles

- **Logarithme népérien** : ln est la primitive de x ↦ 1/x sur ]0 ; +∞[ qui s'annule en 1 ; elle est strictement croissante, de dérivée 1/x. ln(u) exige u > 0 ; la dérivée de ln|u| est u′/u, et une primitive de u′/u est ln|u|. ln((x + 3)/(x − 1)) n'a pas le même domaine que ln(x + 3) − ln(x − 1).
- **Propriétés** : ln(ab) = ln a + ln b, ln(a/b) = ln a − ln b, ln(1/a) = −ln a, ln(√a) = (1/2) ln a, ln(aⁿ) = n ln a, pour a > 0 et b > 0. On n'écrit jamais ln(a + b) = ln a + ln b. Dans une équation, on fixe le domaine, on regroupe les ln en un seul, puis on rejette les solutions hors du domaine ; dans une inéquation, le sens est conservé.
- **Limites de ln** : ln tend vers +∞ en +∞ et vers −∞ en 0⁺ ; (ln x)/x → 0 en +∞ et x ln x → 0 en 0⁺ ; ln(1 + x)/x → 1 en 0 et (ln x)/(x − 1) → 1 en 1. La courbe a pour asymptote verticale l'axe des ordonnées et une branche parabolique de direction l'axe des abscisses ; la tangente en 1 est y = x − 1 ; e ≈ 2,718 est le réel de logarithme 1.
- **Exponentielle** : exp est la réciproque de ln ; eˣ > 0, ln(eˣ) = x pour tout réel x, e^(ln x) = x pour x > 0 ; e^(a + b) = eᵃ eᵇ, e^(−a) = 1/eᵃ ; les courbes de eˣ et de ln sont symétriques par rapport à la droite y = x. Une équation du second degré en eˣ se résout par X = eˣ, en ne gardant que les racines X > 0 ; eˣ = k n'a de solution que pour k > 0.
- **Dérivée et limites de eˣ** : (eˣ)′ = eˣ, (e^u)′ = u′ e^u, une primitive de u′ e^u est e^u ; la tangente en 0 à la courbe de eˣ est y = x + 1 ; eˣ → 0 en −∞ et +∞ en +∞ ; eˣ/x → +∞ en +∞ et x eˣ → 0 en −∞. Oublier u′ dans (e^(2x))′ est l'erreur classique.
- **Fonction aˣ** : aˣ = e^(x ln a) pour a > 0, de dérivée (ln a) aˣ ; croissante si a > 1, décroissante si 0 < a < 1 ; aˣ = k se résout par x = ln k/ln a. La dérivée de 2ˣ n'est pas x × 2ˣ⁻¹.
- **Intérêts composés** : V = C (1 + t)ⁿ ; le taux mensuel équivalent est (1 + t)^(1/12) − 1, jamais t/12 ; la durée est n = ln(V/C)/ln(1 + t), arrondie à l'année supérieure si les intérêts sont annuels ; le capital à placer est C = V/(1 + t)ⁿ.
- **Optimiser** : domaine, dérivée sous forme lisible, résolution de f′(x) = 0 avec ln ou eˣ (en divisant par le coefficient de l'exposant), changement de signe de f′ pour nommer maximum ou minimum, puis valeur en unités de l'énoncé : B(x) = 10 ln x − 2x est maximal en x = 5.
