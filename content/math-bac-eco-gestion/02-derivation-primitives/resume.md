# 📜 Résumé : Dérivation et primitives

- **Nombre dérivé, tangente et point anguleux** : f est dérivable en x₀ si lim x→x₀ (f(x) − f(x₀))/(x − x₀) = f′(x₀) est un réel ; la tangente est y = f′(x₀)(x − x₀) + f(x₀), pas y = f′(x₀)x + f(x₀). f est dérivable en x₀ si et seulement si f′g(x₀) = f′d(x₀) (finis) ; sinon point anguleux et deux demi-tangentes. Dérivable en x₀ implique continue en x₀ (admis), la réciproque est fausse ; pour une fonction à deux formules, on contrôle d'abord le raccord des valeurs.
- **Fonction dérivée, opérations, coût moyen, élasticité** : (fg)′ = f′g + fg′, (1/g)′ = −g′/g², (f/g)′ = (f′g − fg′)/g² (g ≠ 0) ; (xⁿ)′ = nxⁿ⁻¹, (√x)′ = 1/(2√x) sur ]0 ; +∞[. Le coût marginal est Cm = C′ ; le coût moyen CM = C/x se dérive comme un quotient, pas comme C′. L'élasticité E(p) = p D′(p)/D(p) donne le pourcentage de variation de la demande pour une hausse de 1 % du prix.
- **Dérivée d'une composée** : (g ∘ f)′ = g′(f) × f′ ; (fⁿ)′ = n f′ fⁿ⁻¹ (f ≠ 0 si n ≤ −1) ; (√f)′ = f′/(2√f) pour f > 0 ; sin′ = cos, cos′ = −sin. On dérive l'extérieur en gardant l'intérieur, puis on multiplie par la dérivée de l'intérieur, jamais oubliée.
- **Dérivée d'une réciproque** : si f′(x₀) ≠ 0, (f⁻¹)′(f(x₀)) = 1/f′(x₀) : on cherche l'antécédent de y, on dérive en ce point, on prend l'inverse. Si f′(x₀) = 0, f⁻¹ n'est pas dérivable en f(x₀) (tangente verticale).
- **Variations et extremums** : f′ ≥ 0 sur un intervalle donne f croissante, f′ ≤ 0 décroissante ; un extremum relatif intérieur annule f′, et f′ qui s'annule en changeant de signe donne un extremum (x³ : f′(0) = 0 sans extremum). Pour B = px − C, B′ = p − C′ : maximum là où le coût marginal égale le prix ; le coût moyen est minimal là où il égale le coût marginal.
- **Dérivée seconde et point d'inflexion** : f″ = (f′)′ ; la courbe a un point d'inflexion (la tangente traverse la courbe) là où f″ s'annule en changeant de signe ; f″(x₀) = 0 sans changement de signe ne suffit pas (x⁴ en 0). Le coût marginal C′ est minimal à l'inflexion de la courbe du coût total.
- **Accroissements finis** : f continue sur [a ; b] et dérivable sur ]a ; b[ donne c de ]a ; b[ avec f′(c) = (f(b) − f(a))/(b − a) (c n'est pas toujours le milieu, ni unique) ; m ≤ f′ ≤ M donne m(b − a) ≤ f(b) − f(a) ≤ M(b − a) ; |f′| ≤ k donne |f(b) − f(a)| ≤ k|b − a|.
- **Primitives** : F est une primitive de f sur I si F′ = f ; toute fonction continue sur un intervalle en admet (admis), les primitives sont F + k, et une seule vérifie F(x₀) = y₀ (la constante ne s'oublie pas). c ↦ cx, xⁿ ↦ xⁿ⁺¹/(n + 1) (n ≥ 1 ou n ≤ −2), 1/√x ↦ 2√x ; u′uⁿ ↦ uⁿ⁺¹/(n + 1), u′/u² ↦ −1/u, u′/√u ↦ 2√u. On compense un facteur constant seulement, on décompose (a + b/(x + c)²) avant de primitiver, et on vérifie en dérivant.
