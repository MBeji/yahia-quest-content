# 📜 Résumé : Suites réelles

- **Arithmétiques et géométriques** : uₙ₊₁ = uₙ + r donne uₙ = u₀ + n·r (intérêts simples) ; uₙ₊₁ = q·uₙ donne uₙ = u₀·qⁿ (intérêts composés). Une hausse de t % multiplie par q = 1 + t/100, jamais par t/100. La somme de n termes vaut n × (premier + dernier) / 2 en arithmétique, et (premier) × (1 − qⁿ) / (1 − q) en géométrique (q ≠ 1). u₀ est le premier terme : uₙ est le (n + 1)-ième.
- **Majorée, minorée, bornée** : uₙ ≤ M, uₙ ≥ m, ou les deux, pour **tout** n ; on le prouve par encadrement ou par récurrence, jamais en testant quelques termes (n² reste sous 10 pour n ≤ 3, pas ensuite). Bornée n'implique pas convergente : (−1)ⁿ.
- **Variation** : signe de uₙ₊₁ − uₙ ; quotient uₙ₊₁ / uₙ comparé à 1 seulement pour des termes strictement positifs (−3 × 2ⁿ décroît malgré q = 2) ; ou variations de f avec uₙ = f(n). Une suite peut décroître puis croître : on donne le rang à partir duquel elle monte.
- **Convergence** : convergente = limite finie ; divergente = limite infinie ou absente. qⁿ tend vers 0 si −1 < q < 1, vers +∞ si q > 1, n'a pas de limite si q ≤ −1, et vaut 1 si q = 1. Si lim f(x) = ℓ alors lim f(n) = ℓ. Croissante et majorée (ou décroissante et minorée) implique convergente, avec ℓ ≤ M mais pas forcément ℓ = M.
- **Opérations sur les limites** : somme, produit, quotient de limites finies se calculent ; quatre formes indéterminées (+∞ − ∞, 0 × ∞, ∞ / ∞, 0 / 0) se lèvent en factorisant le terme dominant : 2ⁿ − 3ⁿ tend vers −∞, pas vers 0.
- **Limites et ordre** : comparaison (uₙ ≥ vₙ, vₙ → +∞), encadrement par deux suites de même limite, ou |uₙ − ℓ| ≤ vₙ avec vₙ → 0. Au passage à la limite, seul ≥ est garanti : 1/n > 0 mais sa limite vaut 0.
- **uₙ₊₁ = a·uₙ + b** (a ≠ 1) : point fixe ℓ = b / (1 − a), vₙ = uₙ − ℓ géométrique de raison a, uₙ = ℓ + aⁿ(u₀ − ℓ) ; limite ℓ si −1 < a < 1. Poser vₙ = uₙ − b est une erreur : seule la soustraction du point fixe donne une suite géométrique.
- **Suites homographiques** uₙ₊₁ = (a·uₙ + b) / (c·uₙ + d) : les limites possibles sont les points fixes (ℓ = (aℓ + b) / (cℓ + d)) ; deux points fixes α et β donnent vₙ = (uₙ − α) / (uₙ − β) géométrique, un seul donne vₙ = 1 / (uₙ − α) arithmétique ; les données de la suite désignent le bon point fixe.
