## Exercice 1 (3.5 points)

A l'aide d'une perfusion, on introduit un médicament dans le sang d'un malade.
La perfusion est programmée de façon que la concentration C (en microgrammes par cm³) du médicament dans le sang ne dépasse pas 200 µg/cm³.
Le tableau suivant donne pour ce malade, le temps T (en minutes) mis pour atteindre la concentration C (en µg/cm³).

[tableau : C = 24 ; 72 ; 104 ; 120 ; 128 ; 144 ; 160 ; 176 ; 184 — T = 70 ; 161 ; 242 ; 294 ; 323 ; 395 ; 495 ; 635 ; 786]

1. Compléter dans la figure 1 de l'annexe, le nuage de points de la série (C,T).
2. On pose X = ln(200 - C).
   Le tableau ci-dessous donne les valeurs de la série (X,T). (Les valeurs de X sont arrondies à 10⁻¹).

[tableau : X = 5.2 ; 4.9 ; 4.6 ; 4.4 ; 4.3 ; 4 ; 3.7 ; 3.2 ; 2.8 — T = 70 ; 161 ; 242 ; 294 ; 323 ; 395 ; 495 ; 635 ; 786]

   a) Déterminer l'arrondi à 10⁻³ du coefficient de corrélation linéaire entre X et T.
   b) En déduire que l'on peut exprimer le temps T en fonction de la concentration C par une relation de la forme T = α + β ln(200 - C), où α et β sont deux réels qui seront arrondis à 10⁻¹.
3. Dans cette question les résultats seront arrondis à l'unité.
   a) Estimer le temps T₁ mis pour atteindre la concentration C₁ = 190 µg/cm³.
   b) L'efficacité du médicament est optimale lorsque sa concentration est comprise entre 190 µg/cm³ et 197 µg/cm³.
      Déterminer la durée de l'efficacité optimale du médicament.

## Exercice 2 (5 points)

1. On considère dans ℂ, l'équation (E) : z² - 2(√3 + i)z + 8(1 + i√3) = 0.
   a) Vérifier que 4i est une solution de (E).
   b) Déterminer l'autre solution de (E).

Le plan est rapporté à un repère orthonormé direct (O, vec(u), vec(v)).
Dans la figure 2 de l'annexe, (ζ) est le cercle de centre O et de rayon 4 ; A, B et C sont les points de (ζ) d'affixes z_A = -4, z_B = 4 et z_C = 4i.

2. On considère le point D d'affixe z_D = 2√3 - 2i.
   a) Écrire z_D sous forme exponentielle.
   b) Construire le point D dans la figure 2.
3. Soit I le point d'affixe z_I = (√3 - 3) + i(√3 + 1).
   a) Vérifier que z_D - z_I = (3 + √3)(1 - i).
   b) Montrer que I est le projeté orthogonal de D sur la droite (AC).
   c) Construire le point I.
4. Soit J le projeté orthogonal de D sur la droite (BC).
   a) Justifier que le triangle ABC est rectangle en C.
   b) Montrer que le quadrilatère CIDJ est un rectangle.
   c) En déduire l'affixe du point J.

## Exercice 3 (4.5 points)

1. a) Montrer que pour tout réel t ≥ 0, 1/(1+t) ≤ 1.
   b) En déduire que pour tout réel x ≥ 0, ln(1+x) ≤ x.
2. Montrer que pour tout réel t ≥ 0, ln(1+e^(2t)) = 2t + ln(1+e^(-2t)).

On considère les intégrales A = ∫₂³ t e^t dt et B = ∫₂³ e^t ln(1+e^(2t)) dt.

3. À l'aide d'une intégration par parties, montrer que A = 2e³ - e².
4. a) Montrer que B - 2A ≥ 0.
   b) En utilisant la question 1.b), montrer que B - 2A ≤ e^(-2) - e^(-3).
   c) En déduire que 65.56 < B < 65.65.

## Exercice 4 (7 points)

On considère la fonction f définie sur ]-2, +∞[ par f(x) = x - ln(x+2).
On désigne par (C_f) sa courbe représentative dans un repère orthonormé (O, vec(i), vec(j)) du plan.

I) 1. a) Calculer lim_{x→-2⁺} f(x). Interpréter le résultat.
      b) Montrer que lim_{x→+∞} f(x) = +∞ puis calculer lim_{x→+∞} f(x)/x.
      c) Montrer que la droite Δ : y = x est une direction asymptotique à la courbe (C_f) au voisinage de +∞.
   2. a) Montrer que pour tout réel x > -2, f'(x) = (x+1)/(x+2).
      b) Dresser le tableau de variation de f.
      c) Montrer que l'équation f(x) = 0 admet dans l'intervalle ]-2, +∞[ exactement deux solutions α et β telles que α < -1 et 1.1 < β < 1.2.
   3. a) Étudier la position relative de (C_f) et Δ.
      b) Tracer la courbe (C_f).
   4. Soit 𝒜 l'aire (en u.a) de la partie du plan limitée par la courbe (C_f), la droite Δ et les droites d'équations x = -1 et x = β.
      Montrer que 𝒜 = β² + β - 1.

II) Soit la suite (u_n) telle que u₀ = 0 et u_(n+1) = f(u_n), pour tout n ∈ IN.
   1. a) Montrer par récurrence que pour tout n ∈ IN, u_n ≥ -1.
      b) Montrer que la suite (u_n) est décroissante.
      c) En déduire que la suite (u_n) est convergente et calculer sa limite.
   2. On considère la suite (v_n) définie sur IN par v_n = (2+u₀)×(2+u₁)× ... ×(2+u_n).
      a) Justifier que pour tout k ∈ IN, ln(2+u_k) = u_k - u_(k+1).
      b) Montrer que pour tout n ∈ IN, ln(v_n) = -u_(n+1).
      c) En déduire lim_{n→+∞} v_n.
