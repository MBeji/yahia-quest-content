# 🧭 النّسبة والمصدر الصّناعيّ — حرفانِ يبنيانِ صفةً ومعنًى

> 💡 «أضفْ ياءً مشدّدةً إلى اسمٍ تحصلْ على صفةٍ تقولُ من أين هو؛ أضفْ إليها تاءً تحصلْ على معنًى مجرّدٍ لم يكنْ في اللغةِ قبلَك.»

## 🏰 صفةٌ تقولُ الانتسابَ

يصفُ عليّ الدّوعاجي زوجتَه فيقولُ إنّها «سَمْراءُ القامةِ … بعينَينِ نَجْلاوَيْنِ كأعيُنِ
**الحجازيّات**»، وإنّ عليها الثّيابَ **الدّمشقيّةَ** المُطَرَّزةَ، وإنّها تتحلّى بأنفسِ الياقوتِ
المجلوبِ من أعماقِ الخليجِ **الفارسيِّ** والمحيطِ **الهنديِّ**.

خمسُ كلماتٍ تنتهي كلُّها بالياءِ المشدّدةِ، وكلٌّ منها تردُّ الموصوفَ إلى مكانٍ. فما اسمُ هذه
الصّيغةِ؟ وكيف تُبنى؟

::: definition
**النّسبةُ**: **صيغةٌ صرفيّةٌ تدلُّ على صفةِ الانتسابِ إلى شيءٍ**.
**وتتكوّنُ** من **الاسمِ المنسوبِ إليه** مع **ياءٍ مضاعفةٍ مسبوقةٍ بكسرةٍ** تُسمّى **ياءَ النّسبةِ**.
:::

| المنسوبُ إليه | الصّفةُ المنسوبةُ | ماذا تقولُ؟         |
| ------------- | ----------------- | ------------------- |
| دمشقُ         | دِمَشْقيّ         | مكانُ الصّنعِ       |
| الحِجازُ      | حِجازيّ           | مكانُ الأصلِ        |
| الهِندُ       | هِنْديّ           | مكانُ الأصلِ        |
| الحريرُ       | حريريّ            | المادّةُ           |
| الرّبيعُ      | رَبيعيّ           | الزّمانُ           |

::: exemple كيف تقرأُ صفةً منسوبةً وترجعُ إلى أصلِها

1. **انزعْ ياءَ النّسبةِ والكسرةَ قبلَها**: «فضّيّ» ← «فضّ».
2. **أعِدْ ما يقتضيه الاسمُ**: تاءَ التأنيثِ المحذوفةَ ← «فضّة».
3. **تحقّقْ بالمعنى**: أهو مصنوعٌ من الفضّةِ؟ نعم ← **المنسوبُ إليه هو الفضّةُ**، **لأنّ** النّسبةَ
   لا تكونُ إلّا إلى شيءٍ قائمٍ يُرَدُّ إليه الموصوفُ.

:::

::: verifie
ما المنسوبُ إليه في «السّجّادُ البُخاريُّ» وفي «الخطُّ الكوفيُّ»؟

---

**بُخارى** و**الكوفةُ**: مدينتانِ، والصّفتانِ تردّانِ السّجّادَ والخطَّ إلى مكانِ صنعِهما — كما تردُّ
«الثّيابُ الدّمشقيّةُ» الثّيابَ إلى دمشقَ.
:::

::: retenir
النّسبةُ صفةُ انتسابٍ، وعلامتُها ياءٌ مضاعفةٌ مسبوقةٌ بكسرةٍ تلحقُ آخرَ الاسمِ.
:::

## 🔧 ما يتغيّرُ في الاسمِ قبلَ أن يقبلَ الياءَ

انسبْ إلى «مكّة» تقلْ **مكّيّ** — سقطت التاءُ. وانسبْ إلى «أب» تقلْ **أبَويّ** — زادَ حرفٌ!
وانسبْ إلى «سماء» تقلْ **سَماويّ** — تبدّلت الهمزةُ.

فهل الياءُ تُضافُ وكفى، أم أنّ الاسمَ نفسَه يُهيَّأُ لها أوّلًا؟

::: propriete
**تلحقُ ياءُ النّسبةِ آخرَ الاسمِ، ويُهيَّأُ الاسمُ لها**:

- **تاءُ التأنيثِ تسقطُ**: فاطمةُ ← فاطِميّ، البصرةُ ← بَصْريّ، القاهرةُ ← قاهِريّ.
- **الثلاثيُّ المحذوفُ الآخِرِ يستردُّ محذوفَه**: أب ← أبَويّ، أخ ← أخَويّ، يَد ← يَدَويّ،
  دَم ← دَمَويّ، سَنَة ← سَنَويّ، شَفَة ← شَفَويّ، لُثَة ← لَثَويّ.
- **الممدودُ**: الحكمُ فيه على **أصلِ الهمزةِ**، وهو ثلاثةُ أحوالٍ لا حالانِ:
  - **أصليّةٌ** (الهمزةُ حرفٌ من الجذرِ) ← **تبقى**: ابتداء (ب د أ) ← ابتدائيّ، إنشاء (ن ش أ) ←
    إنشائيّ، ضَوْء (ض و ء) ← ضَوْئيّ.
  - **همزةُ تأنيثٍ** (وزنُ فَعْلاء) ← **تُقلبُ واوًا وجوبًا**: صحراء ← صحراويّ، حمراء ← حمراويّ.
  - **منقلبةٌ عن واوٍ أو ياءٍ** ← **يجوزُ الوجهانِ**، الهمزةُ أو الواوُ: سماء (س م و) ← سَماويّ
    أو سَمائيّ، كِساء (ك س و) ← كِسائيّ أو كِساويّ، هواء (ه و ي) ← هَوائيّ أو هَواويّ،
    انتقاء (ن ق ي) ← انتقائيّ أو انتقاويّ.
- **المركّبُ الإضافيُّ**: يُنسَبُ إلى **الجزءِ المميِّزِ** منه لا إلى صدرِه العامِّ، كيلا يقعَ
  اللّبسُ — بلادُ الجريدِ ← **جَريديّ** (لا «بِلاديّ»، فكلُّ بلادٍ بلادٌ)، وأبو بكرٍ ← **بَكْريّ**.
:::

| المنسوبُ إليه | ما تغيّرَ            | الصّفةُ    |
| ------------- | -------------------- | ---------- |
| فاطمةُ        | سقطت تاءُ التأنيثِ   | فاطِميّ    |
| الكوفةُ       | سقطت تاءُ التأنيثِ   | كُوفيّ     |
| أبٌ           | استُرِدَّ المحذوفُ   | أبَويّ     |
| يَدٌ          | استُرِدَّ المحذوفُ   | يَدَويّ    |
| ابتداءٌ       | همزةٌ أصليّةٌ فبقيت  | ابتدائيّ   |
| صحراءُ        | همزةُ تأنيثٍ فصارت واوًا | صحراويّ |
| سماءٌ         | همزةٌ منقلبةٌ: وجهانِ | سَماويّ (أو سَمائيّ) |

::: exemple انسبْ إلى «شَفَة» وإلى «انتقاء»

1. **شَفَة**: ثلاثيٌّ حُذفت لامُه (الأصلُ «شَفَهٌ» أو «شَفَوٌ»)، فيُستردُّ المحذوفُ قبلَ الياءِ ←
   **شَفَويّ**، ومنه «الأصواتُ الشَّفَويّةُ».
2. **انتقاء**: رُدَّه إلى فعلِه «انتقى ينتقي» ← لامُه **ياءٌ**، فالهمزةُ **منقلبةٌ** لا أصليّةٌ،
   ويجوزُ فيها الوجهانِ ← **انتقائيّ** أو **انتقاويّ**، **لأنّ** المنقلبةَ ليست حرفًا من الجذرِ
   حتّى تلزمَ، ولا همزةَ تأنيثٍ حتّى يجبَ قلبُها.

:::

::: piege الخطأ الشائع

إلصاقُ الياءِ بالاسمِ كما هو: «فاطمةيّ» أو «يَديّ». التاءُ تسقطُ وجوبًا، والثلاثيُّ المنقوصُ
الآخِرِ يستردُّ محذوفَه — فالنّسبةُ تُهيّئُ الاسمَ قبلَ أن تلحقَه.

:::

::: verifie
انسبْ إلى «البُنْدُقيّة» وإلى «دَم».

---

**بُنْدُقيّ** (سقطت تاءُ التأنيثِ) و**دَمَويّ** (استُرِدَّ المحذوفُ من الثلاثيِّ ثمّ لحقته الياءُ).
:::

::: retenir
التاءُ تسقطُ، والمحذوفُ يُستردُّ، وهمزةُ الممدودِ حكمُها بأصلِها: أصليّةٌ تبقى، وللتأنيثِ تصيرُ
واوًا وجوبًا، ومنقلبةٌ فيها وجهانِ — ثمّ تلحقُ الياءُ.
:::

## 🔁 من مركّبٍ إضافيٍّ إلى مركّبٍ نعتيٍّ

قل: «درسوا **كتبَ الهندِ** واشتغلوا **بكتبِ الفرسِ**». ثمّ قلْها بالنّسبةِ: «درسوا **الكتبَ
الهنديّةَ** واشتغلوا **بالكتبِ الفارسيّةِ**».

المعنى واحدٌ، والتركيبُ تغيّرَ من رأسِه. فما الذي ربحَتْه الجملةُ؟

::: methode
**لتحويلِ مركّبٍ إضافيٍّ أو جارٍّ ومجرورٍ إلى مركّبٍ نعتيٍّ**:

1. **عيّنِ الاسمَ الثّاني** (المضافَ إليه أو المجرورَ): «كتبُ **الهندِ**»، «أعمدةٌ **من الرّخامِ**».
2. **اصنعْ منه صفةً بالنّسبةِ**: الهندُ ← هنديّة، الرّخامُ ← رُخاميّة.
3. **اجعلْها نعتًا للاسمِ الأوّلِ، مطابقًا له** في التعريفِ والتّذكيرِ والإعرابِ: «الكتبُ
   الهنديّةُ»، «أعمدةٌ رُخاميّةٌ».
:::

| المركّبُ الإضافيُّ | المركّبُ النّعتيُّ  |
| ------------------ | ------------------- |
| عطورٌ من السّنْدِ  | عطورٌ سِنْديّةٌ     |
| أعمدةٌ من الرّخامِ | أعمدةٌ رُخاميّةٌ    |
| السّمكُ في البحرِ  | السّمكُ البحريُّ    |
| أَسْوِرةٌ من ذهبٍ  | أَسْوِرةٌ ذهبيّةٌ   |
| علومُ الفلسفةِ     | العلومُ الفلسفيّةُ  |

::: exemple حوّلْ «بلغوا في علومِ الطّبِّ ما لم يبلغْه أحدٌ»

1. **الاسمُ الثّاني**: «الطّبّ».
2. **الصّفةُ منه**: طِبّيّ، ومؤنّثُها طِبّيّة.
3. **النّعتُ يُطابقُ**: «العلوم» جمعُ مؤنّثٍ معرّفٌ مجرورٌ ← **في العلومِ الطِّبّيّةِ**، **لأنّ**
   النّعتَ يتبعُ منعوتَه في التعريفِ والإعرابِ والعددِ.

:::

::: verifie
حوّلْ «لونُ الرّخامِ كلونِ الوَرْدِ» إلى مركّبٍ نعتيٍّ فيه نسبةٌ.

---

**الرّخامُ ورديٌّ** أو «لونُ الرّخامِ ورديٌّ»: صُنعت الصّفةُ من «الوَرْد» بالنّسبةِ، فأغنت عن
التّشبيهِ كلِّه.
:::

::: retenir
خُذِ الاسمَ الثّاني، اصنعْ منه صفةً بالنّسبةِ، وأجرِها نعتًا مطابقًا على الأوّلِ.
:::

## 🧪 المصدرُ الصّناعيُّ — تاءٌ تصنعُ معنًى مجرّدًا

«إنسانٌ» ذاتٌ. و«إنسانيٌّ» صفةُ انتسابٍ إليها. فما «**إنسانيّةٌ**»؟

ليست ذاتًا ولا صفةَ ذاتٍ: إنّها **معنًى** قائمٌ بنفسِه. وكذلك «الشّعوبيّةُ» و«الانتهازيّةُ»
و«الأوّليّةُ».

::: definition
**المصدرُ الصّناعيُّ**: **اسمٌ لَحِقت آخرَه ياءٌ مضاعفةٌ مسبوقةٌ بكسرةٍ وتاءٌ** — أي اللاحقةُ
**(ـيّة)** — **ويدلُّ على معنًى مجرّدٍ**.
:::

| الاسم      | المصدرُ الصّناعيُّ | المعنى المجرّدُ        |
| ---------- | ------------------ | ---------------------- |
| أوّلٌ      | أوّليّة            | كونُ الشّيءِ أوّلًا    |
| حُرٌّ      | حُرّيّة            | كونُ المرءِ حُرًّا     |
| انتهازيّ   | انتهازيّة          | خُلُقُ انتهازِ الفرصِ  |
| موضوعٌ     | موضوعيّة           | التزامُ الموضوعِ       |
| كيفَ       | كيفيّة             | طريقةُ الشّيءِ        |

::: exemple كيف تُميّزُ المصدرَ الصّناعيَّ من نسبةٍ مؤنّثةٍ؟

1. **انزعِ اللاحقةَ واسألْ عن المعنى**: «الأعمدةُ الرُّخاميّةُ» ← الأعمدةُ **موصوفةٌ**
   بأنّها من رخامٍ ← نسبةٌ مؤنّثةٌ.
2. **جرّبْ جعلَها نعتًا**: إن استقامت نعتًا لموصوفٍ فهي نسبةٌ.
3. **و«الحرّيّةُ»؟** لا تقعُ نعتًا لشيءٍ، بل تُسنَدُ إليها الأخبارُ: «الحرّيّةُ غاليةٌ» ← **مصدرٌ
   صناعيٌّ**، **لأنّه** اسمُ معنًى لا صفةُ ذاتٍ.

:::

::: piege الخطأ الشائع

عدُّ كلِّ ما انتهى بـ«ـيّة» مصدرًا صناعيًّا. «الثّيابُ الدّمشقيّةُ» ليست مصدرًا صناعيًّا: هي نسبةٌ
جاءت نعتًا لمؤنّثٍ. الفيصلُ في **الوظيفةِ والمعنى**، لا في اللاحقةِ.

:::

::: verifie
«السّلفيّةُ» و«الأعمدةُ الرّخاميّةُ»: أيُّهما مصدرٌ صناعيٌّ؟

---

**السّلفيّةُ**: اسمُ معنًى مجرّدٍ لا يقعُ نعتًا. أمّا **الرّخاميّةُ** فنسبةٌ جاءت نعتًا لـ«الأعمدة»
وتُطابقُه في التعريفِ والعددِ.
:::

::: retenir
(ـيّة) تصنعُ مصدرًا صناعيًّا إذا أفادت معنًى مجرّدًا، ونسبةً مؤنّثةً إذا وقعت نعتًا.
:::

## ⚠️ أوظّفُ: ياءٌ في الآخرِ ليست كلُّها نسبةً

يطلبُ التمرينُ في الكتابِ أن تُميّزَ النّسبةَ من غيرِ النّسبةِ في هذه الثّمانيةِ:

**المتنبّي · الحَفْصيّون · المَعَرّي · البُخاريّ · الشّاميّ · الكُرْسيّ · الرّاعي · الصّحاري**

كلُّها تنتهي بياءٍ. وأربعةٌ منها فقط نسبةٌ. فكيف تفصلُ؟

::: methode
**ثلاثةُ أسئلةٍ تفصلُ، بهذا الترتيبِ**:

1. **أهي ياءٌ مشدّدةٌ مسبوقةٌ بكسرةٍ؟** إن كانت مخفّفةً فليست نسبةً: الرّاعي، الصّحاري، المتنبّي
   أسماءٌ منقوصةٌ آخرُها ياءٌ واحدةٌ.
2. **أيبقى معنًى بعد نزعِ الياءِ؟** «البُخاريّ» ← بُخارى، مدينةٌ ← نسبةٌ. «الكُرْسيّ» ← «كُرْس»،
   لا شيءَ ← ليست نسبةً، والياءُ من بنيةِ الكلمةِ.
3. **أيدلُّ الباقي على شيءٍ يُنتسَبُ إليه؟** مكانٍ، أو قبيلةٍ، أو مادّةٍ، أو زمانٍ.
:::

| الكلمة      | نسبةٌ؟ | لماذا                                   |
| ----------- | ------ | --------------------------------------- |
| الحَفْصيّون | نعم    | إلى أبي حفصٍ — والدولةُ الحفصيّةُ بتونس |
| المَعَرّي   | نعم    | إلى مَعَرّةِ النّعمانِ                  |
| البُخاريّ   | نعم    | إلى بُخارى                              |
| الشّاميّ    | نعم    | إلى الشّامِ                             |
| المتنبّي    | لا     | اسمُ فاعلٍ منقوصٌ من «تنبّأ»            |
| الرّاعي     | لا     | اسمُ فاعلٍ منقوصٌ من «رعى»              |
| الصّحاري    | لا     | جمعُ «صحراء»، وهو منقوصٌ                |
| الكُرْسيّ   | لا     | اسمٌ جامدٌ، ياؤُه من بنيةِ الكلمةِ      |

::: exemple لماذا «المعرّي» نسبةٌ و«المتنبّي» ليست؟

1. **انظرِ الياءَ**: في «المعرّي» مشدّدةٌ مسبوقةٌ بكسرةٍ؛ وفي «المتنبّي» الشّدّةُ على **الباءِ**
   لا على الياءِ، والياءُ واحدةٌ.
2. **انزعِ الياءَ**: يبقى «مَعَرّة» وهي بلدةٌ ← يصحُّ الانتسابُ. ويبقى «المتنبّ» ← لا شيءَ.
3. **وأصلُ الكلمةِ**: «المتنبّي» اسمُ فاعلٍ من «تنبّأ»، **لأنّه** لقبٌ وُضِعَ على فعلٍ فعلَه
   الرّجلُ، لا على مكانٍ جاءَ منه.

:::

::: piege الخطأ الشائع

الحكمُ بالعينِ على الصّورةِ المكتوبةِ. «الصّحاري» و«الكُرسيّ» تنتهيانِ بما يشبهُ ياءَ النّسبةِ،
ولا نسبةَ فيهما. الاختبارُ هو **نزعُ الياءِ**: إن بقيَ اسمٌ يُنتسَبُ إليه فهي نسبةٌ، وإلّا فلا.

:::

::: verifie
في نصِّ «العِقدِ الفريدِ» يُنسَبُ إلى مدينةِ **مَرْو** فيقالُ للرّجالِ «مَرْوَزِيّ» وللثّيابِ
«مَرْوِيّ». فما الذي يدلُّ عليه هذا؟

---

أنّ النّسبةَ إلى الاسمِ الواحدِ قد تختلفُ صيغتُها **باختلافِ المنسوبِ**: صيغةٌ للنّاسِ وصيغةٌ
للأشياءِ. والياءُ المضاعفةُ المسبوقةُ بكسرةٍ باقيةٌ في الاثنتَينِ — فهي العلامةُ، وما قبلَها سماعٌ.
:::

::: retenir
انزعِ الياءَ: إن بقيَ اسمٌ يُنتسَبُ إليه فهي نسبةٌ، وإلّا فهي منقوصٌ أو اسمٌ جامدٌ.
:::
