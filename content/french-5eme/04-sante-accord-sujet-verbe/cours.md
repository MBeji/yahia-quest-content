# 💚 Découvrons les secrets d'une bonne santé

> 💡 « Le verbe suit son sujet comme l'ombre suit le marcheur : où qu'il aille, il s'accorde. »

## ⚡ Le thème du module

Santé et bien-être : bien manger, bouger, dormir, se soigner. Deux outils de langue : l'**accord du verbe avec son sujet** et les verbes en **-ir** au présent.

## 🛡️ La règle d'or : le verbe s'accorde avec son sujet

Le verbe change de **terminaison** selon la **personne** du sujet.

| Sujet | Terminaison au présent (verbe en -er) |
| --- | --- |
| je | -e |
| tu | -es |
| il / elle / on | -e |
| nous | -ons |
| vous | -ez |
| ils / elles | -ent |

**La méthode en trois pas** :

1. je trouve le **verbe** ;
2. je pose **« qui est-ce qui ? »** pour trouver le **sujet** ;
3. je remplace le sujet par **je, tu, il, nous, vous, ils** et j'écris la bonne terminaison.

*Les enfants de la classe (mangent / mange) des fruits.* → *Qui est-ce qui mange ? Les enfants* → **ils** → **mangent**. ✓

## ⚠️ Les trois pièges de l'accord

**1. Le sujet éloigné.** Des mots peuvent se glisser entre le sujet et le verbe.

*Les fruits, riches en vitamines, **protègent** notre corps.*
→ Qui est-ce qui protège ? *Les fruits* → **ils** → protègent.

**2. Le sujet double.** Deux sujets reliés par **et** valent un pluriel.

*Le sport **et** le sommeil **sont** nécessaires.* → **ils** → sont.

**3. Le sujet inversé.** Le sujet peut passer après le verbe.

*Que **mangent** les sportifs ?* → Qui est-ce qui mange ? *les sportifs* → **ils** → mangent.

> 🗝️ Quand j'hésite : je remplace toujours le sujet par un pronom (**il** ou **ils**). L'oreille reconnaît alors la bonne forme.

## 🧮 Je conjugue les verbes en **-ir** au présent

Les verbes comme **finir**, **grandir**, **guérir**, **choisir**, **grossir**, **maigrir**, **nourrir**, **réussir** se conjuguent tous de la même façon.

| finir | grandir |
| --- | --- |
| je fin**is** | je grand**is** |
| tu fin**is** | tu grand**is** |
| il / elle fin**it** | il / elle grand**it** |
| nous fin**issons** | nous grand**issons** |
| vous fin**issez** | vous grand**issez** |
| ils / elles fin**issent** | ils / elles grand**issent** |

Les trois personnes du singulier se disent pareil, mais s'écrivent **-is, -is, -it**. Au pluriel apparaît le groupe **-iss-**.

> ⚠️ Le piège : ne pas confondre avec les verbes en **-er**. On dit *il mange* (pas de t) mais *il grandit* (avec un t).
