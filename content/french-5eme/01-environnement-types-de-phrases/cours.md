# 🌳 Rendons notre environnement plus agréable

> 💡 « Une école propre, un quartier vert : cela commence par des mots justes pour en parler. »

## ⚡ Mon projet d'écriture

Premier module, premier projet : *je raconte un événement en rapport avec ma vie à l'école et mon environnement*.

Toute l'année, mes meilleurs textes iront dans le **livre-souvenirs** de la classe. Ce module me donne trois outils : les **types de phrases**, les **trois temps** et les **graphies du son [e]**.

## 🔮 Les trois types de phrases

| Type              | À quoi il sert       | Signe final | Exemple                             |
| ----------------- | -------------------- | ----------- | ----------------------------------- |
| **déclaratif**    | dire, raconter       | **.**       | *Les élèves ramassent les papiers.* |
| **interrogatif**  | poser une question   | **?**       | *Qui a arrosé les plantes ?*        |
| **exclamatif**    | exprimer un sentiment | **!**      | *Comme la cour est propre !*        |

Trois façons de poser une question :

- avec un **mot interrogatif** : *Où sont les poubelles ?*
- en **inversant** le sujet : *Arroses-tu les plantes ?*
- avec **est-ce que** : *Est-ce que tu arroses les plantes ?*

> 🗝️ Le signe de fin n'est pas une décoration : il **dit** le type de la phrase. Change le signe, tu changes le sens.

## 🕰️ Les trois temps : présent, passé, futur

Le verbe situe l'action dans le temps.

| Temps       | Quand ?          | Mots repères                  | Exemple                                     |
| ----------- | ---------------- | ----------------------------- | ------------------------------------------- |
| **présent** | maintenant       | aujourd'hui, en ce moment     | *Aujourd'hui, nous plantons un arbre.*      |
| **passé**   | avant            | hier, l'an dernier, autrefois | *Hier, nous avons planté un arbre.*         |
| **futur**   | après            | demain, bientôt, l'an prochain | *Demain, nous planterons un arbre.*         |

Pour trouver le temps, je cherche d'abord le **mot repère**, puis je vérifie la **forme du verbe**.

> ⚠️ Le piège : un mot repère peut manquer. Alors seul le verbe décide : *je chante* (présent), *j'ai chanté* (passé), *je chanterai* (futur).

## 🔤 Les graphies du son [e] à la fin des mots

Le son **[e]** s'écrit de plusieurs façons à la fin d'un mot. Ce n'est pas au hasard : cela dépend de la **nature** du mot.

| Graphie | Nature du mot                | Exemples                            |
| ------- | ---------------------------- | ----------------------------------- |
| **-é**  | participe passé, adjectif    | *planté*, *ramassé*, *un jardin fleuri* |
| **-er** | verbe à l'infinitif          | *planter*, *ramasser*, *protéger*   |
| **-ez** | verbe conjugué avec **vous** | *vous plantez*, *vous ramassez*     |
| **-et** | nom masculin                 | *un bosquet*, *un jouet*, *un robinet* |
| **-es** | nom ou adjectif au pluriel   | *des arbres*, *propres*             |

**Le test de l'infinitif** : je remplace par *mordre*. Si « mordre » va, j'écris **-er** ; si « mordu » va, j'écris **-é**.

- *Il faut (planter / planté) un arbre.* → *Il faut **mordre*** → **planter**.
- *L'arbre est (planter / planté).* → *L'arbre est **mordu*** → **planté**.

> ⚠️ Le piège : *planter* et *planté* se prononcent exactement pareil. Seul le test permet de choisir.

## 🌍 Les mots de l'environnement

Pour mon projet, j'ai besoin de mots précis : **l'environnement**, **la nature**, **la pollution**, **les déchets**, **une poubelle**, **le tri**, **recycler**, **arroser**, **planter**, **protéger**, **propre**, **pollué**, **un arbre**, **une plante**, **la cour**.

> 🏆 Premier module franchi ! Tu sais choisir le type de ta phrase, situer ton récit dans le temps et ne plus confondre -er et -é. Au module 2, tu vas apprendre à **dire non** — la forme négative.
