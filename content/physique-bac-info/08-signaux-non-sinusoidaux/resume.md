# 📜 Résumé : Production de signaux non sinusoïdaux

- **Multivibrateurs** : comparateur + réservoir d'énergie (RC) + source autonome ; bistable (deux états stables), monostable (un état stable, un quasi-stable, commande externe), astable (deux états quasi-stables, oscille seul) ; l'astable est un oscillateur de relaxation, à créneaux (pas de sinus) ; une horloge délivre des créneaux.
- **Comparateur à A.O. (trigger inverseur)** : u_E sur E⁻, R₂ de S vers E⁺, R₁ de E⁺ à la masse ; ε = R₁/(R₁ + R₂)·u_S − u_E ; u_S = ±U_sat selon le signe de ε ; seuils U_HB = +R₁/(R₁ + R₂)·U_sat (u_E croissante) et U_BH = −R₁/(R₁ + R₂)·U_sat (u_E décroissante) ; cycle d'hystérésis ; sinus d'amplitude inférieure au seuil : pas de basculement.
- **Comparateur à porte CMOS** : sortie 0 ou U_DD ; porte simple = un seuil (voisin de U_DD/2), pas de cycle ; porte à hystérésis = deux seuils U_BH < U_HB (½ et ¾ de U_DD dans le chapitre) ; entre les seuils, la sortie dépend de l'histoire de l'entrée.
- **Astable : grandeurs** : comparateur rebouclé par RC ; niveaux E_H et E_B ; u_C oscille entre U_BH et U_HB ; T = T₁ + T₂, N = 1/T, δ = T₁/T (en %) ; δ = 0,5 seulement si T₁ = T₂ ; états quasi-stables.
- **Durée d'une phase** : RC·du_C/dt + u_C = u_S ; u_C(t) = (U_i − U_f)·e^(−t/RC) + U_f ; Δt = τ·Log((U_i − U_f)/(U_0 − U_f)) avec U_0 entre U_i et U_f ; Log = logarithme népérien ; ne pas oublier U_f.
- **Astable à A.O.** : E_H = +U_sat, E_B = −U_sat, seuils ±R₁/(R₁ + R₂)·U_sat ; T = 2RC·Log(1 + 2R₁/R₂), δ = 0,5, T indépendante de U_sat ; pour R₁ = R₂, T = 2RC·Log 3 ≈ 2,2 RC ; avec deux diodes, T₁ = R_A·C·Log(1 + 2R₁/R₂), T₂ = R_B·C·Log(1 + 2R₁/R₂), δ = R_A/(R_A + R_B).
- **Astable à porte à hystérésis** : E_H = U_DD, E_B = 0 ; T = RC·Log[(U_BH − U_DD)/(U_HB − U_DD) × U_HB/U_BH] ; seuils ½ et ¾ de U_DD : T = RC·Log 3 ≈ 1,1 RC, δ ≈ 0,63 ; seuils symétriques par rapport à U_DD/2 : δ = 0,5.
- **Astable à deux portes** : u_S1 et u_S2 complémentaires, u_E2 = u_S1 − u_C, RC·du_C/dt + u_C = ±U_DD, bascule à u_E2 = U_DD/2, u_C entre ±U_DD/2, u_E2 de −U_DD/2 à 3U_DD/2 ; T = 2RC·Log 3 ≈ 2,2 RC et δ = 0,5 ; en général T₁ = RC·Log((2U₁ − U₂)/(U₁ − U₂)) (phase u_S1 = 0) et T₂ = RC·Log((U₁ + U₂)/U₂) (phase u_S1 = U₁).
