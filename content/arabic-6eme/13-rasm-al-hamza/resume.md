# 📜 ملخّص: رسمُ الهمزة

- **الهمزةُ المتطرّفة** (في آخرِ الكلمة) تُرسَمُ بحسبِ **ما قبلَها وحدَه**: كسرةٌ ← الياء («الشّاطِئُ»)، ضمّةٌ ← الواو («لُؤْلُؤٌ»)، فتحةٌ ← الألف («بَدَأَ»)، حرفٌ ساكنٌ أو حركةٌ طويلة ← السّطر («دِفْءٌ»، «هُدُوءٌ»).
- **من الماضي إلى المضارع** ننظرُ من جديدٍ إلى ما قبلَ الهمزة: «هَيَّأَ» ← «يُهَيِّئُ» (صارَ مكسورًا)، و«بَدَأَ» ← «يَبْدَأُ» (بقيَ مفتوحًا)، و«جَاءَ» ← «يَجِيءُ» (بقيَتْ حركةً طويلة).
- **الهمزةُ المتوسّطة** (في وسطِ الكلمة) تتبعُ **الحركةَ الأقوى** بينَ حركتِها وحركةِ ما قبلَها — الكسرةُ > الضّمّةُ > الفتحةُ > السّكون: كسرةٌ ← النّبرة («سُئِلَ»)، ضمّةٌ ← الواو («مُؤْمِنٌ»)، فتحةٌ ← الألف («رَأْسٌ»، «يَسْأَلُ»).
- **المتوسّطةُ على السّطر** إذا كانَتْ **مفتوحةً** بعدَ فتحةٍ طويلةٍ أو ضمّةٍ طويلة («تَسَاءَلَ»، «مَبْدُوءَةٌ»)؛ فإن لم تكنْ مفتوحةً عادَتِ الحركةُ الأقوى («عَائِدٌ»، «تَفَاؤُلٌ»).
- **حينَ يتّصلُ بالكلمةِ حرفٌ بعدَ الهمزة** تصيرُ متوسّطةً ونعيدُ الحساب: «بَدَأَ» ← «بَدَؤُوا»، «يَقْرَأُ» ← «يَقْرَؤُونَ»، «أَبْنَاءَهَا» / «أَبْنَائِنَا».
