# 📜 خلاصةُ الدّرس — رسمُ الهمزة

## ترتيبُ الحركاتِ في القوّة

> **الكسرةُ ← الضّمّةُ ← الفتحةُ ← السّكونُ**

**الحركةُ ← الكرسيّ**: كسرةٌ ← **ياءٌ (ئ)** · ضمّةٌ ← **واوٌ (ؤ)** · فتحةٌ ← **ألفٌ (أ)**.

## الهمزةُ المتوسّطة

تُرسَمُ على ما يناسبُ **أقوى الحركتَين**: حركتِها وحركةِ ما قبلَها.

| الكلمة | الحركتانِ     | الأقوى   | الكرسيّ |
| ------ | ------------- | -------- | ------- |
| سَأَلَ | فتحةٌ + فتحةٌ | الفتحةُ  | **أ**   |
| سُئِلَ | كسرةٌ + ضمّةٌ | الكسرةُ  | **ئ**   |
| مسؤول  | ضمّةٌ + سكونٌ | الضّمّةُ | **ؤ**   |
| بِئْر  | سكونٌ + كسرةٌ | الكسرةُ  | **ئ**   |
| رَأْس  | سكونٌ + فتحةٌ | الفتحةُ  | **أ**   |

> **على السّطر** إن سبقَها مدٌّ بالألفِ أو واوٌ ساكنةٌ: قراءَة · مُروءَة.
>
> **استثناءٌ**: بعدَ **ياءٍ ساكنةٍ** تُكتَبُ على **نبرةٍ (ئ)** مهما كانتْ حركتُها: هيْئة · شيْئًا.

## الهمزةُ المتطرّفة

تُرسَمُ بحسبِ **حركةِ ما قبلَها وحدَها**:

| ما قبلَها | الكرسيّ | مثال           |
| --------- | ------- | -------------- |
| فتحةٌ     | **أ**   | ملجَأ · قرَأ   |
| ضمّةٌ     | **ؤ**   | تباطُؤ · لؤلُؤ |
| كسرةٌ     | **ئ**   | شاطِئ · قارِئ  |
| سكونٌ     | **ء**   | جزْء · شيْء    |

## ⚠️ الفخُّ الأوّل

**الكسرةُ أقوى من كلِّ شيءٍ**: «سُئِلَ» بالياءِ رغمَ الضّمّةِ قبلَها.
