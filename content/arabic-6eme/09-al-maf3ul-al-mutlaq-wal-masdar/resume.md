# 📜 خلاصةُ الدّرس — المفعولُ المطلقُ والمصدر

## المصدر

اسمٌ يدلُّ على الحدثِ مجرَّدًا من الزّمن.

- مصادرُ الثّلاثيِّ **المجرَّدِ**: **سماعيّةٌ** (جلسَ ← جُلوس).
- مصادرُ الثّلاثيِّ **المزيدِ**: **مطّردةٌ بالأوزان**.

## أوزانُ مصادرِ المزيد

| الفعل       | المصدر           | مثال               |
| ----------- | ---------------- | ------------------ |
| **أفعلَ**   | إفعال            | أكرمَ ← إكرام      |
| **فاعلَ**   | مُفاعَلة / فِعال | ساهمَ ← مساهَمة    |
| **فعَّلَ**  | تفعيل / تفعِلة   | سلَّمَ ← تسليم     |
| **تفعَّلَ** | تفعُّل           | ترَدَّدَ ← ترَدُّد |
| **تفاعلَ**  | تفاعُل           | تناسبَ ← تناسُب    |
| **انفعلَ**  | انفعال           | انكسرَ ← انكسار    |
| **افتعلَ**  | افتعال           | اشتاقَ ← اشتياق    |
| **افعلَّ**  | افعِلال          | احمرَّ ← احمِرار   |
| **استفعلَ** | استفعال          | استقبلَ ← استقبال  |

## المفعولُ المطلق

**مصدرٌ منصوبٌ من لفظِ الفعلِ** يؤكّدُه أو يبيّنُ نوعَه أو عددَه.

| النّوع         | المثال                |
| -------------- | --------------------- |
| مؤكِّدٌ للفعل  | فرِحْتُ **فرَحًا**    |
| مبيِّنٌ للنّوع | سارَ **سيرًا حثيثًا** · انتظرَ **انتظارَ الصّابرِ** |
| مبيِّنٌ للعدد  | دقَّ **دقَّتَينِ**    |

## ⚠️ الفروقُ الّتي تُمتحَنُ

- **مفعولٌ مطلقٌ** من لفظِ الفعل · **مفعولٌ به** وقعَ عليه الفعل · **تمييزٌ** يفسّرُ العدد · **حالٌ** يبيّنُ الهيئة.
- كلُّ مفعولٍ مطلقٍ مصدرٌ، **وليس كلُّ مصدرٍ مفعولًا مطلقًا** — المصدرُ يقعُ مبتدأً وفاعلًا ومجرورًا.
