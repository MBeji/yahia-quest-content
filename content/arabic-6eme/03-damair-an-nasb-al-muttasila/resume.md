# 📜 ملخّص: ضمائرُ النّصبِ المتّصلة

- **ضميرُ النّصب** ضميرٌ متّصلٌ **يُعوّضُ اسمًا منصوبًا**: صدَمَتِ السّيّارةُ الذّئبةَ ← صدَمَتْ**ها**.
- **وظيفتانِ لا ثالثةَ لهما**:
  - اتّصلَ بـ**فعلٍ** ← **مفعولٌ به**: تحبُّ**كَ**، انتابَ**ه**، دفعَ**ه**.
  - اتّصلَ بـ**ناسخٍ** (إنّ، أنّ، كأنّ، لكنّ، ليتَ، لعلّ) ← **اسمُ ناسخٍ**: إنّ**ها**، لكنّ**ه**.
- **الخريطةُ الكاملةُ للضّمائرِ المتّصلة** — القرينةُ هي ما قبلَ الضّمير:
  اسمٌ ← مضافٌ إليه · حرفُ جرٍّ ← مجرورٌ · فعلٌ ← مفعولٌ به · ناسخٌ ← اسمُ ناسخٍ.
- **نونُ الوقاية**: تدخلُ قبلَ ياءِ المتكلّمِ بعد الفعل («أعجبَ**ني**»)، والياءُ وحدَها هي المفعولُ به.
- **الفخّ**: الشّكلُ واحدٌ والوظيفةُ مختلفةٌ — كتابِ**ه** (مضافٌ إليه) · ضربَ**ه** (مفعولٌ به) · إنّ**ه** (اسمُ ناسخٍ).
- **الفخّ الثّاني**: تاءُ «كتبتُ» ضميرُ **رفعٍ** فاعلٌ، لا ضميرَ نصبٍ.
