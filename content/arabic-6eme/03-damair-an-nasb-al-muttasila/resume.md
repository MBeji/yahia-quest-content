# 📜 ملخّص: ضمائرُ النّصبِ المتّصلة

- **ضميرُ النّصبِ** ضميرٌ متّصلٌ **يُعوِّضُ اسمًا منصوبًا**: أضعُ الاسمَ مكانَه لأتأكّد — «انتابَ**هُ** خوفٌ» ← «انتابَ العصفورَ خوفٌ». صُوَرُه صُوَرُ ضمائرِ الجرّ، وضميرُ «أنا» بعد الفعلِ **ـنِي**.
- **بعد الفعل ← مفعولٌ به**: «تُحبُّ**كَ** العصافيرُ»، «رافقَ**نِي** صديقي» — ويأتي قبلَ الفاعلِ المرفوع، فلا أجعلُه فاعلًا.
- **بعد النّاسخِ الحرفيّ ← اسمُ النّاسخ**: «إنَّ**ها** جميلةٌ»، «لكنَّ**هُ** وحيدٌ»، «لِأنَّ**هُ**» — والضّميرُ الّذي لصِقَ بفعلٍ في الجملةِ نفسِها يبقى مفعولًا به.
- **نصبٌ أم جرّ؟** أسألُ: بِمَ لصِقَ الضّمير؟ فعلٌ أو ناسخٌ ← ضميرُ نصب · اسمٌ أو حرفُ جرٍّ ← ضميرُ جرّ — «إنَّ**كَ**» نصبٌ و«علي**كَ**» جرّ.
