# 📜 خلاصةُ الدّرس — اسمُ الفاعلِ واسمُ المفعول

## من الثّلاثيِّ المجرَّد

| الاسم        | الوزن      | مثال         |
| ------------ | ---------- | ------------ |
| اسمُ الفاعل  | **فاعِل**  | كتبَ ← كاتِب |
| اسمُ المفعول | **مَفعول** | كتبَ ← مكتوب |

## من المضاعفِ والنّاقص

| الفعل | اسمُ الفاعل    | اسمُ المفعول |
| ----- | -------------- | ------------ |
| مدَّ  | مادّ           | ممدود        |
| ردَّ  | رادّ           | مردود        |
| بنى   | بانٍ (البانِي)  | مَبنيّ       |
| دعا   | داعٍ (الدّاعي) | مَدعوّ       |

> اسمُ الفاعلِ من النّاقصِ **منقوصٌ**: «قاضٍ» نكرةً، «القاضي» معرفةً.

## من المزيد — ثلاثُ خطوات

1. هاتِ **المضارعَ**.
2. أبدِلْ حرفَ المضارعةِ **ميمًا مضمومةً**.
3. **كسرةٌ** قبلَ الآخِرِ ← فاعلٌ · **فتحةٌ** ← مفعولٌ.

| الفعل   | المضارع | فاعل     | مفعول    |
| ------- | ------- | -------- | -------- |
| أكرمَ   | يُكرِم  | مُكرِم   | مُكرَم   |
| علَّمَ  | يعلِّم  | مُعلِّم  | مُعلَّم  |
| استقبلَ | يستقبِل | مُستقبِل | مُستقبَل |

## ⚠️ الفخُّ الأوّل

**حركةٌ واحدةٌ تقلبُ المعنى**: «مُحترِم» يحترمُ غيرَه · «مُحترَم» يحترمُه غيرُه.
