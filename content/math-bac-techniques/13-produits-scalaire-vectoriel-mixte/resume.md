# 📜 Résumé : Produit scalaire, produit vectoriel et produit mixte dans l'espace

- **Produit scalaire** : AB⃗ . AC⃗ = AB × AC × cos(AB⃗, AC⃗), un réel, nul si l'un des vecteurs est nul ; en base orthonormée, u⃗ . v⃗ = xx′ + yy′ + zz′ et ‖u⃗‖ = √(x² + y² + z²) ; u⃗ . v⃗ = 0 signifie « orthogonaux » et n'impose pas que l'un des deux soit nul.
- **Plans** : le plan passant par A de vecteur normal N⃗ est l'ensemble des M tels que AM⃗ . N⃗ = 0 ; ax + by + cz + d = 0 a pour vecteur normal (a ; b ; c), perpendiculaire au plan et non contenu dans le plan ; P ∥ P′ si les normales sont colinéaires, P ⊥ P′ si N⃗ . N′⃗ = 0, D ∥ P si u⃗ . N⃗ = 0, D ⊥ P si u⃗ et N⃗ sont colinéaires (parallèle au sens large).
- **Distances à un plan et à une droite** : d(A, P) = |a xA + b yA + c zA + d| / √(a² + b² + c²), avec valeur absolue ; le projeté H de A sur une droite vérifie AH⃗ . u⃗ = 0 ; la distance est toujours la longueur AH le long de la perpendiculaire, jamais AM pour un point M quelconque.
- **Produit vectoriel** : u⃗ ∧ v⃗ est un vecteur normal au plan de u⃗ et v⃗, tel que (u⃗, v⃗, u⃗ ∧ v⃗) soit directe, de norme ‖u⃗‖ ‖v⃗‖ |sin| ; nul si et seulement si u⃗ et v⃗ sont colinéaires ; u⃗ ∧ v⃗ = −(v⃗ ∧ u⃗) ; en base orthonormée directe, (yz′ − zy′ ; zx′ − xz′ ; xy′ − yx′).
- **Produit vectoriel en action** : AB⃗ ∧ AC⃗ est normal au plan (ABC) ; l'aire du triangle ABC vaut (1/2)‖AB⃗ ∧ AC⃗‖ (la norme seule est l'aire du parallélogramme) ; |sin θ| = ‖u⃗ ∧ v⃗‖/(‖u⃗‖ ‖v⃗‖) et cos θ = u⃗ . v⃗/(‖u⃗‖ ‖v⃗‖) ; d(A, Δ) = ‖AB⃗ ∧ u⃗‖/‖u⃗‖.
- **Produit mixte** : (u⃗, v⃗, w⃗) = (u⃗ ∧ v⃗) . w⃗, nul si et seulement si les trois vecteurs sont coplanaires ; une base orthonormée est directe si et seulement si le produit mixte vaut 1 ; volume du parallélépipède |(AB⃗, AD⃗, AE⃗)|, du tétraèdre (1/6)|(AB⃗, AC⃗, AD⃗)|, toujours en valeur absolue ; hauteur issue de A : |(BC⃗, BD⃗, BA⃗)|/‖BC⃗ ∧ BD⃗‖ ; distance de deux droites non coplanaires : |(u⃗, u′⃗, AA′⃗)|/‖u⃗ ∧ u′⃗‖.
- **Sphère : équation** : S(I, R) est l'ensemble des M tels que IM = R, d'équation (x − a)² + (y − b)² + (z − c)² = R² ; le centre se lit avec le signe opposé, le second membre est R² ; x² + y² + z² − 2ax − 2by − 2cz + d = 0 donne h = a² + b² + c² − d (sphère si h > 0, point si h = 0, vide si h < 0) ; la sphère de diamètre [AB] est l'ensemble des M tels que MA⃗ . MB⃗ = 0.
- **Sphère et plan** : avec d = d(I, P), d > R donne le vide, d = R la tangence en H (projeté de I), d < R le cercle de centre H et de rayon √(R² − d²) (jamais R − d) ; le plan tangent en A ∈ S a pour vecteur normal IA⃗.
