# 📜 Résumé : Droites et plans de l'espace

- **Colinéarité et coplanarité** : u⃗ et v⃗ sont colinéaires si les trois déterminants d'ordre 2 (ab′ − a′b, ac′ − a′c, bc′ − b′c) sont nuls, jamais un seul ; u⃗, v⃗, w⃗ sont coplanaires si det(u⃗, v⃗, w⃗) = a(b′c″ − b″c′) − b(a′c″ − a″c′) + c(a′b″ − a″b′) = 0 ; quatre points sont coplanaires si AB⃗, AC⃗, AD⃗ le sont.
- **Droite, représentation paramétrique** : D(A, u⃗) a pour équations x = x₀ + λa, y = y₀ + λb, z = z₀ + λc ; la constante est le point, le coefficient de λ est la direction ; un point est sur D si une même valeur de λ convient aux trois équations.
- **Droite, représentation cartésienne** : deux équations de plans, que le point doit vérifier toutes les deux (une seule équation est un plan) ; on passe à la forme paramétrique en éliminant une inconnue puis en prenant une autre comme paramètre, et à la forme cartésienne en éliminant λ.
- **Deux droites** : vecteurs directeurs colinéaires, parallèles (confondues si un point de l'une est sur l'autre) ; sinon on résout le système avec deux paramètres distincts λ et μ : une solution donne des droites sécantes, aucune des droites non coplanaires.
- **Plan** : M est dans le plan (A, u⃗, v⃗) si AM⃗ = λu⃗ + μv⃗ ; équation ax + by + cz + d = 0, obtenue par det(AM⃗, AB⃗, AC⃗) = 0 ; u⃗(α, β, γ) est un vecteur du plan si aα + bβ + cγ = 0, et (a, b, c) n'est en général pas un vecteur du plan.
- **Deux plans** : parallèles si (a, b, c) = k(a′, b′, c′), confondus si d = kd′ en plus, strictement parallèles sinon ; dans les autres cas, sécants suivant une droite que l'on obtient en résolvant le système.
- **Droite et plan** : D est parallèle à P si son vecteur directeur est un vecteur de P ; en reportant D dans l'équation de P, kλ = h donne un point (k ≠ 0), aucun point (k = 0, h ≠ 0) ou tous les points (k = 0, h = 0).
- **Trois plans et section** : une solution unique, une droite commune ou aucun point commun, et trois plans deux à deux sécants n'ont pas toujours un point commun ; la section d'un tétraèdre s'obtient en coupant le plan avec chaque arête dans le repère (B, BC⃗, BD⃗, BA⃗), le point étant sur l'arête si son paramètre est compris entre 0 et 1.
