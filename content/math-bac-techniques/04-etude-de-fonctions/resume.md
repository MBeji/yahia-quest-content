# 📜 Résumé : Étude de fonctions

- **Plan d'étude et parité** : domaine, réduction (f paire ou impaire ⟹ étude sur D ∩ [0 ; +∞[), limites, variations, branches infinies, points particuliers, tracé ; f(−x) = ±f(x) pour tout x de D, jamais en un seul point ; dans un problème, le domaine est celui de la situation.
- **Axe de symétrie** : x = a est axe de C ⟺ f(2a − x) = f(x) pour tout x de D (avec 2a − x ∈ D) ; le symétrique de x est 2a − x ; a = 0 redonne la parité.
- **Centre de symétrie** : W(a ; b) est centre de C ⟺ f(2a − x) = 2b − f(x) ⟺ Y = f(a + X) − b est impaire dans le repère d'origine W (X = x − a, Y = y − b).
- **Branches infinies** : asymptote verticale (limite infinie en a), horizontale (lim f = b), oblique (lim [f(x) − (ax + b)] = 0, avec a = lim f(x)/x et b = lim [f(x) − ax] réels) ; b infini, a = 0 ou a infini : branches paraboliques ; décomposer f(x) = ax + b + c/(x − x₀) donne l'asymptote et la position.
- **Fonctions irrationnelles** : f = √u est définie où u ≥ 0, (√u)′ = u′/(2√u) là où u > 0, demi-tangente verticale aux zéros de u où u′ ≠ 0 ; en −∞, √(x²) = −x ; asymptote oblique par f(x)/x puis f(x) − ax (quantité conjuguée).
- **Fonctions trigonométriques** : f(x + T) = f(x) ; étude sur un intervalle de longueur T, puis translations de kT ; cos(kx) et sin(kx) ont pour période 2π/k ; une somme se répète quand tous ses termes se répètent ; avec la parité, [0 ; T/2] suffit.
- **Courbes déduites** : f + k : translation de vecteur (0 ; k) ; −f : symétrie d'axe (Ox) ; |f| : on retourne les arches sous (Ox) et on garde le reste, avec une pointe aux zéros de f où f′ ≠ 0.
- **Nombre de solutions de f(x) = m** : points communs de C_f et de la droite y = m ; une solution par intervalle de continuité et de stricte monotonie dont l'image contient m, sans compter deux fois une extrémité partagée.
