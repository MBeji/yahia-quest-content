# 📜 Résumé : Nombres complexes

- **Forme algébrique et conjugué** : z = a + ib avec i² = −1, z̄ = a − ib ; z × z̄ = a² + b² (jamais a² − b²) ; on divise en multipliant par le conjugué du dénominateur ; z réel ⇔ z = z̄, imaginaire pur ⇔ z = −z̄ et z ≠ 0 ; iⁿ = iʳ où r est le reste de n par 4.
- **Affixe, module et distance** : |a + ib| = √(a² + b²) = OM (jamais a + b) ; AB = |z_B − z_A| ; |zz′| = |z||z′|, |zⁿ| = |z|ⁿ, |z̄| = |z| ; |z + z′| ≤ |z| + |z′|, avec égalité si les deux vecteurs ont le même sens.
- **Argument** : arg(z) est une mesure de (u⃗, OM⃗), à 2π près, et 0 n'en a pas ; on cherche θ avec cos θ = a/r et sin θ = b/r, et le quadrant tranche (arctan seul trompe) ; arg(z̄) = −arg(z), arg(−z) = arg(z) + π.
- **Forme trigonométrique** : z = r(cos θ + i sin θ) = [r, θ] avec r > 0, a = r cos θ, b = r sin θ ; [r, θ] × [r′, θ′] = [r r′, θ + θ′], z/z′ = [r/r′, θ − θ′], zⁿ = [rⁿ, nθ] ; le signe entre cos et i sin est toujours « + ».
- **Forme exponentielle et Moivre** : e^(iθ) = cos θ + i sin θ, z = r e^(iθ), zⁿ = rⁿ e^(inθ) (l'angle est multiplié aussi) ; (cos θ + i sin θ)ⁿ = cos nθ + i sin nθ ; z réel ⇔ arg(z) = kπ, imaginaire pur ⇔ arg(z) = π/2 + kπ.
- **Euler et linéarisation** : cos θ = (e^(iθ) + e^(−iθ))/2, sin θ = (e^(iθ) − e^(−iθ))/(2i) ; on développe avec le binôme (sans oublier le double produit) puis on regroupe e^(ikx) et e^(−ikx) ; cos nx et sin nx viennent de (cos x + i sin x)ⁿ.
- **Angles, colinéarité, orthogonalité** : (AB⃗, CD⃗) = arg((z_D − z_C)/(z_B − z_A)) et CD/AB est le module de ce quotient ; quotient réel ⇔ colinéaires, imaginaire pur ⇔ orthogonaux ; des différences d'affixes, jamais des affixes seules.
- **Ensembles de points** : |z − a| = r est un cercle de centre A ; |z − a| = |z − b| est la médiatrice de [AB] ; (z − a)/(z − b) réel donne la droite (AB) privée de B, imaginaire pur le cercle de diamètre [AB] privé de A et de B.
