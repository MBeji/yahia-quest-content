# 📜 Résumé : Fonctions logarithmes

- **Définition** : ln est la primitive de x ↦ 1/x sur ]0 ; +∞[ qui s'annule en 1 : ln′(x) = 1/x et ln 1 = 0 ; les primitives de 1/x sont ln x + k ; ln n'existe que pour x > 0.
- **Propriété fondamentale** : pour a > 0 et b > 0, ln(ab) = ln a + ln b ; on en déduit ln(1/a) = −ln a, ln(a/b) = ln a − ln b, ln(aⁿ) = n ln a et ln(aʳ) = r ln a (r rationnel), dont ln √a = (1/2) ln a ; jamais ln(a + b) = ln a + ln b.
- **Étude de ln** : ln est strictement croissante et dérivable sur ]0 ; +∞[, de limites −∞ en 0⁺ et +∞ en +∞ ; c'est une bijection de ]0 ; +∞[ sur ℝ ; ln 1 = 0, ln e = 1 avec 2 < e < 3 ; ln x < 0 ⟺ 0 < x < 1 ; ln x ≤ x − 1 : la courbe est sous sa tangente en 1.
- **Équations et inéquations** : ln a = ln b ⟺ a = b et ln a < ln b ⟺ a < b (a, b > 0) ; on écrit le domaine d'abord, on regroupe en un seul ln, puis on garde les solutions du domaine ; ln x = r ⟺ x = eʳ ; diviser par ln q change le sens si 0 < q < 1.
- **Limites usuelles** : ln x / x tend vers 0 en +∞ et x ln x tend vers 0 en 0⁺ (pour r > 0 rationnel, ln x / xʳ et xʳ ln x aussi) ; ln x/(x − 1) et ln(1 + x)/x tendent vers 1, d'où ln(1 + x) ≈ x près de 0 ; en 0⁺, ln x / x tend vers −∞.
- **Dérivée de ln(u)** : (ln u)′ = u′/u si u > 0, et (ln|u|)′ = u′/u si u ≠ 0 ; les primitives de u′/u sont ln|u| + k ; une primitive de ln sur ]0 ; +∞[ est x ln x − x.
- **Étude d'une fonction avec ln** : domaine, limites (croissances comparées), dérivée u′/u, tableau de variation, branches infinies (asymptote seulement si f(x) − ax tend vers un réel), position relative, réciproque avec (f⁻¹)′(y₀) = 1/f′(x₀).
- **Logarithme décimal** : log x = ln x / ln 10 ≈ 0,43 ln x ; log 1 = 0, log 10 = 1, log(10ʳ) = r ; mêmes règles de calcul que ln ; multiplier x par 10 ajoute 1 à log x ; pH = −log c.
