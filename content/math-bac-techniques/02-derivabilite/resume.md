# 📜 Résumé : Dérivabilité

- **Nombre dérivé** : f′(a) = lim x→a (f(x) − f(a))/(x − a), pente de la tangente en A(a ; f(a)) ; tangente y = f′(a)(x − a) + f(a) ; approximation affine f(a + h) ≈ f(a) + h f′(a).
- **À gauche et à droite** : f dérivable en a ⟺ f′g(a) et f′d(a) existent et sont égaux ; sinon point anguleux ; taux infini ⟹ demi-tangente verticale ; dérivable ⟹ continue, mais continue ⇏ dérivable.
- **Fonction dérivée** : f dérivable sur I si elle l'est en tout point de I ; on dérive par les formules usuelles (xⁿ, 1/x, √x, √(ax + b), (ax + b)/(cx + d), sin, cos, tan) et les opérations (f + g, af, fg, fⁿ, 1/f, f/g), en précisant l'ensemble de dérivabilité.
- **Composée** : (g∘f)′ = (g′∘f) × f′ ; cas fréquents (fⁿ)′ = nf′fⁿ⁻¹ et (√f)′ = f′/(2√f) là où f > 0.
- **Dérivée seconde, inflexion** : f″ = (f′)′ ; point d'inflexion = la courbe traverse sa tangente ; critères : f″ s'annule en changeant de signe, ou f′ s'annule sans changer de signe ; f″(a) = 0 seul ne suffit pas.
- **Sens de variation** : f′ ≥ 0 sur I ⟺ f croissante ; f′ ≤ 0 ⟺ décroissante ; f′ = 0 ⟺ constante ; on le résume dans un tableau de variation, en lisant le signe de f′ et non celui de f.
- **Extrema** : extremum local en x₀ ⟹ f′(x₀) = 0 (condition nécessaire, non suffisante) ; f′ qui s'annule en changeant de signe (+ à − : maximum, − à + : minimum) ; local ≠ global ; optimisation = modéliser, dériver, étudier le signe.
- **Accroissements finis** : f continue sur [a ; b] et dérivable sur ]a ; b[ ⟹ il existe c avec f′(c) = (f(b) − f(a))/(b − a) ; m ≤ f′ ≤ M sur I ⟹ m(b − a) ≤ f(b) − f(a) ≤ M(b − a) ; |f′| ≤ k ⟹ |f(b) − f(a)| ≤ k|b − a|.
