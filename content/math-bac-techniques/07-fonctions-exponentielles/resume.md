# 📜 Résumé : Fonctions exponentielles

- **exp, réciproque de ln** : exp(x) = y ⇔ x = ln y pour y > 0 ; exp est strictement positive et strictement croissante, exp(0) = 1, exp(1) = e ; exp(x) = −3 n'a pas de solution.
- **Règles de calcul et notation eˣ** : e^(a + b) = eᵃ × eᵇ, e^(a − b) = eᵃ/eᵇ, e⁻ᵃ = 1/eᵃ, (eᵃ)ʳ = e^(ar) ; jamais e^(a + b) = eᵃ + eᵇ.
- **Équations et inéquations** : e^u = e^v ⇔ u = v, e^u = k ⇔ u = ln k pour k > 0 ; avec eˣ et e^(2x), on pose X = eˣ > 0 et l'on rejette les X ≤ 0 ; ln ne passe pas dans une somme.
- **Dérivée et courbe** : (eˣ)′ = eˣ, exp strictement croissante ; la tangente en A(0 ; 1) est y = x + 1 et eˣ ≥ x + 1 ; (eˣ − 1)/x → 1 en 0, soit eˣ ≈ 1 + x près de 0.
- **Limites** : eˣ → +∞ en +∞ et eˣ → 0 en −∞ ; eˣ/xⁿ → +∞ en +∞ et xⁿeˣ → 0 en −∞ : l'exponentielle l'emporte sur toute puissance ; asymptote y = 0 en −∞.
- **Dérivée de eᵘ et primitives** : (e^u)′ = u′ e^u ; les primitives de u′ e^u sont e^u + k ; on compense la constante manquante devant u′ (une primitive de e^(2x) est e^(2x)/2).
- **aˣ et xʳ** : aˣ = e^(x ln a) et xʳ = e^(r ln x) ; (aˣ)′ = ln a × aˣ ; aˣ croît si a > 1, décroît si 0 < a < 1 ; aˣ = b ⇔ x = ln b/ln a (a ≠ 1, b > 0), et le sens d'une inéquation s'inverse si a < 1.
- **Étudier e^(u(x))** : f′ = u′ e^u a le signe de u′, f varie comme u ; u → −∞ donne f → 0 (asymptote y = 0) ; un prolongement par continuité se pose quand la limite est un réel (e^(−1/x) → 0 en 0⁺).
