# 📜 Résumé : Équations à coefficients complexes

- **Racines carrées (système)** : z² = a + ib avec z = x + iy équivaut à x² − y² = a, 2xy = b et x² + y² = √(a² + b²) ; un complexe non nul a exactement deux racines carrées opposées, et le signe de 2xy dit si x et y ont le même signe ; on ne garde jamais les quatre couples de signes.
- **Racines carrées (forme exponentielle)** : si Z = λ e^(iα), les racines carrées sont √λ e^(iα/2) et son opposée ; racine carrée du module (jamais module divisé par 2), moitié de l'argument.
- **Second degré dans ℂ** : Δ = b² − 4ac est un complexe sans signe ; on en cherche une racine carrée δ et z = (−b ± δ)/(2a) ; Δ = 0 donne la racine double −b/(2a) ; az² + bz + c = a(z − z′)(z − z″) ; avec b = 2b′, Δ′ = b′² − ac et z = (−b′ ± δ′)/a.
- **Somme et produit** : z′ + z″ = −b/a (avec le signe moins) et z′z″ = c/a ; connaissant une racine, on trouve l'autre sans Δ ; deux complexes de somme S et de produit P sont les solutions de z² − Sz + P = 0.
- **Coefficients réels** : si Δ < 0, les deux solutions sont conjuguées, (−b ± i√(−Δ))/(2a), de somme −b/a et de produit |z|² = c/a ; dès qu'un coefficient n'est pas réel, la conjugaison n'est plus garantie.
- **Racines nièmes** : zⁿ = r e^(iθ) a exactement n solutions ⁿ√r e^(i(θ + 2kπ)/n), k = 0, …, n − 1, sommets d'un polygone régulier inscrit dans le cercle de rayon ⁿ√r ; sans le terme 2kπ/n, on perd n − 1 solutions ; j = e^(i2π/3) vérifie j³ = 1 et 1 + j + j² = 0.
- **Degré 3, 4, 6** : on devine une racine (réelle, ou imaginaire pure z = iy) puis on factorise par identification ; pour z⁴ ou z⁶, on pose Z = z² ou Z = z³, on résout en Z, puis on revient à z (quatre solutions pour un degré 4, pas deux).
- **Paramètre θ et lieux** : on résout en gardant θ constant, on écrit z = c + r e^(iθ) pour lire |z − c| = r (et non |z| = r), on borne θ pour savoir quelle partie du cercle est décrite, et un quotient imaginaire pur prouve un angle droit.
