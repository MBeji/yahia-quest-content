- **Mettre en équation** : choisir l'inconnue → traduire les données → résoudre → **vérifier et interpréter** (rejeter les solutions hors de l'ensemble de résolution ou sans sens concret). Multiplier une inéquation par un nombre négatif **change le sens** de l'inégalité.
- **Valeur absolue** (k > 0) : |X| = k ⇔ X = k ou X = −k ; |X| ≤ k ⇔ −k ≤ X ≤ k ; |X| ≥ k ⇔ X ≤ −k ou X ≥ k ; |A| = |B| ⇔ A = B ou A = −B. |x − a| se lit comme la distance de x à a.
- **Quotients et radicaux** : d'abord l'**ensemble de résolution** (dénominateur ≠ 0, radicande ≥ 0), puis on résout, puis on écarte les valeurs interdites. √A = k (k ≥ 0) ⇔ A = k².
- **Second degré** : forme canonique ax² + bx + c = a[(x + b/(2a))² − Δ/(4a²)] et **discriminant Δ = b² − 4ac**. Δ < 0 : aucune racine ; Δ = 0 : racine double x₀ = −b/(2a) ; Δ > 0 : x₁ = (−b − √Δ)/(2a) et x₂ = (−b + √Δ)/(2a). **Discriminant réduit** : b = 2b', Δ' = b'² − ac, racines (−b' ∓ √Δ')/a.
- **Somme et produit** : S = x₁ + x₂ = −b/a et P = x₁ · x₂ = c/a. Si a + b + c = 0, les racines sont 1 et c/a ; si a − b + c = 0, elles sont −1 et −c/a. Deux nombres de somme S et de produit P sont racines de x² − Sx + P = 0.
- **Factorisation et signe** : Δ > 0 ⇒ a(x − x₁)(x − x₂), signe de a **à l'extérieur** des racines et de −a **entre** elles ; Δ = 0 ⇒ a(x − x₀)², signe de a sauf en x₀ ; Δ < 0 ⇒ signe de a partout. Une inéquation **large** (≤, ≥) inclut les racines, une inéquation **stricte** les exclut.
- **Produits et quotients** : signe de chaque facteur dans un même tableau, puis produit des signes ; les valeurs interdites d'un quotient sont toujours exclues.
- **Se ramener au second degré** : bicarrée (poser X = x², ne garder que X ≥ 0), fractionnaire (ensemble de résolution puis multiplication), irrationnelle (√A = B ⇔ A = B² **et** B ≥ 0, vérification obligatoire).
