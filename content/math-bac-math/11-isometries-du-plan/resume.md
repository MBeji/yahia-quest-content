# 📜 Résumé : Isométries du plan

- **Définition** : une application du plan dans lui-même est une **isométrie** si elle **conserve les distances** — M′N′ = MN pour tous M, N d'images M′, N′. Identité, translations, symétries orthogonales, symétries centrales et rotations en sont. Deux points distincts gardent des images distinctes.
- **Produit scalaire et configurations** : f est une isométrie **⟺** elle conserve le produit scalaire (AB⃗·AC⃗ = A′B′⃗·A′C′⃗). D'où la conservation des **angles géométriques**, du **milieu/barycentre**, du **parallélisme**, de l'**orthogonalité**, du **contact** ; droite ↦ droite, segment ↦ segment isométrique, cercle ↦ cercle isométrique, parallélogramme ↦ parallélogramme. L'image d'un repère orthonormé (A, AB⃗, AC⃗) est orthonormée, et les **coordonnées ne changent pas** : AM⃗ = x·AB⃗ + y·AC⃗ ⟹ A′M′⃗ = x·A′B′⃗ + y·A′C′⃗.
- **Réciproque** : toute isométrie est une **bijection** du plan ; f⁻¹ est une isométrie et f(M) = N ⟺ f⁻¹(N) = M. (S_D)⁻¹ = S_D, (S_I)⁻¹ = S_I, (t_u⃗)⁻¹ = t_(−u⃗), rotation (I, α) ↦ rotation (I, −α). Seules les symétries sont **involutives**.
- **Composition** : g∘f est une isométrie ; associative, **non commutative**. g = f⁻¹ ⟺ f∘g = Id ; **(f∘g)⁻¹ = g⁻¹∘f⁻¹** ; h∘f = h∘g ⟺ f = g. Deux symétries orthogonales : **axes sécants en I** ⟹ S_D′∘S_D = **rotation** de centre I, d'angle 2(u⃗, u′⃗) ; **axes perpendiculaires en I** ⟹ **symétrie centrale** S_I (seul cas commutatif) ; **axes parallèles** ⟹ **translation** t_(2IJ⃗) (J projeté orthogonal de I ∈ D sur D′). Inverser l'ordre donne la réciproque.
- **Points fixes** : si f ≠ Id et A non fixe, tout point fixe est sur la **médiatrice de [AA′]**. Fixer **3 points non alignés** ⟺ f = Id (une isométrie est **déterminée par 3 points non alignés et leurs images**) ; fixer **2 points** A, B ⟹ f fixe la droite (AB), et si f ≠ Id alors **f = S_(AB)** ; fixer **un seul point** I ⟹ **rotation** de centre I et d'angle non nul. Toute isométrie s'écrit de façon **unique** t∘g avec g fixant un point O donné.
- **Sans point fixe** : soit une **translation de vecteur non nul**, soit une **symétrie glissante** t_u⃗∘S_Δ avec **u⃗ directeur de Δ** (alors f∘f = t_(2u⃗), alors que S_D∘S_D = Id).
- **Décomposition et classification** : toute isométrie = **au plus trois symétries orthogonales**. Rotation (I, θ) = S_D′∘S_D, D et D′ sécantes en I avec 2(u⃗, u′⃗) ≡ θ [2π] (**premier axe libre**, second imposé) ; translation t_u⃗ = S_D′∘S_D, D ⊥ u⃗ et D′ parallèle passant par K tel que HK⃗ = ½u⃗ ; symétrie centrale = deux axes perpendiculaires. Points fixes : Id → tout le plan ; S_D → la droite D ; rotation (θ ≠ k2π) → {I} ; translation non nulle → ∅ ; symétrie glissante → ∅.
- **Reconnaître une isométrie par ses équations** : **1)** vérifier M′N′ = MN (en complexes |z′₁ − z′₂| = |z₁ − z₂|, ce qui exige **|a| = 1**) ; **2)** résoudre f(M) = M ; **3)** conclure par la classification. z′ = az + b (|a| = 1) : translation t_b si a = 1, sinon **rotation** de centre d'affixe b/(1 − a) et d'angle arg(a). z′ = az̄ + b (|a| = 1) : **symétrie orthogonale** si les points fixes forment une droite, **symétrie glissante** s'il n'y en a aucun. Types : z′ = iz − 1 − i → rotation (−i, π/2) ; z′ = i·z̄ → symétrie d'axe y = x ; z′ = z̄ + 2 → symétrie glissante d'axe (Ox).
