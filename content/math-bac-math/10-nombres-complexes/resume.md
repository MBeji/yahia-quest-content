# 📜 Résumé : Nombres complexes

- **Forme algébrique et conjugué** : i² = −1 et tout z s'écrit **de façon unique** z = a + ib. z réel ⟺ b = 0 ⟺ z = z̄ ; z imaginaire ⟺ a = 0 ⟺ z = −z̄. (z + z′)‾ = z̄ + z̄′, (zz′)‾ = z̄ z̄′, (zⁿ)‾ = (z̄)ⁿ, (z/z′)‾ = z̄/z̄′ ; z + z̄ = 2Re(z), z − z̄ = 2i Im(z), zz̄ = |z|². Diviser = multiplier par le conjugué du dénominateur ; les puissances de i tournent de 4 en 4 ; ℂ **n'est pas ordonné**.
- **Plan complexe et module** : M(z) dans (O, u⃗, v⃗) direct, affixe de MN⃗ = z_N − z_M, **|z| = √(a² + b²) = OM** et **MN = |z_N − z_M|** — un module est une longueur. |zz′| = |z||z′|, |z′/z| = |z′|/|z|, |zⁿ| = |z|ⁿ, |z̄| = |z|, |z|² = zz̄, **|z + z′| ≤ |z| + |z′|**. Lieux : **|z − ω| = r → cercle** de centre Ω(ω) ; **|z − a| = |z − b| → médiatrice** de [AB]. Deux vecteurs sont **colinéaires** ssi le quotient de leurs affixes est réel, **orthogonaux** ssi il est imaginaire.
- **Argument et écriture trigonométrique** : pour z ≠ 0, arg(z) ≡ θ [2π] mesure (u⃗, OM⃗), cos θ = a/|z|, sin θ = b/|z|, **z = |z|(cos θ + i sin θ)** — le **quadrant** tranche entre deux angles de même cosinus. arg(z̄) ≡ −arg z, arg(−z) ≡ π + arg z, arg(kz) ≡ arg z si k > 0 (≡ π + arg z si k < 0) ; **arg(zz′) ≡ arg z + arg z′**, arg(z′/z) ≡ arg z′ − arg z, arg(zⁿ) ≡ n arg z, d'où **Moivre : zⁿ = |z|ⁿ(cos nθ + i sin nθ)**.
- **Écriture exponentielle** : e^(iθ) = cos θ + i sin θ, de module 1, avec (e^(iθ))‾ = e^(−iθ) et −e^(iθ) = e^(i(θ+π)) ; e^(iθ)e^(iθ′) = e^(i(θ+θ′)), (e^(iθ))ⁿ = e^(inθ). Tout z ≠ 0 s'écrit **z = re^(iθ)**, r = |z|. Factorisations clés : **1 + e^(iθ) = 2cos(θ/2)e^(iθ/2)** et **1 − e^(iθ) = −2i sin(θ/2)e^(iθ/2)** (si le facteur est négatif, ajouter π à l'argument) ; elles achèvent les sommes Σcos kθ, calculées comme suites géométriques de raison e^(iθ).
- **Angles orientés** : **(u⃗, AB⃗) ≡ arg(z_B − z_A)** et **(AB⃗, CD⃗) ≡ arg((z_D − z_C)/(z_B − z_A))** [2π], le module du quotient donnant CD/AB. Avec Z = (z_C − z_A)/(z_B − z_A) : A, B, C alignés ⟺ Z réel ; (AB) ⊥ (AC) ⟺ Z imaginaire ; ABC équilatéral ⟺ |Z| = 1 et arg Z ≡ ±π/3. Lieux : arg(z − z_A) ≡ θ [2π] → **demi-droite** d'origine A privée de A ; arg((z − z_A)/(z − z_B)) ≡ θ [2π] → **arc de cercle** par A et B, privé de A et B (avec [π], le cercle entier).
- **Racines nièmes** : zⁿ = 1 a exactement **n** solutions e^(i2kπ/n), k ∈ {0, …, n − 1}, sommets d'un polygone régulier du cercle trigonométrique, de somme nulle ; pour n = 3, j = −1/2 + i√3/2 avec j³ = 1, j² = j̄, **1 + j + j² = 0**. Plus généralement zⁿ = a = |a|e^(iθ) a n solutions **zₖ = r e^(i(θ/n + 2kπ/n))** avec rⁿ = |a|. Racines carrées de u par la **méthode algébrique** : x² − y² = Re(u), 2xy = Im(u), x² + y² = |u| (le signe de 2xy apparie x et y). Un complexe a **deux** racines carrées opposées : jamais de notation √z.
- **Équations** : az² + bz + c = 0 a toujours deux solutions **z = (−b ± δ)/2a**, δ étant **une** racine carrée de Δ = b² − 4ac (Δ est complexe : « Δ < 0 » n'a pas de sens) ; az² + bz + c = a(z − z₁)(z − z₂), **z₁ + z₂ = −b/a**, **z₁z₂ = c/a** (le contrôle le plus rapide). Racines conjuguées **seulement** si a, b, c sont tous réels. Degré ≥ 3 : deviner une racine z₀ (réelle ou imaginaire pure), factoriser **P(z) = (z − z₀)g(z)**, résoudre g.
- **Complexes et trigonométrie** : **Moivre** (cos x + i sin x)ⁿ = cos nx + i sin nx **développe** cos nx et sin nx en puissances (binôme puis identification) — cos 3x = cos³x − 3cos x sin²x. Les **formules d'Euler** cos x = (e^(ix) + e^(−ix))/2 et sin x = (e^(ix) − e^(−ix))/**2i** **linéarisent** : cos³x = (1/4)cos 3x + (3/4)cos x, sin⁵x = (1/16)(sin 5x − 5 sin 3x + 10 sin x) — la forme qui s'intègre. Vérifie toute linéarisation sur une valeur particulière.
