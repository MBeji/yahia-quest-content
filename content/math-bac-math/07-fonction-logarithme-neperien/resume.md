# 📜 Résumé : Logarithme népérien

- **Définition** : ln x = ∫₁ˣ dt/t pour x > 0 — c'est **la primitive de x ↦ 1/x qui s'annule en 1**. Elle est continue, dérivable et strictement croissante sur ]0, +∞[, avec ln′(x) = 1/x et ln 1 = 0. Pour x > 1, ln x est l'aire sous l'hyperbole y = 1/t entre 1 et x (ln 2 ≈ 0,693, encadré à la main par 37/60 ≤ ln 2 ≤ 47/60).
- **Comparaison et résolution** : pour a > 0 et b > 0, ln a > ln b ⟺ a > b ; ln a = ln b ⟺ a = b ; ln a = 0 ⟺ a = 1 ; ln a > 0 ⟺ a > 1 ; ln a < 0 ⟺ 0 < a < 1. Méthode : conditions d'existence, puis forme ln A = ln B, puis bijection. Une solution hors du domaine est une fausse solution.
- **Bijection et le nombre e** : ln réalise une bijection strictement croissante de ]0, +∞[ sur ℝ ; l'unique solution de ln x = 1 est notée **e**, donc ln e = 1 et e ≈ 2,71828 (2 < e < 3).
- **Propriétés algébriques** (a > 0, b > 0) : ln(ab) = ln a + ln b ; ln(a/b) = ln a − ln b ; ln(1/b) = −ln b ; ln(aᵖ) = p ln a pour p entier ; ln(ᵖ√a) = (1/p)ln a pour p ≥ 2. Usage type : le plus petit n avec (1/2)ⁿ ≤ 10⁻⁴ est n = 14. **Piège** : ln(a + b) ≠ ln a + ln b, et ln(x²) = 2 ln|x|.
- **Limites de référence** : lim_{x→+∞} ln x = +∞ ; lim_{x→0⁺} ln x = −∞ (asymptote verticale x = 0) ; lim_{x→+∞} (ln x)/x = 0 ; lim_{x→1} (ln x)/(x − 1) = 1 (c'est ln′(1)).
- **Variation, tangente et courbe** : ln croît strictement de −∞ à +∞ en s'annulant en 1 ; la tangente en 1 est **T : y = x − 1**, et la courbe reste sous T : **ln x ≤ x − 1** pour tout x > 0 (égalité en 1 seulement). En tout point A(a, ln a), la tangente coupe l'axe des ordonnées exactement **1 unité sous** le projeté de A.
- **Croissances comparées** : pour n et m entiers non nuls, lim_{x→+∞} (ln x)ⁿ/xᵐ = 0 et lim_{x→0⁺} xᵐ(ln x)ⁿ = 0 — ln perd contre toute puissance de x. **Piège** : lim_{x→0⁺} (ln x)/x = −∞ (ce n'est pas un produit xᵐ ln x), et lim_{x→0⁺} (ln x + 1/x) = +∞.
- **ln(u) et ln|u|** : ln(u) est définie là où u > 0, ln|u| là où u ≠ 0 ; dans les deux cas la dérivée est la même, **f′(x) = u′(x)/u(x)**. Toujours résoudre le signe de u avant de dériver. Exemple : f(x) = ln(x² + x − 2) sur ]−∞, −2[ ∪ ]1, +∞[, f′(x) = (2x + 1)/(x² + x − 2).
- **Primitives nouvelles** : toute fonction u′/u a pour primitives **ln|u| + k** (sur un intervalle où u ne s'annule pas) ; et **x ln x − x est une primitive de ln** sur ]0, +∞[. Réflexe d'IPP : poser f = ln, c'est lui qui se simplifie en dérivant (∫₁^e x ln x dx = (e² + 1)/4 ; ∫₁^e ln x dx = 1).
- **Encadrements, suites et intégrales** : pour x > 0, **1/(x + 1) ≤ ln(x + 1) − ln x ≤ 1/x** ; on en déduit Sₙ = 1 + 1/2 + … + 1/n ≥ ln(n + 1), donc la série harmonique diverge, et que Sₙ − ln n converge vers la constante d'Euler γ ≈ 0,5772. Pour une suite d'intégrales, encadrer l'intégrande puis intégrer (ex. (ln 2)/(n + 1) ≤ ∫₀¹ xⁿ ln(x + 2)dx ≤ (ln 3)/(n + 1) → 0).
