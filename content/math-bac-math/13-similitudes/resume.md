# 📜 Résumé : Similitudes

- **Homothéties et translations** : h(I, k) est définie par IM′⃗ = kIM⃗ ; pour k ≠ 1, f est une homothétie de rapport k **⟺** M′N′⃗ = kMN⃗. Elle conserve les angles orientés. h₂∘h₁ est une homothétie de rapport **k₁k₂** (une **translation** si k₁k₂ = 1) ; translation ∘ homothétie de rapport k ≠ 1 = homothétie de **même rapport k** (centre différent). En complexes : **z′ = kz + b avec k réel ≠ 1**, centre b/(1 − k).
- **Définition** : pour k réel **strictement positif**, une **similitude de rapport k** vérifie **A′B′ = k·AB** pour tous A, B. Les isométries sont les similitudes de rapport 1 ; une homothétie de rapport k est une similitude de rapport **|k|**. Composée de deux similitudes : rapport **kk′**. Théorème clé : **similitude ⟺ composée d'une homothétie et d'une isométrie**.
- **Conservations** : A′B′⃗·C′D′⃗ = **k²**·AB⃗·CD⃗, donc les **aires sont multipliées par k²** (les longueurs seulement par k, les angles pas du tout). Une similitude est une **bijection**, de réciproque une similitude de rapport **1/k** ; elle conserve angles géométriques, orthogonalité, alignement, barycentre, parallélisme, contact ; segment ↦ segment, droite ↦ droite, cercle ↦ cercle. Deux similitudes coïncidant sur **3 points non alignés** sont égales. **Triangles semblables** : A′B′/AB = A′C′/AC = B′C′/BC ⟺ angles égaux deux à deux.
- **Directe / indirecte** : **directe** = homothétie ∘ **déplacement** (conserve les angles **orientés**) ; **indirecte** = homothétie ∘ **antidéplacement** (les change en leurs **opposées**). Règle des signes (directe = +1, indirecte = −1) : dir∘dir = dir, **ind∘ind = dir**, dir∘ind = ind ; la réciproque garde la nature. **Existence-unicité** : pour A ≠ B et C ≠ D, il existe **exactement une** similitude directe et **une** indirecte envoyant A sur C et B sur D — sans aucune condition sur les longueurs (k = CD/AB).
- **Similitude directe** : son **angle** θ vérifie (AB⃗, A′B′⃗) ≡ θ [2π] pour **tout** couple ; angle de f∘g = **θ + θ′**, angle de f⁻¹ = **−θ**. Si k ≠ 1, elle a un **unique point fixe**, son **centre** I ; ses **éléments caractéristiques** sont (I, k, θ), caractérisés par **IM′ = k·IM** et **(IM⃗, IM′⃗) ≡ θ [2π]**. **Forme réduite** : **f = h(I, k)∘r(I, θ) = r(I, θ)∘h(I, k)**.
- **Écriture complexe (directe)** : **z′ = az + b avec a = ke^(iθ)**, donc **k = |a|**, **θ = arg(a)** et centre **z_I = b/(1 − a)**. Lire a d'abord : a = 1 ⟹ translation ; a réel ⟹ **homothétie** ; |a| = 1 ⟹ **rotation** (chapitre 12) ; sinon similitude directe. Un rapport **négatif** ajoute π à l'angle : r(Ω, π/6)∘h(Ω, −2) se réduit en **r(Ω, −5π/6)∘h(Ω, 2)**.
- **Similitude indirecte** : de rapport k ≠ 1, elle a un **unique point fixe** (son **centre** I) et un **axe** D = {M : IM′⃗ = kIM⃗}. **Forme réduite : f = h(I, k)∘S_D = S_D∘h(I, k)** ; éléments caractéristiques = (I, k, D) — **pas d'angle**. D et sa perpendiculaire en I sont **globalement invariants**, **f∘f = h(I, k²)**, et D porte la **bissectrice** de l'angle MIM′ ((u⃗, IM′⃗) ≡ −(u⃗, IM⃗) [2π]). **Écriture complexe : z′ = az̄ + b**, avec **k = |a|** et **z_I = (a·b̄ + b)/(1 − |a|²)** (si |a| = 1, c'est un **antidéplacement**, pas une similitude à centre).
- **Méthode d'identification** : (1) rapport k = A′B′/AB = |a| ; (2) directe ou indirecte — barre de conjugaison, signe d'un angle orienté ; (3) si k = 1, retour aux isométries ; (4) si directe, angle θ = arg(a) ; (5) centre = **unique point fixe** ; (6) si indirecte, axe = {IM′⃗ = kIM⃗} ou bissectrice de MIM′ ; (7) **vérifier la forme réduite sur un second point**.
