# 📜 Résumé : Fonction exponentielle

- **Définition** : exp est la **réciproque de ln**, définie sur ℝ à valeurs dans ℝ*₊, notée e^x. Pour x réel et y > 0 : **y = e^x ⟺ x = ln y** ; ln(e^x) = x ; e^(ln x) = x ; e^0 = 1, ln e = 1, e ≈ 2,71828. C_exp et C_ln sont **symétriques par rapport à Δ : y = x**. Conséquence permanente : **e^x > 0**, donc un facteur exponentiel ne change jamais le signe d'un produit.
- **Règles de calcul** : e^(a+b) = e^a × e^b ; e^(a−b) = e^a/e^b ; e^(−a) = 1/e^a ; e^(na) = (e^a)^n ; e^(a/q) = q√(e^a) ; e^((p/q)a) = q√(e^(pa)). Réflexe : tout réécrire sous la forme e^α et **additionner les exposants**.
- **Équations et inéquations** : e^A = e^B ⟺ A = B ; e^A ≤ e^B ⟺ A ≤ B ; e^A = k n'a de solution que si k > 0 (alors A = ln k). Une équation en e^(2x) et e^x se ramène au **second degré** en posant X = e^x > 0 (les racines négatives sont rejetées) ; e^(x²−1) < 1 ⟺ x² − 1 < 0, tandis que e^(x²−1) > −2 est vraie partout.
- **Étude de exp** : **(e^x)′ = e^x** (obtenue par la dérivée de la réciproque : 1/ln′(e^x)), donc exp est **strictement croissante** et **bijective de ℝ sur ℝ*₊** ; lim_{−∞} e^x = 0 (asymptote y = 0), lim_{+∞} e^x = +∞ ; lim_{+∞} e^x/x = +∞ (branche parabolique de direction (Oy)) ; lim_{x→0} (e^x − 1)/x = 1. Tangente en 0 : **T : y = x + 1**, et **e^x ≥ x + 1** pour tout x (égalité en 0 seulement) : C est au-dessus de T. Les solutions de f′ = f sont exactement les **x ↦ k e^x**.
- **Croissances comparées** : en +∞, **ln x ≪ x^r ≪ e^x**. Formellement lim_{x→+∞} e^(nx)/x^m = +∞ ; lim_{x→−∞} x^m e^(nx) = 0 ; lim_{x→+∞} e^x/x^r = +∞ ; lim_{x→+∞} (ln x)/x^r = 0 ; lim_{x→0⁺} x^r ln x = 0 (r rationnel > 0). Méthode : **factoriser par l'exponentielle** (x³ − e^(2x) = e^(2x)(x³/e^(2x) − 1) → −∞) ou poser t = −x en −∞ (x e^x = −t/e^t → 0).
- **Fonction x ↦ e^(u(x))** : **(e^u)′ = u′ e^u** ; les primitives de u′e^u sont **e^u + k**. Primitives types : e^(−3x) → −(1/3)e^(−3x) ; x e^(x²) → ½e^(x²) ; sin x · e^(cos x) → −e^(cos x). Reconnaître u′e^u **avant** de penser IPP : ∫₀¹ x e^(x²)dx = (e − 1)/2 se fait par primitive, ∫₀¹ x e^x dx = 1 exige une intégration par parties.
- **Exponentielle de base a** (a > 0) : **a^b = e^(b ln a)** ; a^(c+d) = a^c a^d, (a^c)^d = a^(cd), a^c b^c = (ab)^c ; **(a^x)′ = (ln a)a^x** — jamais x·a^(x−1). Toutes les courbes passent par (0, 1) ; a > 1 ⟹ croissante, lim_{+∞} = +∞ et lim_{−∞} = 0 ; 0 < a < 1 ⟹ décroissante, limites échangées ; y = a^x et y = (1/a)^x sont symétriques par rapport à l'axe des ordonnées. Une équation se résout en ramenant les deux membres à **la même base** (ou en prenant le ln).
- **Fonctions puissances** (r rationnel, x > 0) : **x^r = e^(r ln x)** ; **(x^r)′ = r x^(r−1)** ; primitives x^(r+1)/(r + 1) + k pour r ≠ −1 ; **ⁿ√x = x^(1/n)**. Limites : r > 0 ⟹ x^r → +∞ en +∞ et → 0 en 0⁺ ; r < 0 ⟹ l'inverse. x^r n'est défini que pour **x > 0** (la définition passe par ln x).
