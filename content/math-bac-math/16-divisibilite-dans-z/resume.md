# 📜 Résumé : Divisibilité dans ℤ

- **Diviser** : d (non nul) divise a s'il existe un entier q tel que **a = dq** ; a est alors un multiple de d, et les multiples de d forment dℤ = {dq, q ∈ ℤ}. Si d divise a, **−d aussi** — les diviseurs vont par paires ±. Cas à connaître : D₁ = {−1, 1} ; **tout entier non nul divise 0**, mais 0 ne divise rien ; D_p = {−p, −1, 1, p} pour p premier. Propriétés : a divise b et b divise a ⟹ **a = ±b** ; transitivité ; et surtout **a divise αb + βc** dès que a divise b et c. Méthode reine : pour « n − 1 divise n + 10 », écrire n + 10 = (n − 1) + 11, donc n − 1 divise **11**, donc n ∈ {−10, 0, 2, 12}.
- **Division euclidienne** : pour tout a et tout b ≠ 0, il existe un **couple unique** (q, r) avec **a = bq + r et 0 ≤ r < |b|**. Le quotient est le plus grand entier ≤ a/b si b > 0, le plus petit entier ≥ a/b si b < 0 ; le reste est r = a − bq et appartient à {0, 1, …, |b| − 1}. Le reste ne dépend **pas du signe de b** : 47 par 5 ou par −5 laisse 2 ; −47 par 5 ou par −5 laisse 3. Attention aux négatifs : le quotient de −20 par 7 est **−3** (et r = 1), jamais −2.

- **Congruence** : **a ≡ b (mod n) ⟺ n divise a − b**, avec n entier naturel non nul. Tout entier a un **unique** reste modulo n dans {0, …, n − 1}, et deux entiers sont congrus **si et seulement si** ils ont le même reste : −19, −129, 124 et 13610 sont tous ≡ 3 (mod 11). Relation **réflexive, symétrique, transitive**. À retenir : **a ≡ 0 (mod n) signifie n divise a** ; et congru ≠ égal (−2 ≡ 2 (mod 4) est vrai).
- **Compatibilité avec les opérations** : si a ≡ b et c ≡ d (mod n), alors **a + c ≡ b + d** et **ac ≡ bd** ; de plus **ha ≡ hb** pour tout entier h et **a^m ≡ b^m** pour tout m > 0. On réduit donc chaque facteur **avant** de multiplier : 55348932 ≡ 9 et 1968755 ≡ 2 (mod 17) donnent un produit ≡ 18 ≡ **1** (mod 17). Deux interdits : **on ne simplifie pas par un facteur** (2 × 3 ≡ 2 × 8 (mod 10) mais 3 ≢ 8) et **on ne réduit pas l'exposant modulo n**.
- **Tableaux de congruence** : « pour tout entier a » = n cas seulement, ceux des restes. Modulo 6, les restes possibles de a² sont **{0, 1, 3, 4}** ; la table des produits montre que ab ≡ 1 (mod 6) ⟺ a et b sont tous deux ≡ 1, ou tous deux ≡ 5. Même balayage pour résoudre : 2x ≡ 4 (mod 10) donne **x ≡ 2 ou 7 (mod 10)** (deux solutions), x² ≡ 3 (mod 4) n'en a **aucune**, x² ≡ 4 (mod 11) donne x ≡ 2 ou 9. Résultat type : les restes de a⁹ − a modulo 9 sont **{0, 3, 6}**.
- **Grandes puissances, en trois gestes** : réduire la base, trouver la **période** des puissances, réduire l'exposant modulo cette période. Les puissances de 2 modulo 7 valent 1, 2, 4 et se répètent tous les **3** crans, d'où 247³⁴⁹ ≡ 2³⁴⁹ ≡ 2 (mod 7) car 349 ≡ 1 (mod 3). Cherche d'abord une base ≡ **−1 ou 1** : 298 ≡ −1 (mod 13) donne 298³⁴⁹ ≡ −1 ≡ **12**, et 9 ≡ −1 (mod 10) donne le chiffre des unités de 9²⁰⁰⁷, qui est **9**.
- **Théorème de Fermat** : pour p **premier** ne divisant **pas** a, **a^(p−1) ≡ 1 (mod p)**. Ainsi a⁶ ≡ 1 (mod 7) dès que 7 ne divise pas a, donc a^600 = (a⁶)^100 ≡ 1 pour ces mêmes a. Les deux hypothèses sont indispensables : 2⁵ ≡ 2 (mod 6), car 6 n'est pas premier. Les **nombres de Fermat** F_n = 2^(2ⁿ) + 1 (3, 5, 17, 257, 65537) ne sont pas tous premiers : 641 divise F₅.
- **Critères de divisibilité (méthode de Pascal)** : puisque n s'écrit avec des puissances de 10, il suffit de connaître les restes de 10ᵏ. Modulo **9** et **3**, ils valent tous 1 : n ≡ **somme des chiffres**. Modulo **11**, ils alternent 1, −1 : n ≡ **somme alternée depuis les unités**. Modulo **4**, n ≡ ses **deux derniers chiffres**. Modulo **111**, 1000 ≡ 1 : n ≡ **somme de ses blocs de 3 chiffres** (100010001 → 100 + 10 + 1 = 111, divisible). Modulo **7**, les restes 1, 3, 2, 6, 4, 5 se répètent avec une période de **6**.
- **Le réflexe de contrôle du chapitre** : **toute division euclidienne se relit sur a = bq + r avec 0 ≤ r < |b| ; toute congruence se teste sur une valeur numérique ; tout reste annoncé se recoupe par un second chemin de calcul.** Un reste négatif ou supérieur au module signale une erreur, toujours.
