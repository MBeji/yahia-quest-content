# 📜 Résumé : Déplacements et antidéplacements

- **Les deux clans** : un **déplacement** est une isométrie qui **conserve** les mesures des angles orientés ; un **antidéplacement** les change en leurs **opposées**. Déplacements : identité, translation, rotation. Antidéplacements : symétrie orthogonale, symétrie glissante. Un antidéplacement conserve tout de même distances et angles géométriques.
- **Critère de parité** : déplacement ⇔ composée de **2** symétries orthogonales ; antidéplacement ⇔ **1 ou 3** symétries. Règle des signes (déplacement = +1, antidéplacement = −1) : dép∘dép = dép, antidép∘antidép = **dép**, dép∘antidép = antidép ; la réciproque garde la nature.
- **Détermination** : deux déplacements (resp. deux antidéplacements) qui coïncident sur **deux points distincts** sont égaux ; si AB = CD ≠ 0, il existe **exactement un** déplacement et **un** antidéplacement envoyant A sur C et B sur D.
- **Angle d'un déplacement** : θ tel que (AB⃗, A′B′⃗) ≡ θ [2π] pour **tout** couple. Si θ ≡ 0 [2π] ⟹ **translation** ; sinon **rotation d'angle θ**. Angle de f∘g = θ + θ′ ; angle de f⁻¹ = −θ.
- **Compositions** : t_u⃗∘t_v⃗ = t_(u⃗+v⃗) ; deux rotations ⟹ **translation** si θ + θ′ ≡ 0 [2π], sinon **rotation d'angle θ + θ′** ; rotation (θ ≠ 0) et translation ⟹ **rotation d'angle θ** (mais r∘t et t∘r n'ont pas le même centre).
- **Écriture complexe** (repère orthonormé direct) : translation ⟺ z′ = z + b (b affixe de u⃗) ; rotation ⟺ z′ = az + b avec a = e^(iθ), a ≠ 1, centre z_I = b/(1 − a). Un déplacement s'écrit z′ = az + b avec |a| = 1 ; la forme **conjuguée** z′ = az̄ + b est celle d'un **antidéplacement**.
- **Antidéplacements** : tout antidéplacement est une symétrie orthogonale composée d'une translation. Avec un **point fixe** ⟹ **symétrie orthogonale** ; sans point fixe ⟹ **symétrie glissante**.
- **Forme réduite** : f = t_u⃗∘S_D = S_D∘t_u⃗ avec u⃗ ≠ 0⃗ **directeur de D** — couple (axe, vecteur) unique. Propriétés : le milieu de [MM′] est sur D ; si M ∈ D alors u⃗ = MM′⃗ ; **f∘f = t_(2u⃗)** ; f⁻¹ a le même axe et le vecteur −u⃗. Pour réduire t_v⃗∘S_D : couper v⃗ = v₁⃗ (parallèle à D) + v₂⃗ (perpendiculaire), l'axe glisse de **½v₂⃗** et il reste t_(v₁⃗).

- **Méthode d'identification** : (1) compter les symétries ⟹ nature ; (2) somme des angles ⟹ translation ou rotation ; (3) point fixe ⟹ symétrie orthogonale ou glissante ; (4) suivre **un point bien choisi** pour le centre/le vecteur ; (5) **vérifier sur un second point**.
