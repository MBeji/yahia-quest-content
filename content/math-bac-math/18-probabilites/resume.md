# 📜 Résumé : Probabilités

- **Dénombrement** : sur un ensemble à n éléments, tirages successifs **avec** remise ⟹ **nᵖ** ; tirages successifs **sans** remise ⟹ **A_n^p = n!/(n − p)!** ; tirage **simultané** ⟹ **C_n^p = n!/((n − p)!p!)** ; rangement de tous les éléments ⟹ **n!**. Avec C_n^0 = 1, la symétrie **C_n^p = C_n^(n−p)**, le lien **A_n^p = p!·C_n^p**, et **Σ_(k=0)^(n) C_n^k = 2ⁿ** (nombre de parties d'un ensemble à n éléments).
- **Probabilité sur un ensemble fini** : l'univers E est l'ensemble des issues, un événement est une partie de E. Une probabilité vérifie p(E) = 1, p(∅) = 0 et p(A) = Σ des probabilités des événements élémentaires de A. Propriétés à savoir : **p(A̅) = 1 − p(A)** et **p(A ∪ B) = p(A) + p(B) − p(A ∩ B)** (l'addition simple n'est valable que si A ∩ B = ∅).
- **Équiprobabilité** : quand toutes les issues ont la même probabilité, **p(A) = card(A)/card(E)** — calculer une probabilité redevient un pur dénombrement. À justifier (pièce équilibrée, dé non pipé, tirage au hasard), jamais à supposer.
- **Probabilité conditionnelle** : **p(A/B) = p(A ∩ B)/p(B)** avec p(B) ≠ 0, d'où **p(A ∩ B) = p(B)·p(A/B)**. Sur un **arbre pondéré** : les branches d'un même nœud somment à **1**, on **multiplie** le long d'un chemin, on **additionne** les chemins menant au même événement. p(A/B) ≠ p(B/A).
- **Indépendance** : A et B sont indépendants lorsque **p(A ∩ B) = p(A)·p(B)**, ce qui équivaut à **p(A/B) = p(A)** si p(B) ≠ 0. Deux événements **incompatibles** de probabilités non nulles ne sont **jamais** indépendants.
- **Probabilités totales** : si B₁, ..., Bₙ forment une **partition** de E (deux à deux disjoints, de réunion E) avec p(Bᵢ) ≠ 0, alors **p(A) = Σ p(Bᵢ)·p(A/Bᵢ)**. Pour remonter à une cause, on revient au quotient : **p(Bᵢ/A) = p(Bᵢ ∩ A)/p(A)**.
- **Variable aléatoire** : X : E → ℝ ; sa **loi** est xᵢ ↦ p(X = xᵢ), et **Σ p(X = xᵢ) = 1** (vérification obligatoire). **Espérance E(X) = Σ xᵢpᵢ**, linéaire : E(αX) = αE(X) et E(X + Y) = E(X) + E(Y). **Variance V(X) = E((X − E(X))²) = E(X²) − (E(X))²** (toujours ≥ 0), **écart-type σ(X) = √(V(X))**.
- **Fonction de répartition** : **F(x) = p(X ≤ x)**, croissante de 0 à 1. Pour une variable discrète, elle est **en escalier** : chaque saut en xᵢ a pour hauteur p(X = xᵢ), ce qui permet de relire la loi entière sur le graphique.
- **Loi binomiale B(n, p)** : n épreuves **identiques et indépendantes**, deux issues, p = probabilité du succès ⟹ **p(X = k) = C_n^k pᵏ(1 − p)^(n−k)**, avec **E(X) = np**, **V(X) = np(1 − p)**, **σ(X) = √(np(1 − p))** ; n = 1 donne la loi de **Bernoulli**. « Au moins un succès » se calcule par le contraire : **1 − (1 − p)ⁿ**. Un tirage **sans remise** n'est **pas** binomial.
- **Lois continues** : loi **uniforme** sur [a, b] (densité 1/(b − a)) ⟹ **P(c ≤ X ≤ d) = (d − c)/(b − a)** — seule la longueur compte. Loi **exponentielle** de paramètre λ > 0 (densité λe^(−λt)) ⟹ **P(X ≥ c) = e^(−λc)**, **P(0 ≤ X ≤ c) = 1 − e^(−λc)** et **P(c ≤ X ≤ d) = e^(−λc) − e^(−λd)**. Dans les deux cas **P(X = c) = 0**, donc inégalités strictes et larges donnent la même probabilité.
