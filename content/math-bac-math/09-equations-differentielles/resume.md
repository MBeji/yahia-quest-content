# 📜 Résumé : Équations différentielles

- **Équation différentielle** : équation dont l'inconnue y est une **fonction**, reliant y à ses dérivées ; une solution est une fonction dérivable (deux fois pour l'ordre 2) qui vérifie l'égalité **pour tout x**. Vérifier une candidate = la dériver et la réinjecter dans l'équation.
- **y′ = f(x)** : les solutions sont les **primitives** de f, soit x ↦ F(x) + c ; une condition (ex. y(1) = 5) fixe c. Schéma valable dans tout le chapitre : famille de solutions, puis une condition qui en sélectionne une.
- **y′ = ay** : les solutions sur ℝ sont les fonctions x ↦ **ke^(ax)**, k ∈ ℝ (démonstration : g = fe^(−ax) a une dérivée nulle donc est constante). Ne jamais oublier k ; a est le coefficient **dans l'exposant**.
- **Condition initiale (ordre 1)** : pour a ≠ 0, l'unique solution de y′ = ay valant y₀ en x₀ est x ↦ **y₀e^(a(x−x₀))**. Le sens de variation dépend du signe de **ak** : a < 0 avec k > 0 donne une décroissance.
- **y′ = ay + b (a ≠ 0)** : la fonction constante **−b/a** est solution ; toutes les solutions sont x ↦ **ke^(ax) − b/a**, et celle qui vaut y₀ en x₀ est x ↦ (y₀ + b/a)e^(a(x−x₀)) − b/a. Piège : c'est **−b/a**, jamais +b/a.
- **Modèle physique en trois temps** : traduire l'énoncé en y′ = ay + b, écrire ke^(ax) − b/a, fixer k avec la valeur en 0 ; si a < 0 la limite en +∞ est −b/a. Exemple du circuit L-r : i(t) = 0,1(1 − e^(−500t)) → E/r = 0,1 A (régime transitoire puis permanent).
- **Décroissance radioactive** : N′ = −λN et N(0) = N₀ donnent N(t) = **N₀e^(−λt)** ; la **demi-vie** vaut T₀.₅ = **(ln 2)/λ**, indépendante de N₀ (carbone 14 : T₀.₅ = 5730 ans ⟹ λ ≈ 1,21 × 10⁻⁴ ; 60 % restants ⟹ t ≈ 4223 ans). Loi de Newton : f′ = a(f − T) ⟹ f(t) = T + (f(0) − T)e^(at), qui **tend** vers T sans jamais l'atteindre.
- **y″ + ω²y = 0 (ω ≠ 0)** : les solutions sont x ↦ **A sin(ωx) + B cos(ωx)** ; deux conditions sont nécessaires, et f(0) = x₀, f′(0) = y₀ donnent l'unique f(x) = (y₀/ω)sin(ωx) + x₀cos(ωx). **ω est la racine** du coefficient de y (y″ + 9y = 0 ⟹ ω = 3). Seul le cas + ω²y est au programme.
- **Forme amplitude-phase** : A sin(ωx) + B cos(ωx) = **r cos(ωx − φ)** avec r = √(A² + B²), cos φ = B/r et sin φ = A/r. La **période 2π/ω** ne dépend que de l'équation, l'**amplitude r** que des conditions initiales.
- **Deux techniques de bac** : pour un second membre non nul, trouver une **solution particulière** g de la forme imposée, alors f est solution ⟺ f − g est solution de l'équation homogène (ex. y′ + 2y = x² ⟹ f(x) = ke^(−2x) + x²/2 − x/2 + 1/4) ; pour y″ = ay′ + b, poser **z = y′** pour se ramener à l'ordre 1, puis primitiver.
