# 📜 Résumé : Primitives

- **Définition et existence** : F est une primitive de f sur l'intervalle I si F est dérivable sur I et F′(x) = f(x) pour tout x de I ; toute fonction **continue** sur un intervalle y admet au moins une primitive (théorème admis) ; on valide toujours une primitive en la **dérivant**.
- **Famille des primitives et condition initiale** : deux primitives de f sur un intervalle I diffèrent d'une **constante** (leurs courbes se déduisent par translation verticale) ; pour x₀ ∈ I et y₀ réel, il existe une **unique** primitive telle que F(x₀) = y₀ — on écrit F + c puis on calcule c.
- **Signe de f et variations de F** : puisque F′ = f, le signe de f donne le sens de variation de toute primitive F — f > 0 sur un intervalle ⟹ F croissante, f < 0 ⟹ F décroissante, f qui s'annule en changeant de signe en x₀ ⟹ **extremum** de F en x₀ ; on lit les variations de F directement sur le tableau de signes de f.
- **Primitives usuelles** : xⁿ → x^(n+1)/(n+1) ; 1/xⁿ (n ≥ 2) → x^(−n+1)/(−n+1) ; √x → (2/3)x√x ; 1/√x → 2√x ; cos x → sin x ; sin x → −cos x ; cos(ωx + φ) → (1/ω)sin(ωx + φ) ; sin(ωx + φ) → −(1/ω)cos(ωx + φ) ; 1 + tan²x → tan x. Attention au signe de 1/x² (primitive −1/x) et au facteur 1/ω.
- **Linéarité** : F + G primitive de f + g, λF primitive de λf — on primitive terme à terme. Aucune formule pour un produit ou un quotient : F × G n'est pas une primitive de f × g.
- **Formes composées** : u′uⁿ → u^(n+1)/(n+1) ; u′v + v′u → u·v ; u′/uⁿ (u ≠ 0) → u^(−n+1)/(−n+1) ; (u′v − v′u)/v² (v ≠ 0) → u/v ; u′/√u (u > 0) → 2√u ; u′√u (u ≥ 0) → (2/3)u√u ; u′·ⁿ√(u^(1−n)) (u > 0) → n·ⁿ√u ; u′(w′∘u) → w∘u. Méthode : poser u, calculer u′, ajuster par une **constante** multiplicative.
- **Réécrire avant de primitiver** : décomposition d'une fraction rationnelle (f(x) = ax + b + c/(x − 2)²), linéarisation trigonométrique (sin²x = (1 − cos 2x)/2, sin³x = sin x(1 − cos²x)), passage par tan (tan²x = (1 + tan²x) − 1).
- **Pièges classiques** : le théorème « à une constante près » exige un **intervalle** ; x ↦ F(2x) n'est **pas** une primitive de x ↦ f(2x) (sa dérivée vaut 2f(2x)) — la bonne primitive est x ↦ F(2x)/2 ; on ne compense jamais un facteur manquant qui dépend de x.
- **Applications** : un taux instantané est une dérivée, donc la grandeur est une primitive — débit → quantité produite, accélération → vitesse → position ; chaque primitivation consomme une condition initiale (deux remontées = deux données).
