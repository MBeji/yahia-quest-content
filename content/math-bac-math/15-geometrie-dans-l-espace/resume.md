# 📜 Résumé : Géométrie dans l'espace

- **Repère et produit scalaire** : en repère orthonormé, u⃗(x, y, z).v⃗(x′, y′, z′) = xx′ + yy′ + zz′, ‖u⃗‖ = √(x² + y² + z²) et MM′ = √((x − x′)² + (y − y′)² + (z − z′)²). Sinon, AB⃗.AC⃗ = AB.AC.cos BAĈ. **Orthogonalité ⟺ produit scalaire nul.** Une droite est perpendiculaire à un plan quand son vecteur est orthogonal à **deux** vecteurs **non colinéaires** du plan. Sur un cube d'arête 1, le repère (A, AB⃗, AD⃗, AE⃗) est orthonormé direct et donne A(0,0,0), B(1,0,0), C(1,1,0), D(0,1,0), E(0,0,1), F(1,0,1), G(1,1,1), H(0,1,1).
- **Produit vectoriel** : u⃗∧v⃗ est **orthogonal à u⃗ et à v⃗**, (u⃗, v⃗, u⃗∧v⃗) est une base **directe**, et ‖AB⃗∧AC⃗‖ = AB.AC.sin BAĈ. Nul ⟺ vecteurs **colinéaires**. Antisymétrique : u⃗∧v⃗ = −(v⃗∧u⃗). Composantes pour u⃗(a, b, c) et v⃗(a′, b′, c′) :

$$ u⃗∧v⃗ = (bc′ − cb′ , ca′ − ac′ , ab′ − ba′) $$

- **Déterminant, aires, volumes** : (u⃗∧v⃗).w⃗ = (w⃗∧u⃗).v⃗ = (v⃗∧w⃗).u⃗ = det(u⃗, v⃗, w⃗) (permutation **circulaire**) ; nul ⟺ vecteurs **coplanaires**. Aire du parallélogramme ABCD = ‖AB⃗∧AD⃗‖ ; aire du triangle ABD = ½‖AB⃗∧AD⃗‖ ; volume du tétraèdre ABCD = (1/6)|(BC⃗∧BD⃗).BA⃗| ; volume du parallélépipède ABCDEFGH = |(AB⃗∧AD⃗).AE⃗|. Toujours une **valeur absolue**.
- **Équations** : une **droite** se paramètre — x = x₀ + αa, y = y₀ + αb, z = z₀ + αc. Un **plan** a une équation cartésienne ax + by + cz + d = 0, et **(a, b, c) est un vecteur normal** ; pour l'obtenir à partir de trois points, prendre n⃗ = AB⃗∧AC⃗ puis fixer d avec un point. Une **sphère** de centre (x₀, y₀, z₀) et de rayon R : (x − x₀)² + (y − y₀)² + (z − z₀)² = R² — une équation développée se réduit en **complétant les trois carrés**. La sphère **circonscrite** à un solide passe par tous ses sommets : son centre est le point **équidistant des sommets**, obtenu en écrivant les égalités de distances ΩA = ΩB = … (les carrés se simplifient, il reste un système linéaire).
- **Distances** : d(A, P) = |ax₀ + by₀ + cz₀ + d| / √(a² + b² + c²) pour un plan ; d(M, D) = ‖MA⃗∧u⃗‖ / ‖u⃗‖ pour une droite (A ∈ D, u⃗ directeur).
- **Sphère et plan** : avec h = d(centre, P) — intersection **vide** si h > R, **tangente** au seul point H si h = R, **cercle de centre H et de rayon √(R² − h²)** si h < R. Le plan tangent en A ∈ S est le plan de vecteur normal **IA⃗** passant par A.
- **Positions relatives** : deux droites (A, u⃗) et (B, v⃗) sont **coplanaires ⟺ det(AB⃗, u⃗, v⃗) = 0** — alors parallèles si u⃗ et v⃗ sont colinéaires, sécantes sinon. Sinon elles ne sont **ni parallèles ni sécantes**. « Non parallèles » n'implique jamais « sécantes » dans l'espace : résoudre les **trois** lignes du système.
- **Translation t_u⃗** : MM′⃗ = u⃗ ; bijective, de réciproque t_(−u⃗) ; caractérisée par **M′N′⃗ = MN⃗**. Conserve distances, produit scalaire, parallélisme, orthogonalité, milieux. Image d'une droite : une droite **parallèle** ; d'un plan : un plan **parallèle** ; d'une sphère : une sphère de **même rayon**. Analytiquement x′ = x + a, y′ = y + b, z′ = z + c.
- **Homothétie h\_(I,k)** : IM′⃗ = k IM⃗ ; bijective, de réciproque h_(I, 1/k) ; caractérisée par **M′N′⃗ = k MN⃗**, donc M′N′ = |k| MN. Longueurs ×|k|, aires ×k², **volumes ×|k|³**. Image d'une droite ou d'un plan : parallèle à l'original ; d'une sphère de rayon R : une sphère de rayon **|k|R** ; conserve le **contact**. Analytiquement x′ = kx + (1 − k)a, y′ = ky + (1 − k)b, z′ = kz + (1 − k)c ; réciproquement x′ = kx + α, … est l'homothétie de rapport k et de centre (α/(1 − k), β/(1 − k), δ/(1 − k)).
- **Méthode d'image d'une surface** (translation comme homothétie) : exprimer les **anciennes** coordonnées en fonction des **nouvelles**, puis substituer dans l'équation. Et le réflexe de contrôle du chapitre : **un produit vectoriel se vérifie par deux produits scalaires nuls, un point annoncé sur un plan se réinjecte dans son équation, une distance se recoupe par le projeté orthogonal.**
