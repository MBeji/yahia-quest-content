# 📜 Résumé : Coniques

- **Une seule définition** : donnés un foyer F, une directrice D (avec F ∉ D) et un réel e > 0, la conique est l'ensemble des M tels que **MF = e·MH**, H étant le projeté orthogonal de M sur D. Le genre ne dépend que de e : **e = 1 ⟹ parabole**, **e > 1 ⟹ hyperbole**, **0 < e < 1 ⟹ ellipse**. L'axe focal est la perpendiculaire à D passant par F.
- **Parabole** : paramètre p = FK (K projeté de F sur D), sommet S = milieu de [FK], axe focal = axe de symétrie. Équation réduite **y² = 2px**, foyer **F(p/2, 0)**, directrice **x = −p/2** ; par symétrie y² = −2px, x² = 2py, x² = −2py. Pas de centre.
- **Hyperbole** : équation réduite **x²/a² − y²/b² = 1** avec **b² = c² − a²** (c le plus grand), centre O, sommets (±a, 0), foyers **(±c, 0)** avec c = √(a² + b²), directrices **x = ±a²/c**, excentricité **e = c/a**, **asymptotes y = ±(b/a)x**. Si le signe + porte sur y², tout bascule sur (Oy). **Équilatère** ⟺ asymptotes perpendiculaires ⟺ a = b ⟺ **e = √2** ; rapportée à ses asymptotes, elle s'écrit **XY = k**.
- **Ellipse** : équation réduite **x²/a² + y²/b² = 1** avec **b² = a² − c²**, centre O, sommets principaux et secondaires. Si **a > b** : foyers (±c, 0), directrices x = ±a²/c, **e = c/a**. Si **a < b** : foyers (0, ±c), directrices y = ±b²/c, **e = c/b** — l'excentricité se divise toujours par le **demi-grand axe**. Paramétrage **M(a cos θ, b sin θ)**.
- **Tangente en M₀(x₀, y₀) de la conique — règle du dédoublement** : x² → x₀x, y² → y₀y, 2x → x + x₀, 2y → y + y₀. D'où **x₀x/a² ± y₀y/b² = 1** (ellipse +, hyperbole −), **y₀y = p(x + x₀)** et **x₀x = p(y + y₀)** pour les paraboles. Tangentes aux sommets : x = 0 (sommet de parabole), x = a, y = b. Valable seulement si **M₀ est sur la conique** ; depuis un point extérieur, on passe par un discriminant nul.
- **Équation non réduite** : **compléter les carrés** puis translater l'origine en O′ ⟹ équation réduite en (X, Y) ; les éléments se relisent ensuite dans le repère de départ. Cas dégénérés à ne pas oublier : un **point unique** ou l'**ensemble vide**. Classification de **Ax² + By² + Cx + Dy + E = 0** : **AB = 0** ⟹ parabole / droites parallèles / une droite / vide ; **AB < 0** ⟹ hyperbole / deux droites sécantes ; **AB > 0** ⟹ ellipse / cercle / un point / vide.
- **Méthode** : (1) genre par le signe de AB ou par e ; (2) terme en xy ⟹ utiliser la similitude fournie (elle conserve genre et excentricité) ; (3) compléter les carrés pour trouver O′ ; (4) lire a et b, en déduire c ; (5) **vérifier** en réinjectant un sommet dans l'équation de départ et en contrôlant MF/MH = e.
