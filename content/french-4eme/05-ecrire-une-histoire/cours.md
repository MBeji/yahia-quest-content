# 🧙 J'écris une histoire

> 💡 « Il était une fois… Trois mots, et tout un monde s'ouvre. À toi d'écrire la suite. »

## ⚡ Mon mini-projet

Dernier mini-projet : *j'écris une histoire qu'on raconte beaucoup chez nous*. C'est un **conte** — un texte **narratif**, comme *Pinocchio* ou *Le Chat Botté*, mais celui-ci vient de chez nous.

Mon sous-thème : **« Conte-nous une histoire, dis ! »**

## 📖 Les trois moments du conte

| Moment           | Ce que j'écris                                        | Exemple                                   |
| ---------------- | ----------------------------------------------------- | ----------------------------------------- |
| **le début**     | qui, où, quand — la situation de départ               | *Il était une fois un berger très pauvre.* |
| **les événements** | ce qui arrive, un problème, des essais              | *Un jour, son troupeau disparaît.*        |
| **la fin**       | comment tout se termine                               | *Enfin, il retrouve ses moutons.*         |

Les mots qui font avancer l'histoire : **il était une fois**, **un jour**, **soudain**, **alors**, **enfin**.

> 🗝️ Un conte se raconte **dans l'ordre**. Si je mélange les événements, le lecteur se perd.

## 🎭 Les personnages du conte

Dans un conte, il y a souvent un **héros**, un **adversaire** et un **aide**.

*Le berger* (héros) · *le voleur* (adversaire) · *le vieux sage* (aide).

Je peux **porter un jugement** sur eux : *le berger est courageux*, *le voleur est méchant*.

## 🔮 Le féminin des noms

Beaucoup de noms ont une forme **masculine** et une forme **féminine**.

| Règle                  | Masculin      | Féminin         |
| ---------------------- | ------------- | --------------- |
| j'ajoute **-e**        | un ami        | une amie        |
| j'ajoute **-e**        | un marchand   | une marchande   |
| **-ien → -ienne**      | un magicien   | une magicienne  |
| **-er → -ère**         | un berger     | une bergère     |
| **-eur → -euse**       | un voleur     | une voleuse     |
| mot différent          | un roi        | une reine       |
| mot différent          | un frère      | une sœur        |

> ⚠️ Le piège : certains féminins **doublent la consonne** avant le **-e** : *un chien → une chienne*, *un paysan → une paysanne*.

## 🧩 Je reprends les types et les formes de phrases

Dans mon conte, j'utilise les **quatre types** vus en unité 1 :

- **déclaratif** : *Le berger part au lever du soleil.*
- **interrogatif** : *Où sont mes moutons ?*
- **exclamatif** : *Quelle chance !*
- **impératif** : *Suis ce chemin.*

Et les deux **formes** : *Le voleur est loin.* / *Le voleur **n'**est **pas** loin.*

## 🧮 Je conjugue **être**, **avoir**, **aller** et **partir**

| aller                | partir               |
| -------------------- | -------------------- |
| je **vais**          | je **pars**          |
| tu **vas**           | tu **pars**          |
| il / elle **va**     | il / elle **part**   |
| nous **allons**      | nous **partons**     |
| vous **allez**       | vous **partez**      |
| ils / elles **vont** | ils / elles **partent** |

Et je garde **être** (je suis, tu es, il est, nous sommes, vous êtes, ils sont) et **avoir** (j'ai, tu as, il a, nous avons, vous avez, ils ont).

> ⚠️ Le piège : **il part**, sans t ajouté — comme *il prend*. Et au pluriel, on entend le **t** : *ils partent*.

## ✍️ Je légende un dessin, j'écris la fin

- **Légender un dessin**, c'est écrire sous l'image une phrase courte qui dit ce qu'on y voit : *Le berger cherche son troupeau dans la montagne.*
- **Écrire la fin d'une histoire**, c'est résoudre le problème du héros — en une ou deux phrases, avec **enfin** ou **depuis ce jour**.

## ✏️ J'écris les majuscules

Cette unité, j'apprends cinq majuscules : **H · T · U · V · Z**.

Je les utilise pour les noms propres : *Hammamet*, *Tunis*, *Utique*, *Vienne*, *Zarzis*.
