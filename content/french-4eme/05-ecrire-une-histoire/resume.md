# 📜 Résumé : J'écris une histoire

- **Mon mini-projet** : écrire une histoire qu'on raconte beaucoup chez nous — un **conte**, texte narratif, sous-thème « Conte-nous une histoire, dis ! ».
- **Les trois moments** : le **début** (qui, où, quand), les **événements** (le problème), la **fin** (comment cela se termine).
- **Les mots du conte** : il était une fois, un jour, soudain, alors, enfin.
- **Les personnages** : un **héros**, un **adversaire**, un **aide** — et je peux porter un jugement sur eux.
- **Le féminin des noms** : + e (un ami / une amie), -ien → -ienne (magicien / magicienne), -er → -ère (berger / bergère), -eur → -euse (voleur / voleuse), ou un mot différent (roi / reine, frère / sœur).
- **Le piège** : certains féminins doublent la consonne — un chien / une chienne, un paysan / une paysanne.
- **Les quatre types de phrases** (repris) : déclaratif, interrogatif, exclamatif, impératif ; et les deux **formes**, affirmative et négative.
- **aller au présent** : je vais, tu vas, il va, nous allons, vous allez, ils vont.
- **partir au présent** : je pars, tu pars, **il part**, nous partons, vous partez, ils partent.
- **Légender un dessin** : une phrase courte qui dit ce qu'on voit. **Écrire la fin** : résoudre le problème du héros.
- **Les majuscules** : H, T, U, V, Z.
