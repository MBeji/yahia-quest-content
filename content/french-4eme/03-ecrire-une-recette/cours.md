# 🍽️ J'écris une recette

> 💡 « Une recette réussie, c'est d'abord une recette bien écrite : les bons ingrédients, dans le bon ordre. »

## ⚡ Mon mini-projet

Troisième mini-projet : *j'écris la recette d'un plat ou d'un gâteau de chez nous*. Ce n'est plus un récit : c'est un texte **prescriptif**, un texte qui **dit ce qu'il faut faire**.

Mes deux moments : **« Un cœur qui bat ! »** (la santé, l'hygiène) et **« Bon appétit ! »** (l'alimentation, les repas).

## 📋 Les trois parties d'une recette

| Partie            | Ce que j'écris                                  |
| ----------------- | ----------------------------------------------- |
| **le titre**      | le nom du plat — *La salade de fruits*          |
| **les ingrédients** | la liste, avec les quantités — *3 oranges, 2 pommes, 1 banane, du jus de citron* |
| **la préparation** | les étapes, dans l'ordre                       |

Pour les étapes, j'écris les verbes à l'**infinitif** : *Laver les fruits. Éplucher les oranges. Couper les pommes en morceaux. Mélanger le tout.*

## 🔗 Les mots qui rangent les étapes

Pour que le lecteur ne se trompe pas, j'utilise des mots d'ordre :

**D'abord** … **ensuite** … **puis** … **enfin**.

*D'abord, laver les fruits. Ensuite, les éplucher. Puis les couper. Enfin, ajouter le jus de citron.*

> 🗝️ Une recette dans le désordre ne marche pas. L'**ordre des étapes** est aussi important que les ingrédients.

## 🛡️ La phrase minimale et la phrase enrichie

La **phrase minimale**, c'est la phrase la plus courte qui garde un sens : un **groupe sujet** + un **groupe verbal**.

- *Maman prépare.* → phrase minimale

Je peux l'**enrichir** en ajoutant des précisions :

| Ce que j'ajoute        | Question       | Phrase enrichie                                       |
| ---------------------- | -------------- | ----------------------------------------------------- |
| un **complément de lieu** | où ?        | Maman prépare **dans la cuisine**.                    |
| une **précision de qualité** | comment ? | Maman prépare **un délicieux gâteau**.                |

*Maman prépare un délicieux gâteau dans la cuisine.* → phrase enrichie.

Je peux aussi faire l'inverse : **réduire** une phrase enrichie pour retrouver sa phrase minimale.

> ⚠️ Enrichir n'est pas allonger n'importe comment : chaque mot ajouté doit apporter une **information** utile.

## 🔮 Je choisis le bon déterminant

Devant le nom, le déterminant change avec le genre et le nombre :

| | masculin | féminin | pluriel |
| --- | --- | --- | --- |
| je désigne précisément | **le** gâteau | **la** farine | **les** œufs |
| je désigne en général | **un** gâteau | **une** cuillère | **des** amandes |

Pour une quantité que l'on ne compte pas, j'emploie **du**, **de la**, **de l'** : *du sucre*, *de la farine*, *de l'huile*.

## 🧮 Je conjugue les verbes en **-er** et le verbe **faire**

| préparer (verbe en -er)   | faire                |
| ------------------------- | -------------------- |
| je **prépare**            | je **fais**          |
| tu **prépares**           | tu **fais**          |
| il / elle **prépare**     | il / elle **fait**   |
| nous **préparons**        | nous **faisons**     |
| vous **préparez**         | vous **faites**      |
| ils / elles **préparent** | ils / elles **font** |

> ⚠️ Le piège : on écrit **vous faites**, jamais *vous faisez*. Et **nous faisons** se prononce « fe-sons ».

## 🔤 La lettre **ç**

La lettre **c** se lit **s** devant **e** et **i** : *la cerise*, *le citron*.
Devant **a**, **o** et **u**, elle se lit **k** : *le café*, *le cochon*, *la cuisine*.

Alors, pour obtenir le son **s** devant **a**, **o** ou **u**, j'ajoute une **cédille** : **ç**.

- un gar**ç**on · une le**ç**on · nous commen**ç**ons · fran**ç**ais · un gla**ç**on

> 🗝️ Pas de cédille devant **e** et **i** : on n'écrit jamais *çe* ni *çi* — le c seul suffit déjà.

## ✏️ J'écris les majuscules

Cette unité, j'apprends trois majuscules : **I · J · F**.

Je les utilise pour les noms propres : *Ines*, *Jendouba*, *Fatma*.
