# 💬 Je fais parler des personnages

> 💡 « Un bon récit ne dit pas seulement ce qui se passe : il laisse les personnages parler. »

## ⚡ Mon mini-projet

Deuxième mini-projet : *je fais parler des personnages en racontant un événement*. C'est encore un texte **narratif**, mais cette fois j'ajoute les **paroles**.

Mes deux moments : **« Sois mon ami ! »** (l'amitié, le quartier) et **« Tends-moi la main ! »** (l'entraide, aider les autres).

## 🗣️ Comment j'écris un dialogue

Quand un personnage parle, j'ouvre une nouvelle ligne et je mets un **tiret** :

> — Bonjour Nadia, dit Karim.
> — Bonjour ! Tu viens jouer avec nous ? répond Nadia.
> — Oui, avec plaisir, ajoute Karim.

Je choisis un **verbe de parole** : *dire*, *demander*, *répondre*, *ajouter*, *crier*, *murmurer*.

> 🗝️ Un dialogue à deux, c'est un tiret **à chaque fois** que l'on change de personnage.

## 🛡️ Les deux grands constituants de la phrase

Une phrase se coupe en **deux morceaux** :

- le **groupe sujet** : de qui ou de quoi on parle → *Nadia* / *Le petit écureuil*
- le **groupe verbal** : ce qu'il fait → *joue dans la cour* / *grimpe à l'arbre*

| Groupe sujet        | Groupe verbal            |
| ------------------- | ------------------------ |
| Nadia               | joue dans la cour.       |
| Le petit écureuil   | grimpe à l'arbre.        |
| Mes amis            | m'aident à porter le sac.|

Pour trouver le sujet, je demande **qui est-ce qui ?** : *Qui est-ce qui joue dans la cour ?* → **Nadia**.

## 🔮 Le nom et le déterminant

Le **nom** désigne une personne, un animal, une chose ou un lieu : *ami*, *écureuil*, *cartable*, *quartier*.

Devant le nom, il y a presque toujours un **déterminant** : **le, la, les, un, une, des, mon, ma, mes, ce, cette**.

| Déterminant | Nom       | Ensemble       |
| ----------- | --------- | -------------- |
| le          | quartier  | le quartier    |
| une         | amie      | une amie       |
| mes         | voisins   | mes voisins    |
| cette       | main      | cette main     |

> ⚠️ Le déterminant s'accorde avec le nom : *un ami* / *une amie*, *le voisin* / *les voisins*. On n'écrit jamais *une ami* ni *le voisins*.

## 🧮 Je conjugue les verbes en **-er** et le verbe **aller**

Les verbes en **-er** (jouer, aider, parler, chanter, donner) se conjuguent tous pareil au présent.

| jouer                | aller                |
| -------------------- | -------------------- |
| je **joue**          | je **vais**          |
| tu **joues**         | tu **vas**           |
| il / elle **joue**   | il / elle **va**     |
| nous **jouons**      | nous **allons**      |
| vous **jouez**       | vous **allez**       |
| ils / elles **jouent** | ils / elles **vont** |

> ⚠️ Le piège : **je joue**, **il joue** et **ils jouent** se prononcent de la même façon ! Je regarde le sujet pour choisir la bonne terminaison : **-e** pour je, il, elle ; **-ent** pour ils, elles.

**aller** ressemble à un verbe en -er… mais il ne se conjugue pas comme lui : *je vais*, jamais *je alle*.

## 🔤 J'étudie les graphies

- **euil** : un fauteuil, un écureuil, le seuil
- **ouil / ouille** : la grenouille, une nouille, le fenouil
- **gn** : la montagne, un agneau, la campagne, se peigner
- **ph** : une photo, un éléphant, la pharmacie, le téléphone

> 🗝️ **ph** se lit toujours **f** : un éléphant se lit « élé-fan ».

## ✏️ J'écris les majuscules

Cette unité, j'apprends quatre majuscules : **G · P · E · D**.

Je les utilise pour les noms propres : *Gabès*, *Paris*, *Emna*, *Douz*.
