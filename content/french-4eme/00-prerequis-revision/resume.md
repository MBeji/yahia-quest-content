# 📜 Résumé : Je révise mes acquis

- **Je salue** : bonjour, bonsoir, au revoir, merci, s'il te plaît, pardon.
- **Je me présente** : je m'appelle…, j'ai … ans, j'habite à… ; je demande comment t'appelles-tu ? quel âge as-tu ? où habites-tu ?
- **Ma famille** : le père, la mère, le frère, la sœur, le grand-père, la grand-mère, l'oncle, la tante.
- **Ma maison** : le salon, la cuisine, la chambre, la salle de bains, le jardin.
- **Mon école** : la classe, le maître, la maîtresse, la cour ; le livre, le cahier, le stylo, le crayon, la gomme, la règle.
- **Mon corps** : la tête, les yeux, le nez, la bouche, les oreilles, les bras, les mains, les jambes, les pieds.
- **Les jours** : lundi, mardi, mercredi, jeudi, vendredi, samedi, dimanche.
- **Je compte** jusqu'à 30 : un, deux, trois… dix, onze, douze, quinze, vingt, trente.
- **La phrase** : elle commence par une **majuscule** et se termine par un **point**.
- **Mes sons** : on (bonjour), an (enfant), ou (poule), ch (chat).
