# 📜 Résumé : Le choix d'investissement

- **Investissement** : employer un capital pour un profit sur plusieurs années ; dépense certaine contre recettes espérées. Rentable si les recettes futures, nouvelles dépenses déduites, dépassent le coût (en comparant à la même date). Coût initial : prix + installation, hors taxe.
- **Flux net de trésorerie (CAF)** : chiffre d'affaires − dépenses − dotations = résultat avant impôts ; − impôt = résultat net ; + dotations = flux net. Dotation linéaire = coût ÷ durée de vie ; une dotation plus élevée réduit l'impôt, le flux gagne dotation en plus × taux d'impôt.
- **Actualisation** : valeur actuelle = somme × (1 + i)⁻ⁿ ; une somme lointaine vaut moins.
- **VAN** = Σ flux × (1 + i)⁻ᵗ + valeur résiduelle × (1 + i)⁻ᵖ − I₀. VAN > 0 : rentable ; VAN = 0 : limite, le projet rapporte juste le taux i ; VAN < 0 : non rentable ; entre deux projets, la VAN la plus élevée.
- **Flux constant** : flux × [1 − (1 + i)⁻ᵖ] ÷ i − I₀ ; sinon, actualiser année par année.
- **Valeur résiduelle** = VCN = coût initial − amortissements déjà pratiqués ; ajoutée au dernier flux.
- **DRCI constant** : coût ÷ cash-flow, sans actualisation ; partie décimale × 12 = mois.
- **DRCI variable** : P ans + (I₀ − cumul de P) × 360 ÷ flux de l'année (P + 1) (en jours).
- **Critères** : DRCI > norme, projet rejeté ; sélection du délai le plus court. DRCI et VAN peuvent diverger : le délai ignore l'actualisation et les flux après récupération.
