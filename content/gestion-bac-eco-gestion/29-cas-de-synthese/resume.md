# 📜 Résumé : Les cas de synthèse

- **Méthode** : lire tout l'énoncé et les annexes, relever les données (unité, hors taxe ou TTC), associer chaque question à un outil par son mot-clé, calculer en gardant les résultats intermédiaires, puis commenter. Exploitation et investissement se calculent en général hors taxe ; un budget de trésorerie en TTC.
- **Plein emploi (ch. 10)** : une égalité par atelier, temps unitaire × quantité = capacité, dans la même unité ; capacité réduite = capacité × pourcentage restant ; on contrôle dans les deux égalités.
- **Coûts et écarts (ch. 08 et 11)** : coût de revient = coût de production + distribution ; résultat de la commande = quantité × (prix − coût de revient). Écart = réel − préétabli ; écart sur coût à la quantité réelle, écart sur quantité au coût préétabli.
- **Marché (ch. 13)** : part de marché = CA entreprise ÷ CA secteur ; croissance = augmentation ÷ année précédente ; CA prévu = CA × (1 + taux) ; ventes moins rapides que le secteur : part en baisse.
- **Rentabilité (ch. 09)** : marge unitaire = prix − coût variable ; résultat = marge totale − charges fixes ; comparaison par le taux de marge sur coût variable ; entre deux hypothèses, le résultat le plus élevé, publicité ajoutée au fixe.
- **Investissement (ch. 21)** : CAF = résultat avant impôt × (1 − taux) + dotation ; VAN = CAF × facteur − coût initial hors taxe ; VAN nulle : le projet rapporte juste le taux d'actualisation ; entre deux projets, la VAN la plus élevée.
- **Emprunt (ch. 22)** : intérêt = capital restant dû × taux ; amortissement = annuité − intérêt ; annuités constantes : a = C × i ÷ [1 − (1 + i)⁻ⁿ] ; amortissements constants : C ÷ n ; comparer par la valeur actuelle.
- **Trésorerie (ch. 28)** : TVA = TTC × 18 ÷ 118 ; TVA à décaisser = collectée − déductible − crédit ; solde = encaissements − décaissements ; un solde négatif se commente et se corrige (délais, escompte, découvert, paiement étalé).
