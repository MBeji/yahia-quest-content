# 📜 Résumé : Le tableau de financement

- **Définition** : flux financiers d'un exercice, établis en comparant les bilans comptables avant répartition du 31/12/N-1 et du 31/12/N. 1re partie : haut du bilan ; 2e partie : bas du bilan.
- **Ressources stables nouvelles** : CAF, augmentation de capital, nouveaux emprunts, cessions d'immobilisations. **Emplois stables nouveaux** : acquisitions, remboursements d'emprunts, dividendes, nouveaux prêts.
- **ΔFDR = ressources stables nouvelles − emplois stables nouveaux** : positif = ressource nette, négatif = emploi net ; FDR(N) = FDR(N-1) + ΔFDR.
- **Acquisitions** = valeur brute N − valeur brute N-1 + valeur brute des sorties ; toujours en valeurs brutes ; emprunts nouveaux = dettes financières N − N-1 + remboursements.
- **2e partie** : besoin = actif courant en hausse ou passif courant en baisse ; dégagement = l'inverse ; solde A = dégagements − besoins = −ΔBFR.
- **Lien** : ΔFDR = ΔBFR + ΔTN ; A + B = −ΔFDR ; les deux parties donnent le même solde, de signes opposés.
- **Commenter** : sens de ΔFDR, part de la CAF dans les ressources, ressources externes, conclusion.
