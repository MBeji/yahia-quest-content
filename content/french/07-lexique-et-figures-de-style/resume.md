# 📜 Résumé : Le lexique et les figures de style

- **Formation des mots** : préfixe (avant : _in-_ négation, _dé-_ contraire, _sur-_ excès) + radical (sens de base) + suffixe (après : _-able_ « qui peut être », _-ette_ diminutif). Même radical = même **famille de mots**.
- **Polysémie** : un mot a plusieurs sens ; le **contexte** choisit (_gâter_ le temps, un enfant, des fruits). Le synonyme suit le sens choisi. Les **homonymes** (_verre/vers/vert_) sont des mots différents qui se prononcent pareil.
- **Sens propre / sens figuré** : ce que dit le mot arrive réellement ← sens propre ; c'est une image ← sens figuré (_la jalousie dévorait son cœur_).
- **Champ lexical** : tous les mots (noms, verbes, adjectifs) liés à un même thème ; le champ dominant donne le thème du texte.
- **Synonymes** (sens voisin, pas toujours interchangeables : on _exerce_ un métier, on _parle_ une langue), **antonymes** (sens contraire), **paronymes** (forme proche, sens différent : _compréhensif/compréhensible_, _éruption/irruption_).
- **Registres** : familier (proches, oral : _boulot_, _j'sais pas_) / courant (école, écrit : _travail_, _je ne sais pas_) — on change les mots et la construction.
- **Expressions figées** : sens global, compris en bloc grâce au contexte, sans changer un seul mot (_une tête de mule_, _mener en bateau_).
- **Comparaison** : comparé + outil (_comme, tel, semblable à…_) + comparant (+ point commun). **Métaphore** : comparaison abrégée, sans outil (_ce garçon est un vrai singe_).
- **Personnification** : un trait réservé à l'homme prêté à un non-humain (_l'horloge toussait_) ; on nomme, on cite, on explique l'effet.
- **Méthode** : champ lexical → sens figuré → figures → effet, chaque étape conclue par une interprétation.
