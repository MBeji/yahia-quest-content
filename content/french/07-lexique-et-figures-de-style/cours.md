# ⚔️ Le lexique et les figures de style

> 💡 « Les mots sont les armes du guerrier de l'écriture : en connaître la formation, le sens et les ornements, c'est forger une lame invincible. »

## 🏰 La formation des mots

Tu ne connais pas le mot _impraticable_, et pourtant tu le comprends. Découpe-le : _im-_,
_pratic-_, _-able_. Trois morceaux, et chacun dit quelque chose.

Comment un mot inconnu peut-il être compris sans dictionnaire ? Et de quoi se compose-t-il
exactement ?

::: definition
Un mot se compose souvent de trois éléments : le **radical** porte le sens de base, le
**préfixe** se place **avant** pour le modifier, le **suffixe** se place **après** pour changer
la catégorie ou le sens.
:::

| Élément     | Définition                                                              | Exemple                                          |
| ----------- | ----------------------------------------------------------------------- | ------------------------------------------------ |
| **Radical** | La partie centrale qui porte le sens de base                            | _port_ dans _porter_, _transport_, _apport_      |
| **Préfixe** | Élément placé **avant** le radical pour modifier le sens                | _im-_ dans _impossible_ ; _re-_ dans _relire_    |
| **Suffixe** | Élément placé **après** le radical pour changer la catégorie ou le sens | _-eur_ dans _nageur_ ; _-ment_ dans _rapidement_ |

::: exemple décoder un mot inconnu en trois temps

1. **Isole le radical** : _pratic-_ ← tu le reconnais dans _pratique_, _praticien_ : il s'agit
   de ce qu'on peut faire.
2. **Lis le préfixe** : _im-_ est **privatif**, comme dans _impossible_ ← il nie.
3. **Lis le suffixe** : _-able_ marque la **possibilité**, comme dans _lisible_ ← donc
   _impraticable_ = « qu'on ne peut pas pratiquer », **parce que** le préfixe nie la possibilité
   qu'annonce le suffixe.

:::

| Préfixes courants       | Sens               | Exemples                              |
| ----------------------- | ------------------ | ------------------------------------- |
| _in- / im- / il- / ir-_ | privatif           | inégal, impossible, illisible, irréel |
| _re- / ré-_             | répétition, retour | relire, réorganiser                   |
| _pré-_                  | avant              | prévoir, préhistoire                  |
| _sur-_                  | au-dessus, excès   | surpasser, surévaluer                 |
| _sous-_                 | insuffisance       | sous-estimer, souterrain              |

| Suffixes courants | Ce qu'ils forment  | Exemples               |
| ----------------- | ------------------ | ---------------------- |
| _-eur / -rice_    | nom d'agent        | nageur, actrice        |
| _-tion / -sion_   | nom d'action       | construction, décision |
| _-ment_           | adverbe de manière | rapidement, doucement  |
| _-able / -ible_   | possibilité        | lisible, aimable       |

> 🗡️ La **famille de mots** regroupe tous les mots qui partagent le même radical : _terre_,
> _enterrer_, _terrestre_, _territoire_, _déterrer_ forment une famille.

::: piege l'erreur classique

Prendre une syllabe pour un préfixe. Dans _impôt_, _im-_ n'est pas privatif : le mot ne se
découpe pas ainsi. Le test : le radical restant doit exister par lui-même — _possible_ existe,
_pôt_ n'existe pas.

:::

::: verifie
Que signifie _indéchiffrable_, et comment le sais-tu ?

---

« Qu'on ne peut pas déchiffrer ». Radical _chiffr-_ ; préfixe _dé-_ (défaire) puis _in-_
(privatif) ; suffixe _-able_ (possibilité). Trois éléments lus dans l'ordre donnent le sens sans
dictionnaire.
:::

::: retenir
Un mot se découpe en radical, préfixe et suffixe — et les lire dans l'ordre suffit souvent à
comprendre un mot jamais rencontré.
:::

## ⚡ Champ lexical et champ sémantique

Deux notions voisines par le nom, opposées par le contenu. Le **champ lexical** part d'un thème
et rassemble des mots. Le **champ sémantique** part d'un mot et rassemble des sens.

L'un va du thème vers les mots, l'autre du mot vers les sens. Comment ne plus les confondre ?

::: definition
Le **champ lexical** d'un thème regroupe tous les **mots** qui s'y rapportent, de catégories
grammaticales variées.
Le **champ sémantique** d'un mot regroupe tous les **sens** que ce mot peut prendre selon le
contexte.
:::

| Notion           | Point de départ | Ce qu'on rassemble | Exemple                                                      |
| ---------------- | --------------- | ------------------ | ------------------------------------------------------------ |
| Champ lexical    | un **thème**    | des **mots**       | guerre : combat, ennemi, bataille, vaincre, assaut, victoire |
| Champ sémantique | un **mot**      | des **sens**       | feu : incendie · passion · signal lumineux                   |

::: exemple construire l'un puis l'autre

1. **Champ lexical de la mer** : vague, marin, port, naviguer, salé, tempête… ← des mots
   différents autour d'**un thème**.
2. **Champ sémantique de « glace »** : eau gelée · miroir · dessert · froideur d'un regard ← un
   **seul mot**, plusieurs sens.
3. **Le test** : si tu écris une liste de mots **différents**, c'est un champ lexical. Si tu
   écris plusieurs fois **le même mot** avec des sens différents, c'est un champ sémantique.

:::

> 💡 Pour analyser un texte, repérer le **champ lexical dominant** permet d'identifier le thème
> principal — et un changement de champ lexical au milieu d'un texte signale souvent un
> changement de sujet ou de ton.

::: piege l'erreur classique

Appeler « champ sémantique » une liste de synonymes. Les synonymes sont des **mots différents de
sens voisin** ; le champ sémantique est **un seul mot aux sens multiples**.

:::

::: verifie
_« Le feu de la bataille, le feu du canon, le feu dans ses yeux »_ — champ lexical ou sémantique ?

---

**Champ sémantique** du mot _feu_ : un seul mot employé trois fois avec trois valeurs — le
combat, l'arme, la passion. Un champ lexical aurait aligné des mots différents.
:::

::: retenir
Le champ lexical part d'un thème et donne des mots ; le champ sémantique part d'un mot et donne
des sens.
:::

## 🛡️ Synonymes, antonymes, homonymes, paronymes

Quatre relations entre les mots, et deux d'entre elles se ressemblent dangereusement :
_homonymes_ et _paronymes_. Un candidat sur deux les échange le jour de l'examen.

Quelle est la frontière exacte entre les quatre ?

::: definition
**Synonymes** : sens voisin. **Antonymes** : sens contraire. **Homonymes** : prononciation
**identique**, sens différents. **Paronymes** : forme **proche mais non identique**, sens
différents.
:::

| Relation      | Définition                                             | Exemple                                                                  |
| ------------- | ------------------------------------------------------ | ------------------------------------------------------------------------ |
| **Synonymes** | Mots de sens voisin ou équivalent                      | _courageux_ / _vaillant_ / _intrépide_                                   |
| **Antonymes** | Mots de sens contraire                                 | _victoire_ / _défaite_ ; _fort_ / _faible_                               |
| **Homonymes** | Mots de prononciation identique mais de sens différent | _verre_ (récipient) / _vers_ (poème) / _vert_ (couleur) / _ver_ (animal) |
| **Paronymes** | Mots de forme proche mais de sens différent            | _éruption_ / _irruption_ ; _collision_ / _collusion_                     |

::: exemple séparer homonymes et paronymes en une question

1. **Prononce les deux mots à voix haute.** _verre_ et _vert_ se disent **exactement** pareil ←
   **homonymes**.
2. _éruption_ et _irruption_ se ressemblent mais ne se prononcent **pas** pareil ←
   **paronymes**.
3. **D'où la conséquence pratique** : l'homonyme se corrige à l'écrit (il s'entend juste, il
   s'écrit faux), le paronyme se corrige au sens — **parce que** celui qui dit _irruption_ pour
   _éruption_ se trompe de mot, pas d'orthographe.

:::

> 🗡️ Attention aux paronymes : confondre _accepter_ et _excepter_, ou _éminent_ et _imminent_,
> est une erreur fréquente à l'examen — et elle change complètement le sens de la phrase.

::: piege l'erreur classique

_« Le volcan est entré en irruption. »_ Le mot juste est **éruption** (sortie de matière) ;
_irruption_ signifie « entrée brusque ». Le paronyme est la faute la plus coûteuse, parce qu'elle
n'a pas l'air d'une faute.

:::

::: verifie
_« Le ministre a été mis au courant de sa nomination **éminente** »_ — quel mot fallait-il ?

---

**Imminente** : ce qui va se produire très bientôt. _Éminent_ signifie « remarquable, supérieur »
— les deux mots sont **paronymes**, proches de forme et sans rapport de sens.
:::

::: retenir
Prononciation identique ← homonymes ; forme seulement voisine ← paronymes — et les paronymes
sont les plus coûteux, car ils changent le sens sans alerter l'œil.
:::

## 🔮 Sens propre et sens figuré, dénotation et connotation

_« Les flammes dévoraient la forêt. »_ · _« La jalousie dévorait son cœur. »_ Le même verbe, et
dans le second cas rien n'est mangé.

Le dictionnaire ne donne pourtant qu'une entrée pour _dévorer_. Comment décrire ce déplacement de
sens ?

::: definition
Le **sens propre** est le sens premier, concret et objectif. Le **sens figuré** est un sens
second, imagé.
La **dénotation** est le sens objectif d'un mot, partagé par tous. La **connotation** est
l'ensemble des valeurs subjectives, culturelles ou émotionnelles qui s'y attachent.
:::

| Mot / phrase                           | Ce qui est en jeu               | Analyse         |
| -------------------------------------- | ------------------------------- | --------------- |
| _Les flammes **dévoraient** la forêt._ | le feu consume réellement       | **sens propre** |
| _La jalousie **dévorait** son cœur._   | rien n'est mangé, l'image reste | **sens figuré** |
| _serpent_ → reptile sans pattes        | définition du dictionnaire      | **dénotation**  |
| _serpent_ → trahison, ruse, danger     | valeurs culturelles associées   | **connotation** |

::: exemple mesurer l'effet d'une connotation

1. _« Cet homme est un **serpent**. »_ — dénotation : un reptile. Or un homme n'est pas un
   reptile ← le mot est employé au **sens figuré**.
2. **Ce qui passe alors dans la phrase**, ce sont les **connotations** : la traîtrise, la ruse,
   le danger.
3. **L'auteur n'a rien affirmé** : il n'a pas écrit « cet homme trahit ». Il a laissé le mot
   faire le travail — **parce que** la connotation influence sans avoir à se justifier.

:::

> 💡 En production écrite, choisir un mot pour ses connotations permet d'influencer le lecteur
> sans l'affirmer directement. C'est une arme de l'argumentation — et elle se repère en analyse.

::: piege l'erreur classique

Confondre sens figuré et connotation. Le **sens figuré** concerne le mot **dans cette phrase**
(dévorer ne signifie plus manger) ; la **connotation** accompagne le mot **partout** (serpent
traîne ses valeurs négatives même au sens propre).

:::

::: verifie
Dans _« Ce quartier est un désert le soir »_, relève le sens figuré et une connotation.

---

**Sens figuré** : _désert_ ne désigne pas une étendue de sable mais un lieu vide de monde.
**Connotations** : abandon, silence, éventuellement insécurité — valeurs que le mot apporte sans
que l'auteur les affirme.
:::

::: retenir
Sens propre / sens figuré concernent le mot dans sa phrase ; dénotation / connotation concernent
ce que le mot transporte partout avec lui.
:::

## 🌀 Comparaison et métaphore

_« Le guerrier était fort **comme** un lion. »_ · _« Ce guerrier **est** un lion. »_ Le même
rapprochement, et un mot de moins.

Ce mot retiré change la force de l'image. Pourquoi, et comment nomme-t-on chacune des deux
formes ?

::: definition
La **comparaison** rapproche deux éléments à l'aide d'un **outil comparatif** (_comme, tel,
pareil à, semblable à, plus… que_). Elle comporte le **comparé**, l'**outil**, le **comparant**
et parfois le **point commun**.
La **métaphore** fait le même rapprochement **sans outil comparatif** : elle identifie
directement.
:::

| Phrase                                      | Outil comparatif | Figure            | Effet                      |
| ------------------------------------------- | ---------------- | ----------------- | -------------------------- |
| _Le guerrier était fort **comme** un lion._ | _comme_          | comparaison       | les deux restent distincts |
| _Ce guerrier **est** un lion._              | aucun            | métaphore         | identification, plus forte |
| _Il **rugit** de colère._                   | aucun            | métaphore verbale | le verbe porte l'image     |

::: exemple analyser une comparaison puis la transformer en métaphore

1. **Repère les quatre éléments** : comparé = _le guerrier_ ; outil = _comme_ ; comparant =
   _un lion_ ; point commun = _fort_.
2. **Retire l'outil et le point commun** : il reste _« Ce guerrier est un lion. »_ ←
   **métaphore**.
3. **Mesure ce qui a changé** : la comparaison dit qu'il **ressemble** au lion, la métaphore
   qu'il **en est** un — **parce que** supprimer l'outil supprime la distance entre les deux
   termes.

:::

> 🗡️ La **métaphore filée** est une métaphore développée sur plusieurs phrases ou sur tout un
> texte : _« Ce guerrier était un lion. Sa crinière flottait au vent, et ses griffes
> déchiraient les rangs ennemis. »_

::: piege l'erreur classique

Appeler « métaphore » toute comparaison. Le critère est unique et visible : **la présence de
l'outil comparatif**. S'il y a _comme_, _tel_ ou _semblable à_, c'est une comparaison — quelle
que soit la beauté de l'image.

:::

::: verifie
_« Ses cheveux, cascade d'or, tombaient sur ses épaules »_ — comparaison ou métaphore ?

---

**Métaphore** : aucun outil comparatif. _Cascade d'or_ est apposé directement à _ses cheveux_.
Une comparaison aurait donné : _« Ses cheveux tombaient **comme** une cascade d'or. »_
:::

::: retenir
L'outil comparatif décide : présent ← comparaison, absent ← métaphore — et son absence rend
l'image plus forte.
:::

## 🧪 Les autres figures de style

Quatre figures reviennent constamment dans les textes de l'examen, et chacune se reconnaît à un
indice matériel : un verbe humain, un chiffre impossible, une liste, une liste **ordonnée**.

Quels sont ces indices, et comment ne pas confondre les deux dernières ?

::: definition
La **personnification** attribue des caractères humains à un animal, un objet ou une abstraction.
L'**hyperbole** exagère à des fins expressives.
L'**énumération** aligne des termes de même catégorie.
La **gradation** est une énumération dont les termes sont **ordonnés par intensité**.
:::

| Figure               | Indice à repérer                            | Exemple                                                   |
| -------------------- | ------------------------------------------- | --------------------------------------------------------- |
| **Personnification** | un verbe ou un sentiment réservé à l'humain | _La tempête **hurlait** sa fureur._                       |
| **Hyperbole**        | une quantité ou une durée impossible        | _Je t'ai **attendu mille ans**._                          |
| **Énumération**      | une liste de même catégorie                 | _Des épées, des boucliers, des lances jonchaient le sol._ |
| **Gradation**        | une liste **ordonnée** par intensité        | _Il frémit, tremblait, criait de peur._                   |

::: exemple distinguer énumération et gradation

1. **Compte les termes** : les deux figures en alignent plusieurs ← ce critère ne suffit pas.
2. **Demande-toi si l'ordre pourrait changer** : dans _« des épées, des boucliers, des lances »_,
   on peut permuter sans rien perdre ← **énumération**.
3. **Dans _« il frémit, tremblait, criait »_**, permuter détruit l'effet : l'intensité monte ←
   **gradation**, **parce que** la gradation est une énumération **plus une progression**.

:::

> 🏆 Pour identifier une figure à l'examen, trois étapes : **1)** nommer la figure ; **2)** citer
> les mots qui la constituent ; **3)** expliquer son **effet**. La troisième est celle qu'on
> oublie, et elle porte souvent la moitié des points.

::: piege l'erreur classique

Nommer une figure sans citer ni expliquer. « Il y a une hyperbole » ne vaut presque rien ;
« l'hyperbole _mille ans_ exagère la durée de l'attente pour exprimer l'impatience » vaut la
question entière.

:::

::: verifie
Nomme la figure et son effet : _« Le vent murmurait des secrets aux arbres. »_

---

**Personnification** : _murmurer_ et _des secrets_ sont des comportements humains attribués au
vent. **Effet** : rendre le paysage vivant et complice, et créer une atmosphère intime, presque
inquiétante.
:::

::: retenir
Chaque figure a son indice matériel — verbe humain, quantité impossible, liste, liste ordonnée —
et la réponse complète nomme, cite et explique l'effet.
:::

## 📐 Méthode : analyser le vocabulaire d'un texte

On te donne un texte et une consigne large : « étudiez le vocabulaire ». Sans ordre, on écrit au
hasard ce qu'on remarque — et on oublie l'essentiel.

Quatre observations, toujours dans le même ordre, couvrent la question.

::: exemple applique l'ordre à un court extrait

> _« La ville dormait. Des ombres rampaient le long des murs, longues, noires, menaçantes. Un
> chien hurla mille fois dans la nuit. »_

1. **Champ lexical dominant** : _dormait, ombres, murs, noires, nuit_ ← champ lexical de la
   **nuit et de l'obscurité** ← thème principal.
2. **Figures de style** : _la ville dormait_ et _des ombres rampaient_ ← **personnifications** ;
   _mille fois_ ← **hyperbole** ; _longues, noires, menaçantes_ ← **gradation**.
3. **Sens propre / figuré** : _dormir_ est ici **figuré** (une ville ne dort pas) ← l'auteur
   prête une vie à la ville.
4. **Connotations** : _ombres_, _noires_, _menaçantes_ portent la **peur** ← l'intention est de
   créer l'inquiétude, **parce que** rien dans le texte n'affirme qu'il y a un danger.

:::

::: methode

1. **Repérer le champ lexical dominant** → le thème principal.
2. **Identifier les figures de style** → l'effet recherché.
3. **Distinguer sens propre et sens figuré** → l'intention de l'auteur.
4. **Relever les connotations** → la valeur expressive ou argumentative.

:::

::: piege l'erreur classique

Lister des mots sans conclure. Chaque étape doit aboutir à une **interprétation** : le champ
lexical donne le thème, les figures donnent l'effet, les connotations donnent l'intention. Une
liste sans conclusion ne répond pas à la consigne.

:::

::: verifie
Un texte multiplie les mots _lumière, aube, clarté, éclat_ et les verbes _renaître, s'ouvrir_.
Que conclus-tu ?

---

Champ lexical de la **lumière et du renouveau** ← le thème est l'espoir ou le recommencement. Les
connotations positives de ces mots orientent le lecteur vers l'**optimisme**, sans que l'auteur
ait besoin de l'affirmer.
:::

::: retenir
Quatre observations dans l'ordre — champ lexical, figures, sens figuré, connotations — et chacune
doit se conclure par une interprétation.
:::
