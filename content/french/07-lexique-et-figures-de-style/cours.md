# ⚔️ Le lexique et les figures de style

> 💡 « Les mots sont les armes du guerrier de l'écriture : en connaître la formation, les sens et les images, c'est forger une lame invincible. »

## 🏰 La formation des mots

Tu ne connais pas le mot _inoubliable_, et pourtant tu le comprends. Découpe-le : _in-_,
_oubli-_, _-able_. Trois morceaux, et chacun dit quelque chose.

Comment un mot inconnu peut-il être compris sans dictionnaire ? Et de quoi se compose-t-il
exactement ?

::: definition
Un mot se compose souvent de trois éléments : le **radical** porte le sens de base, le
**préfixe** se place **avant** le radical pour en modifier le sens, le **suffixe** se place
**après** pour changer le sens ou la classe du mot.
:::

| Élément     | Place            | Exemple                                                           |
| ----------- | ---------------- | ----------------------------------------------------------------- |
| **Préfixe** | avant le radical | _in-_ (négation) : _inutile_ ; _dé-_ (contraire) : _décharger_    |
| **Radical** | au centre        | _oubli-_ dans _oublier_, _oubliable_, _inoubliable_               |
| **Suffixe** | après le radical | _-able_ (« qui peut être ») : _utilisable_ ; _-ette_ : _fillette_ |

::: exemple décoder un mot inconnu en trois temps

1. **Isole le radical** : _oubli-_, car tu le reconnais dans _oublier_ — il s'agit de perdre un
   souvenir.
2. **Lis le suffixe** : _-able_ signifie « qui peut être », car _utilisable_ = « qui peut être
   utilisé » ← _oubliable_ = « qui peut être oublié ».
3. **Lis le préfixe** : _in-_ est un préfixe de négation, car _inutile_ = « pas utile » ← donc
   _inoubliable_ = « qui ne peut pas être oublié ».

:::

::: piege Erreur fréquente
Prendre une syllabe pour un préfixe. Dans _image_, _im-_ n'est pas un préfixe de négation : le
mot ne veut pas dire « pas _-age_ ». Le test : une fois le préfixe ôté, le reste doit être un mot
qui existe — _possible_ existe dans _impossible_, _-age_ n'existe pas seul.
:::

::: propriete

- Les mots qui partagent le même radical forment une **famille de mots** : _mémoire_,
  _mémoriser_, _mémorable_, _commémorer_.
- Le préfixe **dé-** donne souvent l'antonyme d'un verbe : _charger_ / _décharger_, _monter_ /
  _démonter_ ; **sur-** marque l'excès ou le degré supérieur : _surchauffé_, _surdoué_.
- Cas-limite : un suffixe peut **nuancer** sans changer la classe — _fillette_ est encore un nom,
  mais le suffixe diminutif _-ette_ ajoute l'idée de petitesse.

:::

::: verifie
Que signifie _infatigable_, et comment le sais-tu ?

---

« Qui ne peut pas être fatigué ». Radical _fatig-_ (de _fatiguer_), car on le retrouve dans
_fatigue_ ; suffixe _-able_ = « qui peut être » ; préfixe _in-_ = négation. Lus ensemble, ils
donnent le sens sans dictionnaire.
:::

::: retenir
Préfixe + radical + suffixe : les lire un par un suffit souvent à comprendre un mot jamais
rencontré ; même radical = même famille.
:::

## 🔮 Un mot, plusieurs sens : la polysémie

_« Le temps se gâte. »_ · _« Cette grand-mère gâte ses petits-enfants. »_ · _« Ces fruits sont
gâtés. »_ Le même verbe, trois fois, et trois sens bien différents.

Comment savoir quel sens prend un mot qui en a plusieurs ?

::: definition
Un mot **polysémique** a **plusieurs sens** ; c'est le **contexte** (la phrase, le texte) qui
indique lequel est employé. On parle de **polysémie**.
:::

| Phrase                              | Sens de _gâter_ | Synonyme possible |
| ----------------------------------- | --------------- | ----------------- |
| _Le temps se **gâte**._             | devenir mauvais | se dégrader       |
| _Elle **gâte** ses petits-enfants._ | combler, choyer | choyer            |
| _Ces fruits sont **gâtés**._        | abîmer          | pourris           |

Dans chaque ligne, c'est le reste de la phrase (_le temps_, _ses petits-enfants_, _ces fruits_)
qui fixe le sens du verbe.

::: exemple trouver le sens d'un mot polysémique

_« Le musicien accorde son violon avant le concert. »_

1. **Regarde le complément** : _son violon_, car un mot polysémique prend son sens de ce qui
   l'entoure.
2. **Écarte les autres sens** : _accorder un adjectif_ (le faire varier), _accorder de
   l'importance_ (donner) ne vont pas avec un instrument.
3. **Conclus** : ici, _accorder_ = régler le son de l'instrument, car c'est ce qu'on fait à un
   violon avant de jouer.

:::

::: piege Erreur fréquente
Donner le sens appris en premier, quel que soit le contexte. Dans _« J'ai reçu une bonne
note »_, _note_ n'est pas un son de musique : c'est une appréciation chiffrée. Le sens se lit dans
la phrase, jamais dans la mémoire seule.
:::

::: propriete

- Pour donner le **synonyme** d'un mot polysémique, il faut d'abord fixer son sens dans la phrase :
  le synonyme change avec le sens.
- Cas-limite — les **homonymes** : _verre_ (récipient), _vers_ (poème), _vert_ (couleur) se
  prononcent pareil mais sont des **mots différents**, souvent d'orthographe différente. Un mot
  polysémique, lui, est **un seul mot** (une seule entrée de dictionnaire) aux sens multiples.
- On dit aussi « champ sémantique » d'un mot pour l'ensemble de ses sens.

:::

::: verifie
Donne un synonyme de _jouer_ dans : _« Cet acteur joue le rôle du roi. »_

---

_Interpréter_ : le complément _le rôle du roi_ indique le théâtre ; _jouer_ n'y signifie ni
« s'amuser » ni « pratiquer un sport », mais « tenir un rôle ».
:::

::: retenir
Un mot polysémique a plusieurs sens ; c'est le contexte qui choisit — et le synonyme suit le sens
choisi.
:::

## 🔥 Sens propre et sens figuré

_« Les flammes dévoraient la forêt. »_ · _« La jalousie dévorait son cœur. »_ Le même verbe, et
dans le second cas, rien n'est mangé ni brûlé.

Comment décrire ce glissement du concret vers l'image ?

::: definition
Le **sens propre** est le sens premier d'un mot, concret. Le **sens figuré** est un sens second,
imagé, qui transporte ce premier sens dans un autre domaine.
:::

| Phrase                                   | Ce qui se passe réellement         | Sens       |
| ---------------------------------------- | ---------------------------------- | ---------- |
| _La **flamme** de la bougie vacille._    | un feu brûle                       | **propre** |
| _Elle parle de son art avec **flamme**._ | aucun feu : un enthousiasme ardent | **figuré** |
| _Ce guide **épouse** la montagne._       | aucun mariage : une passion totale | **figuré** |

Le mot ne change pas ; c'est la réalité qu'il désigne qui change.

::: exemple reconnaître le sens figuré

_« Cette guerre d'usure contre la maladie a duré des années. »_

1. **Pose la question du réel** : y a-t-il des soldats, des armes ? Non, car il s'agit d'une
   maladie.
2. **Retrouve le sens propre** : une _guerre d'usure_ épuise l'ennemi peu à peu.
3. **Conclus** : sens **figuré**, car l'expression transporte cette idée d'épuisement lent dans
   le domaine de la santé.

:::

::: piege Erreur fréquente
Croire que « figuré » veut dire « faux » ou « exagéré ». _« Il a un cœur de pierre »_ est
**vrai** au sens figuré : l'homme est insensible. Le sens figuré dit quelque chose de juste, mais
par une image.
:::

::: propriete

- Le test : **ce que dit le mot arrive-t-il réellement ?** Oui ← sens propre ; non, c'est une
  image ← sens figuré.
- Le sens figuré est à la base des **métaphores** (voir plus bas) : _« Il rugit de colère »_.
- Cas-limite : un même mot peut être propre dans une phrase et figuré dans la suivante — on juge
  toujours **dans la phrase**, jamais le mot seul.

:::

::: verifie
_« Une main géante se referme sur moi et m'empêche de respirer »_, dit un enfant terrorisé. Le mot
_main_ est-il au sens propre ?

---

Non : aucune main réelle ne le serre ; c'est la **peur** qui l'étouffe. _Main_ est au **sens
figuré**, car il transporte l'image d'une étreinte dans le domaine de l'émotion.
:::

::: retenir
Si ce que dit le mot arrive réellement ← sens propre ; si c'est une image ← sens figuré.
:::

## ⚡ Le champ lexical

_Cordée, sommet, ascension, altitude, cime, glacier._ Six mots, aucun n'est _montagne_ — et
pourtant tu sais de quoi parle le texte.

Comment des mots différents peuvent-ils tous désigner un même thème ?

::: definition
Le **champ lexical** d'un thème est l'ensemble des **mots** qui s'y rapportent dans un texte :
noms, verbes, adjectifs, expressions.
:::

| Thème         | Mots du champ lexical                                     |
| ------------- | --------------------------------------------------------- |
| la montagne   | sommet (nom), escalader (verbe), escarpé (adjectif), cime |
| l'obstination | persévérer, ténacité, sans relâche, acharné               |
| la lumière    | clarté, briller, éclatant, rayon, lueur                   |

Les mots d'un même champ lexical n'ont pas la même classe : c'est le **thème** qui les réunit.

::: exemple relever un champ lexical et conclure

_« Les lames claquaient, les boucliers résonnaient, les flèches sifflaient. »_

1. **Repère les mots qui se ressemblent par le thème** : _lames, boucliers, flèches_, car ils
   désignent tous des armes.
2. **Ajoute les verbes** : _claquaient, résonnaient, sifflaient_, car ils disent le bruit du
   combat.
3. **Nomme le thème** : champ lexical du **combat** ← c'est le sujet du passage.

:::

::: piege Erreur fréquente
Ne relever que des noms. Dans _« Il s'acharnait, obstiné, sans relâche »_, il n'y a aucun nom, et
pourtant le champ lexical de l'obstination est là : un verbe, un adjectif, une locution.
:::

::: propriete

- Le **champ lexical dominant** d'un texte indique son **thème principal**.
- Cas-limite — le **mot intrus** : dans _alpinisme, escalade, sommet, plaine, cime_, _plaine_
  n'appartient pas au champ lexical de la montagne, car une plaine est plate.

:::

::: verifie
Quel est l'intrus : _orchestre, violon, concert, symphonie, poisson_ ? Quel champ lexical
forment les autres ?

---

L'intrus est _poisson_ : les quatre autres se rapportent au thème de la **musique**, qui forme
leur champ lexical ; un poisson n'a aucun rapport avec ce thème.
:::

::: retenir
Champ lexical = tous les mots (de toutes classes) liés à un même thème ; le champ dominant donne
le thème du texte.
:::

## 🛡️ Synonymes, antonymes et paronymes

_« Il pratique la natation. »_ Tu cherches un synonyme de _pratiquer_ : _exercer_, _effectuer_,
_cultiver_… Mais _« Il cultive la natation »_ sonne faux.

Les synonymes sont-ils vraiment interchangeables ? Et que faire de deux mots qui se ressemblent
sans vouloir dire la même chose ?

::: definition
Des **synonymes** ont un sens **voisin** ; des **antonymes** ont un sens **contraire** ; des
**paronymes** ont une **forme proche** (presque la même prononciation) mais un **sens
différent**.
:::

| Relation      | Exemple                                                     |
| ------------- | ----------------------------------------------------------- |
| **Synonymes** | _angoisse_ / _détresse_ ; _lutter_ / _se battre_            |
| **Antonymes** | _vantard_ / _modeste_ ; _charger_ / _décharger_             |
| **Paronymes** | _compréhensif_ / _compréhensible_ ; _altitude_ / _latitude_ |

::: exemple choisir le bon synonyme

1. _« Il **pratique** un métier dangereux »_ → **exercer** convient, car on _exerce_ un métier.
2. _« Elle **pratique** l'anglais couramment »_ → **parler** convient, car on _parle_ une langue.
3. _« Le chirurgien **pratique** une opération »_ → **effectuer** convient — mais pas _exercer_,
   car on n'_exerce_ pas une opération. Le synonyme dépend du complément.

:::

::: piege Erreur fréquente
Confondre deux paronymes. _« Mon professeur est très compréhensible »_ est faux : un professeur
**compréhensif** comprend les autres ; une explication **compréhensible** peut être comprise. Le
paronyme ne se voit pas comme une faute d'orthographe, mais il change tout le sens.
:::

::: propriete

- Les synonymes **ne sont pas toujours interchangeables** : on vérifie le contexte (le
  complément, le registre) avant de remplacer un mot.
- Pour un paronyme, on vérifie le **sens** au dictionnaire : _éruption_ (sortie brusque, d'un
  volcan) / _irruption_ (entrée brusque) ; _éminent_ (remarquable) / _imminent_ (tout proche).
- Cas-limite : un antonyme se forme souvent avec un préfixe (_in-_, _dé-_) — _utile_ / _inutile_,
  _monter_ / _démonter_.

:::

::: verifie
_« Les policiers ont fait **éruption** dans la salle. »_ — corrige.

---

_Irruption_ : les policiers **entrent** brusquement ; _éruption_ désigne une sortie brusque
(celle d'un volcan). Les deux mots sont des **paronymes** : forme proche, sens différent.
:::

::: retenir
Synonymes = sens voisin, mais pas toujours interchangeables ; antonymes = sens contraire ;
paronymes = forme proche, sens différent.
:::

## 🗣️ Registre familier, registre courant

À ton ami, tu écris : « Mon frangin a trouvé un boulot. » Dans ta rédaction, tu écrirais plutôt :
« Mon frère a trouvé un travail. » Même information, deux manières de la dire.

Pourquoi ne parle-t-on pas de la même façon à un ami et dans une rédaction ?

::: definition
Le **registre** est la manière de parler choisie selon la situation et l'interlocuteur. Le
**registre familier** s'emploie entre proches, à l'oral ; le **registre courant** convient à
l'école, à l'écrit et avec la plupart des gens. On dit aussi « niveaux de langue ».
:::

| Registre familier         | Registre courant                |
| ------------------------- | ------------------------------- |
| un **boulot**, un **job** | un **travail**, un **emploi**   |
| une **bagnole**           | une **voiture**                 |
| **J'sais pas.**           | **Je ne sais pas.**             |
| **T'as vu ?**             | **As-tu vu ?** / **Tu as vu ?** |

Le familier touche les **mots** (_boulot_) et la **construction** (le _ne_ de la négation qui
disparaît).

::: exemple réécrire une phrase au registre courant

_« Mon frangin, il a pas trouvé de boulot. »_

1. _frangin_ → **frère**, car _frangin_ est un mot familier.
2. _Mon frère, il_ → **Mon frère**, car la reprise par _il_ est une construction de l'oral.
3. _a pas_ → **n'a pas**, car la négation complète exige _ne… pas_ ; _boulot_ → **travail** ←
   _« Mon frère n'a pas trouvé de travail. »_

:::

::: piege Erreur fréquente
Écrire en registre familier dans une rédaction sans s'en rendre compte : _« Le héros était trop
content »_ pour dire « très content ». À l'écrit scolaire, _trop_ signifie « plus qu'il ne
faut » ; pour l'intensité, on écrit _très_ ou _extrêmement_.
:::

::: propriete

- Le registre se choisit selon **la situation** : copie d'examen, lettre officielle ← registre
  courant ; message à un ami, dialogue entre jeunes dans un récit ← le familier est possible.
- Cas-limite : dans un **dialogue** de récit, le familier est permis s'il caractérise un
  personnage ; dans la **narration**, il ne l'est pas.

:::

::: verifie
Réécris au registre courant : _« J'ai pas eu le temps de lire ce bouquin. »_

---

_« Je n'ai pas eu le temps de lire ce livre. »_ La négation retrouve son _ne_ (registre courant) et
_bouquin_, mot familier, devient _livre_.
:::

::: retenir
Registre familier pour les proches et l'oral ; registre courant pour l'école et l'écrit — on
change les mots ET la construction.
:::

## 🧷 Les expressions figées

Ton ami refuse de changer d'avis, et sa mère soupire : « Quelle tête de mule ! » Personne n'imagine
une mule.

Comment comprendre une expression dont les mots, pris un à un, ne disent pas le sens ?

::: definition
Une **expression figée** est un groupe de mots dont le sens est **global** : on ne le déduit pas
mot à mot, et on ne peut pas en changer les mots.
:::

| Expression                     | Sens                               |
| ------------------------------ | ---------------------------------- |
| _une tête de mule_             | une personne très têtue            |
| _une tête brûlée_              | une personne qui aime le danger    |
| _une histoire à dormir debout_ | une histoire invraisemblable       |
| _faire des histoires_          | faire des difficultés, se plaindre |
| _avoir bonne mine_             | avoir l'air en bonne santé         |

::: exemple comprendre une expression figée

_« Ne crois pas ce qu'il dit : il te mène en bateau. »_

1. **Teste le sens mot à mot** : il n'y a ni bateau ni voyage, car la phrase parle de mensonge.
2. **Prends l'expression en bloc** : _mener quelqu'un en bateau_.
3. **Déduis le sens du contexte** : « Ne crois pas ce qu'il dit » ← _mener en bateau_ = tromper,
   faire croire des choses fausses.

:::

::: piege Erreur fréquente
Changer un mot de l'expression : _« une tête d'âne »_ au lieu de _« une tête de mule »_, ou
_« faire beaucoup d'histoire »_. L'expression est figée : un seul mot changé et elle n'existe
plus.
:::

::: propriete

- Un même mot entre dans plusieurs expressions de sens différents : _faire des histoires_ (se
  plaindre) ≠ _raconter des histoires_ (mentir).
- Cas-limite : certaines expressions ont aussi un sens propre — _« mettre la main à la pâte »_
  se dit d'un boulanger qui pétrit (sens propre) ou de quelqu'un qui participe à un travail
  (expression figée). Le contexte tranche.

:::

::: verifie
Que signifie _« Il en a fait toute une histoire »_ ?

---

Il a donné beaucoup trop d'importance à une chose sans gravité. L'expression est figée : son sens
ne vient pas de _histoire_ (récit), mais du bloc entier.
:::

::: retenir
Une expression figée se comprend en bloc, grâce au contexte, et ne se modifie pas.
:::

## 🌀 La comparaison et la métaphore

_« Ce garçon est malin **comme** un singe. »_ · _« Ce garçon est un vrai singe. »_ Le même
rapprochement, et un mot en moins.

Comment s'appellent ces deux façons de rapprocher deux réalités, et qu'est-ce qui les distingue ?

::: definition
La **comparaison** rapproche deux éléments à l'aide d'un **outil de comparaison** : elle comporte
un **comparé** (ce dont on parle), un **outil**, un **comparant** (l'image), et souvent un
**point commun**.
La **métaphore** est une **comparaison abrégée, sans outil de comparaison**.
:::

| Phrase                                    | Comparé   | Outil | Comparant | Point commun | Figure      |
| ----------------------------------------- | --------- | ----- | --------- | ------------ | ----------- |
| _Ce garçon est malin **comme** un singe._ | ce garçon | comme | un singe  | malin        | comparaison |
| _Ce garçon est un vrai singe._            | ce garçon | —     | un singe  | —            | métaphore   |
| _Il était fort **tel** un lion._          | il        | tel   | un lion   | fort         | comparaison |

Dans la métaphore, l'outil et souvent le point commun disparaissent : il ne reste que le comparé
et le comparant.

::: exemple analyser une comparaison, puis la transformer

_« Ses yeux brillaient comme des étoiles. »_

1. **Repère l'outil** : _comme_ ← c'est une **comparaison**, car l'outil est présent.
2. **Nomme les éléments** : comparé = _ses yeux_ ; comparant = _des étoiles_ ; point commun =
   _brillaient_.
3. **Abrège** : retire l'outil ← _« Ses yeux étaient des étoiles. »_ ← **métaphore**, car il
   n'y a plus d'outil de comparaison.

:::

::: piege Erreur fréquente
Prendre le verbe _être_ pour un outil de comparaison. Dans _« Ce guerrier est un lion »_, _est_
n'est pas un outil : il n'y a ni _comme_, ni _tel_, ni _semblable à_. C'est donc une
**métaphore**, pas une comparaison.
:::

::: propriete

- Outils de comparaison : _comme, ainsi que, tel, pareil à, semblable à, ressembler à,
  plus… que_.
- La métaphore peut se trouver dans un nom (_« cette cascade d'or »_ pour des cheveux) ou dans
  un verbe au sens figuré (_« Il rugit de colère »_).
- Cas-limite : _« Il ressemble à son père »_ n'est pas une figure : on rapproche deux réalités
  de même nature, sans image. La comparaison rapproche deux domaines différents (un homme et un
  animal, des yeux et des étoiles).

:::

::: verifie
_« Les insectes de la pluie grignotaient les carreaux. »_ — comparaison ou métaphore ?

---

**Métaphore** : aucun outil de comparaison. Les gouttes (comparé, sous-entendu) sont désignées
directement par l'image des _insectes_ (comparant) qui _grignotent_. Avec un outil : _« Les gouttes
de pluie, comme des insectes, grignotaient les carreaux. »_
:::

::: retenir
Outil de comparaison présent ← comparaison ; absent ← métaphore, « comparaison abrégée ».
:::

## 🧪 La personnification

_« Le vent hurlait entre les ruines. »_ Le vent n'a pas de gorge : il ne crie pas. Pourtant,
l'auteur lui prête un cri d'homme, et le paysage devient menaçant.

Quel indice permet de reconnaître cette figure, et que faut-il dire de son effet ?

::: definition
La **personnification** attribue des caractères **humains** (actions, sentiments, paroles) à un
animal, un objet, un élément ou une idée.
:::

| Phrase                                | Ce qui n'est pas humain | Trait humain prêté  | Figure           |
| ------------------------------------- | ----------------------- | ------------------- | ---------------- |
| _La tempête **hurlait** sa colère._   | la tempête              | hurler, la colère   | personnification |
| _La forêt **retenait son souffle**._  | la forêt                | retenir son souffle | personnification |
| _Le vent souffle fort sur la plaine._ | le vent                 | — (le vent souffle) | aucune figure    |

::: exemple nommer, citer, expliquer l'effet

_« La vieille horloge toussait dans le salon vide. »_

1. **Repère ce qui n'est pas humain** : _la vieille horloge_ ← un objet.
2. **Cherche le trait humain** : _toussait_ ← **personnification**, car tousser est le geste
   d'une personne (ici, d'un vieillard malade), pas d'une horloge.
3. **Explique l'effet** : l'horloge paraît vieille et fatiguée, car on lui prête la toux d'un
   vieillard ; le salon vide semble encore plus triste.

:::

::: piege Erreur fréquente
Nommer la figure sans citer ni expliquer. « Il y a une personnification » ne vaut presque rien ;
« la personnification _l'horloge toussait_ prête à l'objet la toux d'un vieillard et rend le salon
triste » répond à la question.
:::

::: propriete

- Une réponse complète **nomme** la figure, **cite** les mots qui la forment et **explique son
  effet**.
- Cas-limite : _« Le chien aboyait »_ n'est pas une personnification — aboyer est le cri normal
  du chien. Il faut un trait **réservé à l'homme** : _« Le chien souriait à son maître. »_
- Cas-limite : _« La forêt retenait son souffle »_ est une personnification, pas une
  comparaison — il n'y a aucun outil, et c'est un geste humain qui est prêté à la forêt.

:::

::: verifie
Nomme la figure et son effet : _« Le vent murmurait des secrets aux arbres. »_

---

**Personnification** : _murmurer_ et _des secrets_ sont des comportements humains prêtés au vent.
**Effet** : le paysage paraît vivant et complice, l'atmosphère devient intime.
:::

::: retenir
Personnification = trait réservé à l'homme prêté à un non-humain. On nomme, on cite, on explique
l'effet.
:::

## 📐 Méthode : étudier le vocabulaire d'un passage

On te donne un passage et une consigne : « Étudiez le vocabulaire et les images ». Sans ordre, on
écrit au hasard ce qu'on remarque — et on oublie l'essentiel.

Quelles observations faire, et dans quel ordre, pour couvrir la question ?

::: exemple applique l'ordre à un court extrait

> _« La ville dormait. Des ombres rampaient le long des murs, noires comme de l'encre. Un chien
> hurla dans la nuit. »_

1. **Champ lexical dominant** : _dormait, ombres, noires, encre, nuit_ ← la **nuit et
   l'obscurité**, car tous ces mots s'y rapportent : c'est le thème.
2. **Sens propre / figuré** : _dormir_ est au **sens figuré**, car une ville ne dort pas.
3. **Figures** : _la ville dormait_, _des ombres rampaient_ ← **personnifications** ; _noires
   comme de l'encre_ ← **comparaison** (outil _comme_).
4. **Effet** : ces images rendent la ville vivante et inquiétante, car elles montrent un monde
   endormi où les ombres bougent seules.

:::

::: methode

1. **Repérer le champ lexical dominant** → le thème.
2. **Distinguer sens propre et sens figuré** → les images.
3. **Nommer les figures** (comparaison, métaphore, personnification…) en citant les mots.
4. **Conclure sur l'effet** → l'impression que l'auteur veut produire.

Cas-limite : une description **subjective** se reconnaît justement à ses mots choisis
(adjectifs) et à ses comparaisons et métaphores ; une description objective en contient peu.
:::

::: piege Erreur fréquente
Lister des mots sans conclure. Chaque étape doit aboutir à une **interprétation** : le champ
lexical donne le thème, les figures donnent l'effet. Une liste sans conclusion ne répond pas à la
consigne.
:::

::: verifie
Un passage multiplie _lumière, aube, clarté, éclat_ et dit : _« le soleil souriait aux
toits »_. Que conclus-tu ?

---

Champ lexical de la **lumière** ← le thème est le jour qui se lève. _Le soleil souriait_ est une
**personnification** (sourire est humain) ← **effet** : une atmosphère joyeuse, accueillante.
:::

::: retenir
Champ lexical → sens figuré → figures → effet : chaque étape se conclut par une interprétation.
:::

## 🚀 Pour aller plus loin (hors programme de 9e)

Tu rencontreras dans des textes d'autres procédés, que le manuel de 9e n'enseigne pas. Il suffit
pour l'instant de les **reconnaître** quand on te les nomme ; ils ne sont pas évalués ici.

- **Métaphore filée** : une métaphore prolongée sur plusieurs phrases — _« Le temps est un
  fleuve : il coule sans bruit, emporte nos jours et ne remonte jamais vers sa source. »_
- **Hyperbole** : une exagération pour frapper — _« Je t'ai attendu mille ans. »_
- **Énumération** : une liste de termes de même catégorie — _« Des épées, des boucliers, des
  lances jonchaient le sol. »_
- **Gradation** : une énumération rangée par intensité — _« Il frémissait, tremblait, hurlait de
  peur. »_
- **Connotation** : les idées qu'un mot éveille en plus de son sens — _serpent_ fait penser à la
  ruse, _aurore_ à l'espoir.
- **Antithèse** : deux idées opposées mises face à face — _« Dehors le grand jour, en lui la
  nuit. »_
- **Métonymie** : désigner une chose par une autre qui lui est liée — _« boire un verre »_ (son
  contenu).
- **Litote** : dire moins pour faire entendre plus — _« Il n'est pas mécontent »_ (il est
  content).
