# 📜 Résumé : Les reprises et les pronoms compléments

- **Procédés de reprise** : redésigner un être ou une chose déjà nommés, sans ambiguïté ; ils assurent la cohérence du texte et évitent la répétition. Classes : nom ou groupe nominal, pronom personnel, démonstratif, possessif, relatif (_qui_ reprend son antécédent).
- **Reprise nominale** : le même nom, un synonyme, un terme générique (_l'animal_) ou _ce dernier_ n'apportent aucune information nouvelle ; un groupe nominal enrichi (_la bête affamée_) ou une périphrase (_le roi du bitume_) en apportent.
- **Reprise pronominale** : le pronom prend le genre et le nombre du nom repris ; _celui-ci_ = le dernier nommé, _celui-là_ = le premier ; le possessif s'accorde avec la chose possédée (_mes résultats_ → _les tiens_, même pour Salma).
- **Pronoms COD / COI** : 3ᵉ personne COD _le, la, les_ ; COI _lui, leur_ (_leur_ invariable) ; _me, te, nous, vous_ pour les deux ; c'est la construction du verbe qui décide (_je l'aide_, _je lui téléphone_).
- **En / y** : _en_ remplace un complément introduit par _de_ (_du, de la, des_), ou un COD de quantité qu'on répète (_j'en ai lu trois_) ; _y_ remplace une chose introduite par _à_ ; une personne (_penser à sa sœur_) → pronom tonique (_à elle_).
- **Place (règle générale)** : sujet (ne) _me/te/nous/vous/se_ — _le/la/les_ — _lui/leur_ — _y_ — _en_ — verbe ou auxiliaire (pas) : _Je ne le leur ai pas raconté_ ; vaut aussi pour l'impératif négatif (_Ne le leur confie pas_).
- **Impératif affirmatif** : pronoms après le verbe, COD d'abord, avec traits d'union : _Donne-la-moi_, _Montrez-les-leur_, _Donne-m'en_, _Va-t'en_.
