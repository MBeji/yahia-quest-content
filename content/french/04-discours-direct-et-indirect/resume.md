# 📜 Résumé : Le discours direct et le discours indirect

- **Dialogue dans le récit** : les **guillemets** montrent que le narrateur donne la parole à un personnage ; le **tiret** en début de ligne signale un **changement de locuteur** ; la ponctuation des paroles reste à l'intérieur.
- **Verbe introducteur** (_dire, demander, répondre, rétorquer, murmurer…_), choisi selon le type de phrase et l'intention : **avant** la réplique sans inversion ; **au milieu ou à la fin** en incise, **avec inversion du sujet** (_« Je ne peux pas », affirma-t-il_).
- **Rôle du dialogue** : rend le récit plus vivant ; montre le comportement, le caractère et les sentiments des personnages ; dans la réplique, le personnage dit **je**.
- **Discours indirect** : les paroles deviennent une subordonnée — **que** (déclarative), **si** (question totale), **où, quand, ce que, ce qui** (question partielle), **de + infinitif** (ordre).
- **Pronoms** : ceux de celui qui parle deviennent ceux de celui qui rapporte (souvent 1re/2e personne → 3e) ; possessifs compris.
- **Temps** (verbe introducteur au passé) : présent → imparfait ; passé composé → plus-que-parfait ; futur → conditionnel présent (**futur par rapport au passé**) ; l'**imparfait ne change pas**.
- **Indicateurs** : aujourd'hui → ce jour-là ; hier → la veille ; demain → le lendemain ; maintenant → alors ; ici → là.
- **Interrogation indirecte** : ni point d'interrogation, ni inversion, ni _est-ce que_ ; _qu'est-ce qui_ → **ce qui** (sujet), _qu'est-ce que_ → **ce que** (COD).
- **Méthode** : verbe introducteur et son temps → outil → pronoms → temps et indicateurs (seulement si le verbe introducteur est au passé).
