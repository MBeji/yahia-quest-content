# 📜 Résumé : Les types et les formes de phrases

- **4 types** (un seul par phrase, selon l'intention) : déclaratif, interrogatif, impératif, exclamatif. L'impératif n'a **pas de sujet exprimé** ; « ! » ne suffit pas à rendre une phrase exclamative.
- **Forme négative** : deux mots autour du verbe conjugué (de l'auxiliaire aux temps composés) — _encore → ne… plus_, _souvent → ne… jamais_, _quelqu'un → ne… personne_, _quelque chose → ne… rien_ ; _Personne n'est venu._
- **Forme passive** : le COD de l'actif devient sujet ; **être** au temps du verbe actif + participe passé ; agent après **par** (absent si le sujet actif est _on_).
- **Forme emphatique** : présentatif **c'est… qui** (sujet) / **c'est… que** (complément), _ce sont… qui_ au pluriel ; sans mise en relief, la phrase est **neutre**.
- **Décrire une phrase** = un type + ses formes marquées (négative, passive, emphatique) — ex. _Ne m'imitez pas !_ = impérative négative.
