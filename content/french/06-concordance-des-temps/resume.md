# 📜 Résumé : Les temps du récit et les temps du discours

- **Deux systèmes** : le **récit** (passé simple, imparfait, plus-que-parfait ; repères _ce jour-là, la veille, le lendemain_) raconte des faits coupés du moment où l'on écrit ; le **discours** (présent, passé composé, futur, futur antérieur ; repères _aujourd'hui, hier, demain_) part du moment où l'on parle. Le passé simple et le passé composé ne se mélangent pas dans une même narration.
- **Transposer un récit au présent de narration** : action ponctuelle (premier plan) → passé simple ; décor, action qui dure (arrière-plan) → imparfait ; action déjà faite (passé composé) → plus-que-parfait. En sens inverse, le plus-que-parfait redevient passé composé.
- **Futur dans le passé** : quand le verbe principal passe au passé, futur → conditionnel présent (_Elle croyait qu'elle gagnerait_), futur antérieur → conditionnel passé. Ce conditionnel n'est pas une hypothèse.
- **Système en « si »** : si + présent → futur (action réalisable) ; si + imparfait → conditionnel présent (action **éventuelle**, envisagée dans le futur, ou **irréelle** dans le présent — les indices décident) ; si + plus-que-parfait → conditionnel passé (action **irréelle** dans le passé). Jamais de conditionnel juste après _si_.
- **Méthode** : récit ou discours ? → premier plan, arrière-plan ou retour en arrière ? → futur vu du passé ? → système en _si_ ?
- **Pour aller plus loin** (hors programme) : reconnaître le passé antérieur (_eut fini_) et le subjonctif imparfait (_qu'elle vînt_) dans les textes littéraires, sans les employer.
