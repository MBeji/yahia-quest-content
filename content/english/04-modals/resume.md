# 📜 Summary: Modal Verbs

- **Obligation now** — **must** or **have to** + base verb = it is necessary, no choice; **has to** with he / she / it (_Sami has to revise_); **must** never changes and takes no _to_ and no _-s_ (_He must study_).
- **Obligation in the past and the future** — **had to** (past) and **will have to** (future) + base verb, the same for every subject; must has no past form (_Yesterday I had to clean my room_; _He will have to apologise_, never _will has to_).
- **Prohibition** — **mustn't** + base verb, with any subject (_You mustn't cheat_), or **Don't** + base verb, speaking to the reader (_Don't phone in class!_, never _Don't phoning_).
- **Advice** — **should** / **ought to** + base verb = it is a good thing to do; **shouldn't** = it is not; should never takes _to_, ought never goes without it (_You ought to rest_). Advice leaves a choice, obligation does not.
- **Possibility** — **may** / **might** / **could** + base verb = perhaps, in the present or the future (_He might catch a cold_, never _might catches_).
- **Ability and inability** — **can** / **be able to** + base verb; **can't** (cannot) / **be unable to** + base verb; _be_ agrees with the subject (_He is unable to walk_) and _able_ keeps its _to_.
- **Choosing the right modal** — find the job first: obligation (must, have to), prohibition (mustn't, Don't), advice (should, ought to), possibility (may, might, could), ability (can, be able to); then the base verb — only **have to**, **ought to** and **be able to** keep a _to_.
