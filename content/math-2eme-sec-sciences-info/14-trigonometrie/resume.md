# 📜 Résumé : Trigonométrie et mesure de grandeurs

- **Cosinus et sinus** : pour α dans [0 ; π], M est le point du demi-cercle trigonométrique tel que AÔM = α ; cos α est l'**abscisse** de M et sin α son **ordonnée**. On a −1 ≤ cos α ≤ 1 et 0 ≤ sin α ≤ 1 : le cosinus peut être négatif (angle obtus), le sinus ne l'est jamais. cos 0 = 1, cos π/2 = 0, cos π = −1 ; sin 0 = sin π = 0, sin π/2 = 1.
- **Valeurs remarquables** : dans un triangle rectangle, cos α = adjacent/hypoténuse et sin α = opposé/hypoténuse. Le demi-carré et le demi-triangle équilatéral donnent cos π/6 = √3/2, sin π/6 = 1/2 ; cos π/4 = sin π/4 = √2/2 ; cos π/3 = 1/2, sin π/3 = √3/2. Degrés et radians : 30° = π/6, 45° = π/4, 60° = π/3, 90° = π/2, 180° = π.
- **Tangente et cotangente** : tan α = sin α / cos α pour α ≠ π/2 ; cot α = cos α / sin α pour α dans ]0 ; π[. Pour α aigu, tan α est la longueur AT sur la tangente au demi-cercle en A. tan π/2, cot 0 et cot π n'existent pas. tan π/6 = √3/3, tan π/4 = 1, tan π/3 = √3 ; quand elles existent, cot α = 1/tan α.
- **Relations fondamentales** : cos²x + sin²x = 1 sur [0 ; π] ; 1 + tan²x = 1/cos²x pour x ≠ π/2 ; 1 + cot²x = 1/sin²x pour x ≠ 0 et x ≠ π. Une racine carrée donne deux signes possibles pour cos x : c'est la position de x (aigu ou obtus) qui choisit ; sin x est toujours positif ou nul.
- **Angles supplémentaires et complémentaires** : cos(π − x) = −cos x, sin(π − x) = sin x, tan(π − x) = −tan x ; cos(π/2 − x) = sin x, sin(π/2 − x) = cos x, tan(π/2 − x) = cot x. Une équation sin x = k, avec 0 < k < 1, a deux solutions x et π − x dans [0 ; π] ; cos x = k, avec −1 ≤ k ≤ 1, n'en a qu'une.
- **Loi du sinus** : dans tout triangle, a/sin Â = b/sin B̂ = c/sin Ĉ = 2R, où R est le rayon du cercle circonscrit ; chaque côté se divise par le sinus de l'angle **opposé**. La loi donne sin d'un angle, pas l'angle : Â et π − Â ont le même sinus.
- **Aire d'un triangle** : S = ½ bc sin Â = ½ ac sin B̂ = ½ ab sin Ĉ, avec l'angle compris entre les deux côtés utilisés, aigu ou obtus ; le ½ ne s'oublie pas. Avec la loi du sinus, S = abc/(4R).
- **Théorème d'El-Kashi** : a² = b² + c² − 2bc cos Â, et de même pour b² et c². C'est Pythagore quand Â = π/2 ; pour un angle obtus, cos Â < 0 et a² > b² + c². Réciproquement, cos Â = (b² + c² − a²)/(2bc) donne un angle à partir des trois côtés.
