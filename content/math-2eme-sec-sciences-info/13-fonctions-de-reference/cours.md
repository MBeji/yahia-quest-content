# ⚔️ Fonctions de référence — reconnaître une courbe à sa formule

> 💡 «Une poignée de courbes de base et deux gestes, décaler et retourner : avec eux, une formule se lit comme un plan et se dessine sans tâtonner.»

Au chapitre précédent, tu as appris à lire une courbe. Ici, tu apprends à la **prévoir** : à partir d'une formule, dire quelle courbe elle dessine, où sont son sommet ou son centre, et où elle s'approche sans toucher. Huit étapes te mènent de la parabole aux hyperboles, puis à la lecture graphique des équations et des inéquations. On suppose acquis le sens de variation (chapitre 12), les translations et les homothéties (chapitres 7 et 8).

## 🏹 La parabole : la fonction x ↦ ax²

Un carré de côté x mètres a pour aire x² m². Mais la fonction x ↦ x² accepte aussi les x négatifs : −3 et 3 ont le même carré, 9.
Quelle courbe dessinent tous les points (x ; x²), et que devient-elle si l'on remplace x² par 2x², ou par −2x² ?

::: definition
Le plan est muni d'un repère orthogonal (O, i⃗, j⃗). La courbe P de la fonction f définie sur ℝ par f(x) = x² est la **parabole** d'équation y = x².

Le point O est le **sommet** de la parabole ; la droite d'équation x = 0 est son **axe**.
:::

Le sommet est le « fond » de la courbe, et l'axe la verticale qui passe par ce fond : c'est le nombre 0 de l'équation x = 0 qui fixe sa position.

::: exemple De x² à 2x²
1. Pour x = −3, −2, −1, 0, 1, 2, 3, le carré x² vaut 9, 4, 1, 0, 1, 4, 9 et 2x² vaut 18, 8, 2, 0, 2, 8, 18 : on double chaque ordonnée, puisqu'on multiplie x² par 2.
2. Pour g(x) = 2x², on a g(−x) = 2(−x)² = 2x² = g(x) : g est paire, donc sa courbe est symétrique par rapport à l'axe (Oy), comme P.
3. L'homothétie de centre O et de rapport 1/2 envoie M(x ; y) de P sur M′(x/2 ; y/2). Or y/2 = x²/2 = 2(x/2)² : M′ est sur la courbe de g. Réciproquement, tout point (x′ ; 2x′²) vient de (2x′ ; 4x′²), qui est sur P.
4. Pour x = 10³ puis 10⁴, x² vaut 10⁶ puis 10⁸ : en prenant x assez grand, x² dépasse n'importe quel réel A. On dit que x² **tend vers +∞** quand x tend vers +∞.

:::

::: piege Croire que x ↦ x² est croissante sur tout ℝ
On écrit « −3 < −1, donc (−3)² < (−1)² ». Cela tente parce que, pour des nombres positifs, un plus grand nombre a un plus grand carré. Mais (−3)² = 9 et (−1)² = 1 : 9 > 1. Sur ]−∞ ; 0] la fonction décroît : la courbe descend jusqu'au sommet, puis remonte.
:::

::: propriete
Soit a un réel non nul. La courbe de f : x ↦ ax² est une parabole de sommet O et d'axe la droite x = 0.

- Si a > 0 : f(x) ≥ 0 ; f décroît sur ]−∞ ; 0], croît sur [0 ; +∞[ ; minimum 0 en 0 ; f(x) tend vers +∞ quand x tend vers +∞ ou vers −∞.
- Si a < 0 : f(x) ≤ 0 ; f croît sur ]−∞ ; 0], décroît sur [0 ; +∞[ ; maximum 0 en 0 ; f(x) tend vers −∞.

Cas limite : quel que soit a, le sommet reste O, car f(0) = 0.
:::

::: verifie Un point et des variations
Soit h(x) = −3x². Le point A(−2 ; −12) est-il sur la courbe de h ? Quel est le sens de variation de h sur [0 ; +∞[, et quel est son extremum ?
---
On remplace x par −2 : h(−2) = −3 × (−2)² = −3 × 4 = −12, qui est l'ordonnée de A : A est sur la courbe. Ici a = −3 < 0 : la parabole est tournée vers le bas, h décroît sur [0 ; +∞[ et admet un maximum égal à 0, atteint en 0.
:::

::: retenir
La courbe de ax² est une parabole de sommet O et d'axe x = 0 : tournée vers le haut si a > 0 (minimum 0), vers le bas si a < 0 (maximum 0).
:::

Le 2 de « x − 2 » est l'abscisse du sommet, le 1 ajouté à la fin est son ordonnée : la flèche violette va de 0 à 2 vers la droite et de 0 à 1 vers le haut.

::: exemple La courbe de f(x) = (x − 2)² + 1
1. M(x ; y) est sur C ⟺ y = (x − 2)² + 1 ⟺ y − 1 = (x − 2)² : le point N(x − 2 ; y − 1) est alors sur P, car ses coordonnées vérifient y = x².
2. N est M décalé de 2 vers la gauche et de 1 vers le bas : C est donc l'image de P par la translation de vecteur 2i⃗ + j⃗. Le sommet O devient S(2 ; 1) et l'axe x = 0 devient x = 2.
3. Contrôle : f(2) = 1 est la plus petite valeur, et f(1) = f(3) = 2 : les points d'abscisses 1 et 3 sont symétriques par rapport à x = 2.

Autre exemple, sans contexte : g(x) = −2(x + 1)² + 3. On écrit x + 1 = x − (−1), donc α = −1 et β = 3 : sommet S(−1 ; 3), axe x = −1. Comme a = −2 < 0, g admet un maximum 3, atteint en −1. Contrôle : g(0) = −2 + 3 = 1 = g(−2).

:::

::: piege Lire le sommet S(−2 ; 1) dans (x − 2)² + 1
On recopie le « 2 » avec son signe moins. Cela tente parce que le 2 est écrit « avec un moins ». Mais le carré s'annule quand x − 2 = 0, c'est-à-dire pour x = 2. Test : f(−2) = (−4)² + 1 = 17, alors que f(2) = 1. Le sommet est en α, pas en −α.
:::

::: propriete
Soit a un réel non nul, α et β deux réels. La courbe de f : x ↦ a(x − α)² + β est une parabole de sommet S(α ; β) et d'axe la droite x = α. C'est l'image de la parabole de ax² par la translation de vecteur αi⃗ + βj⃗.

- Si a > 0, f décroît sur ]−∞ ; α], croît sur [α ; +∞[, et son minimum est β, atteint en α.
- Si a < 0, c'est l'inverse : maximum β, atteint en α.

Cas limites : si β = 0, f(x) = a(x − α)² a pour sommet S(α ; 0) ; si α = 0, f(x) = ax² + β a pour sommet S(0 ; β) et pour axe x = 0.
:::

::: verifie Sommet, axe, extremum
Donner le sommet, l'axe et l'extremum de f(x) = 3(x − 4)² − 2.
---
Ici α = 4 (le carré s'annule en x = 4) et β = −2 : le sommet est S(4 ; −2) et l'axe est la droite x = 4. Comme a = 3 > 0, la parabole est tournée vers le haut : f admet un minimum égal à −2, atteint en 4.
:::

::: retenir
La courbe de a(x − α)² + β est la parabole de ax² translatée : sommet S(α ; β), axe x = α, avec α lu après le signe moins de (x − α).
:::

::: exemple Trouver le sommet de h(t) = −5t² + 10t
1. On met a = −5 en facteur devant les deux termes en t : h(t) = −5(t² − 2t), pour faire apparaître un carré.
2. On complète : t² − 2t = (t − 1)² − 1, car (t − 1)² = t² − 2t + 1.
3. On distribue −5 sur les deux termes : h(t) = −5[(t − 1)² − 1] = −5(t − 1)² + 5. Le −1 est multiplié par −5.
4. C'est la forme a(t − α)² + β avec α = 1 et β = 5 : sommet S(1 ; 5). Comme a < 0, c'est un maximum : le ballon est le plus haut après 1 s, à 5 m. Contrôle : h(1) = −5 + 10 = 5.

Autre exemple, sans contexte : f(x) = 3x² − 12x + 7. On calcule α = 12/6 = 2, puis β = f(2) = 12 − 24 + 7 = −5. Donc f(x) = 3(x − 2)² − 5. Contrôle : 3(x² − 4x + 4) − 5 = 3x² − 12x + 7.

Lecture graphique sur cette parabole, tournée vers le haut (donc a > 0) : l'ordonnée du point d'abscisse 0 est c = 7 ; l'abscisse du sommet est α = −b/(2a) = 2, donc b = −2aα est du signe de −aα, ici négatif (b = −12) ; et comme a > 0 et β = −5 < 0, la courbe coupe l'axe des abscisses en deux points : le trinôme a deux racines.

:::

::: piege Oublier de multiplier par a le nombre ajouté pour compléter le carré
On écrit h(t) = −5[(t − 1)² − 1] = −5(t − 1)² − 1. Cela tente parce que, pour a = 1, on peut recopier le −1 tel quel. Mais −5 multiplie les deux termes du crochet. Test : cette écriture donne h(1) = −1, alors que h(1) = 5. Le bon terme est −5 × (−1) = +5.
:::

::: methode
Pour f(x) = ax² + bx + c avec a ≠ 0, le carré complété donne ax² + bx + c = a(x + b/(2a))² + c − b²/(4a). En pratique :

1. α = −b/(2a).
2. β = f(α) : on remplace x par α dans la formule.
3. f(x) = a(x − α)² + β : sommet S(α ; β), axe x = α ; minimum β si a > 0, maximum β si a < 0.

Cas limite : si b = 0, alors α = 0 et le sommet est S(0 ; c) : il n'y a rien à compléter.
:::

::: exemple La fonction f(x) = √(x + 4)
1. Existence : la racine exige x + 4 ≥ 0, donc x ≥ −4. L'ensemble de définition est [−4 ; +∞[.
2. Variation : si −4 ≤ a ≤ b, alors 0 ≤ a + 4 ≤ b + 4, donc √(a + 4) ≤ √(b + 4), car la racine carrée est croissante. Donc f est croissante.
3. Courbe : M(x ; y) est sur la courbe de f ⟺ y = √(x + 4) ⟺ N(x + 4 ; y) est sur la courbe de √x. La courbe de f est donc l'image de celle de √x par la translation de vecteur −4i⃗. Points : f(−4) = 0, f(−3) = 1, f(0) = 2, f(5) = 3.
4. Comportement : √(x + 4) > 100 ⟺ x + 4 > 10⁴ ⟺ x > 9 996. Donc f(x) tend vers +∞, mais lentement.

:::

::: piege Écrire √(x + 4) = √x + 2
On écrit « √(x + 4) = √x + √4 = √x + 2 ». Cela tente parce qu'on distribue comme avec une multiplication. Mais pour x = 5, √9 = 3, alors que √5 + 2 ≈ 4,24. Et pour x = −1, √3 existe alors que √(−1) n'existe pas. La racine d'une somme n'est pas la somme des racines.
:::

::: propriete
Soit b un réel. La fonction f : x ↦ √(x + b) est définie sur [−b ; +∞[ et croissante. Sa courbe est l'image de celle de √x par la translation de vecteur −bi⃗, et elle part du point (−b ; 0).

Cas limites : si b = 0, on retrouve √x ; si b < 0, la translation va vers la droite : pour b = −3, f est définie sur [3 ; +∞[.
:::

::: verifie Ensemble de définition et point de départ
Pour f(x) = √(x − 3), donner l'ensemble de définition, le vecteur de translation, le point de départ de la courbe et f(12).
---
La racine exige x − 3 ≥ 0 : l'ensemble de définition est [3 ; +∞[. Ici b = −3, donc la courbe de √x est translatée du vecteur 3i⃗, vers la droite, et part de (3 ; 0). Enfin f(12) = √9 = 3.
:::

::: retenir
La courbe de √(x + b) est celle de √x translatée du vecteur −bi⃗ : définie sur [−b ; +∞[, croissante, partant du point (−b ; 0).
:::

Près de l'axe (Oy), la courbe monte ou descend très haut ; loin de O, elle se colle à l'axe (Ox). Ces deux axes sont les asymptotes.

::: exemple La fonction f(x) = 1/x
1. Avec les nombres du trajet : f(4) = 0,25, f(1 000) = 0,001 et f(0,01) = 100. Pour x = 10⁻⁶, f(x) = 10⁶ : quand x > 0 tend vers 0, f(x) tend vers +∞.
2. Plus x grandit, plus 1/x se rapproche de 0 : f(x) tend vers 0 quand x tend vers +∞.
3. f(−x) = 1/(−x) = −1/x = −f(x) : f est impaire, donc H est symétrique par rapport à O. On en déduit la branche des x négatifs : f(−4) = −0,25.
4. Si 0 < a < b, alors 1/a > 1/b : f est décroissante sur ]0 ; +∞[. Le même raisonnement donne la décroissance sur ]−∞ ; 0[.

Autre exemple, sans contexte : g(x) = −2/x. On multiplie chaque ordonnée de 1/x par −2 : g(1) = −2, g(−1) = 2, g(4) = −0,5. La courbe est dans les angles où x et y sont de signes contraires.

:::

::: piege Croire que 1/x est décroissante sur ℝ* tout entier
On écrit « 1/x décroît sur ]0 ; +∞[ et sur ]−∞ ; 0[, donc sur ℝ* ». Cela tente parce que les deux morceaux descendent. Mais −1 < 1 et f(−1) = −1 < f(1) = 1 : l'ordre n'est pas renversé. On ne peut pas recoller deux intervalles séparés par la valeur interdite 0.
:::

La courbe de a/x est une hyperbole de centre O et d'asymptotes x = 0 et y = 0 ; monotone sur chacun des deux intervalles ]−∞ ; 0[ et ]0 ; +∞[, jamais sur ℝ* entier.

Le centre I est à l'intersection des deux asymptotes : son abscisse est la valeur interdite 1, son ordonnée est le 2 ajouté.

::: exemple La courbe de f(x) = 3/(x − 1) + 2
1. Ensemble de définition : x − 1 ≠ 0, donc ℝ \ {1}.
2. M(x ; y) est sur C ⟺ y − 2 = 3/(x − 1) ⟺ N(x − 1 ; y − 2) est sur H₃, la courbe de x ↦ 3/x. Donc C est l'image de H₃ par la translation de vecteur i⃗ + 2j⃗.
3. Le centre O devient I(1 ; 2) ; les asymptotes x = 0 et y = 0 deviennent x = 1 et y = 2.
4. Contrôle : f(2) = 3 + 2 = 5, f(0) = −3 + 2 = −1, f(4) = 1 + 2 = 3, f(−2) = −1 + 2 = 1. Et f(x) − 2 = 3/(x − 1) n'est jamais nul : la courbe ne coupe pas la droite y = 2.

Autre exemple, sans contexte : g(x) = −2/(x + 3). On écrit x + 3 = x − (−3) et β = 0 : g est définie sur ℝ \ {−3}, de centre I(−3 ; 0), d'asymptotes x = −3 et y = 0. Comme a = −2 < 0, g est croissante sur chaque intervalle de son ensemble de définition.

:::

::: piege Prendre x = β pour asymptote verticale
Pour f(x) = 1/x + 3, on écrit « l'asymptote verticale est x = 3, puisque 3 apparaît dans la formule ». Cela tente parce que 3 est le seul nombre visible. Mais x = 3 est permis : f(3) = 1/3 + 3 = 10/3. La valeur interdite est celle qui annule le dénominateur, x = 0. Le 3 est ajouté aux ordonnées : 1/x tend vers 0, donc f(x) tend vers 3 et la droite y = 3 est l'asymptote horizontale.
:::

::: propriete
Soit a un réel non nul, α et β deux réels. La courbe de f : x ↦ a/(x + α) + β, définie sur ℝ \ {−α}, est une hyperbole de centre I(−α ; β), d'asymptotes les droites x = −α et y = β. C'est l'image de la courbe de a/x par la translation de vecteur −αi⃗ + βj⃗.

- Si a > 0, f est décroissante sur chaque intervalle de son ensemble de définition ; si a < 0, elle est croissante.

Cas limites : si α = 0, f(x) = a/x + β a pour centre I(0 ; β) ; si β = 0, f(x) = a/(x + α) a pour centre I(−α ; 0).
:::

Le 3 qui annule le dénominateur donne l'asymptote verticale x = 3, et le 2 du numérateur, rapporté au 1 du dénominateur, donne l'asymptote horizontale y = 2.

::: exemple Ramener (2x + 1)/(x − 3) à la forme β + k/(x − 3)
1. Ensemble de définition : x − 3 ≠ 0, donc ℝ \ {3}.
2. On fait apparaître le dénominateur au numérateur : 2x + 1 = 2(x − 3) + 7, car 2(x − 3) = 2x − 6 et 1 = −6 + 7.
3. On sépare : f(x) = 2 + 7/(x − 3), de la forme a/(x + α) + β avec a = 7, α = −3, β = 2. Le centre est I(3 ; 2), les asymptotes sont x = 3 et y = 2.
4. Contrôle : f(4) = 9/1 = 9 = 2 + 7 ; f(0) = 1/(−3) = −1/3 = 2 + 7/(−3).

Autre exemple, sans contexte : g(x) = (3x − 2)/(2x + 4). Avec a = 3, b = −2, c = 2, d = 4, le centre est I(−d/c ; a/c) = I(−2 ; 3/2) : asymptotes x = −2 et y = 3/2. Contrôle : 3/2 × (2x + 4) = 3x + 6, donc g(x) = 3/2 − 8/(2x + 4).

:::

::: piege Croire que toute fraction (ax + b)/(cx + d) avec c ≠ 0 est une hyperbole
Pour f(x) = (2x + 6)/(x + 3), on écrit « centre I(−3 ; 2) ». Cela tente parce que c = 1 ≠ 0. Mais 2x + 6 = 2(x + 3), donc f(x) = 2 pour tout x ≠ −3 : la courbe est une droite horizontale privée d'un point, pas une hyperbole. Ici ad − bc = 2 × 3 − 6 × 1 = 0.
:::

::: propriete
Soit a, b, c, d quatre réels, avec c ≠ 0 et ad − bc ≠ 0. La courbe de f : x ↦ (ax + b)/(cx + d), définie sur ℝ privé de −d/c, est une hyperbole de centre I(−d/c ; a/c), d'asymptotes les droites x = −d/c et y = a/c.

Cas limite : si ad − bc = 0, f est constante, égale à a/c, sur son ensemble de définition. Si c = 0, f est une fonction affine.
:::

::: verifie Centre d'une fraction
Donner l'ensemble de définition, le centre et les asymptotes de h(x) = (5x − 3)/(x + 1).
---
Le dénominateur s'annule en x = −1 : l'ensemble de définition est ℝ \ {−1}. Ici ad − bc = 5 × 1 − (−3) × 1 = 8 ≠ 0, donc c'est une hyperbole, de centre I(−d/c ; a/c) = I(−1 ; 5). Les asymptotes sont x = −1 et y = 5. Contrôle : 5(x + 1) − 8 = 5x − 3, donc h(x) = 5 − 8/(x + 1).
:::

::: retenir
La courbe de (ax + b)/(cx + d), avec c ≠ 0 et ad − bc ≠ 0, est une hyperbole de centre I(−d/c ; a/c) ; si ad − bc = 0, la fonction est constante.
:::

Pour un même x, la courbe la plus haute est celle de la plus grande valeur : lire l'ordre des courbes, c'est ranger les nombres.

::: exemple Ranger quatre nombres, puis résoudre 1/x > 2
1. Pour x = 0,25 : x² = 0,0625, x = 0,25, √x = 0,5, 1/x = 4. Donc x² < x < √x < 1/x.
2. Pour x = 4 : 1/x = 0,25, √x = 2, x = 4, x² = 16. Donc 1/x < √x < x < x². L'ordre s'est inversé, car les courbes se croisent en (1 ; 1), seule valeur de x où les quatre nombres sont égaux.
3. Pour 1/x > 2, on trace la droite y = 2. Elle coupe l'hyperbole en (1/2 ; 2), car 1/x = 2 ⟺ x = 1/2. L'hyperbole est au-dessus de la droite pour 0 < x < 1/2 seulement : la branche des x négatifs est sous l'axe (Ox), donc sous la droite.
4. Contrôle par le calcul : pour x > 0, 1/x > 2 ⟺ 1 > 2x ⟺ x < 1/2 ; pour x < 0, 1/x est négatif, donc inférieur à 2 : aucune solution. Donc S = ]0 ; 1/2[.

::: piege Multiplier par x sans regarder son signe
On écrit « 1/x > 2 ⟹ 1 > 2x ⟹ x < 1/2 », donc S = ]−∞ ; 1/2[. Cela tente parce qu'on multiplie les deux membres par x comme par un nombre positif. Mais pour x < 0 l'inégalité change de sens. Test : x = −1 donne 1/x = −1, qui n'est pas supérieur à 2. La bonne réponse est S = ]0 ; 1/2[.
:::

::: methode
Pour résoudre f(x) > g(x), ou avec <, ≥, ≤ :

1. Tracer les deux courbes (ou la courbe et la droite y = k) dans le même repère.
2. Lire les abscisses des points d'intersection : ce sont les solutions de f(x) = g(x).
3. Repérer les intervalles où la courbe de f est au-dessus de celle de g (pour >) ou au-dessous (pour <), et lire leurs bornes sur l'axe des abscisses.
4. Contrôler par le calcul, en discutant le signe quand on multiplie ; crochets ouverts pour < et >, fermés pour ≤ et ≥.

Cas limite : une valeur interdite, comme 0 pour 1/x, n'est jamais dans l'ensemble des solutions : son crochet est toujours ouvert.
:::

::: verifie Résoudre x² ≥ 9
Résoudre x² ≥ 9 avec la parabole d'équation y = x² et la droite y = 9, puis contrôler par le calcul.
---
La droite y = 9 coupe la parabole en x = −3 et x = 3. La parabole est au-dessus de la droite à l'extérieur de ces abscisses, et sur elle en −3 et 3 : comme l'inégalité est large, les crochets sont fermés, S = ]−∞ ; −3] ∪ [3 ; +∞[. Contrôle : x = −4 donne 16 ≥ 9, vrai ; x = 0 donne 0 ≥ 9, faux.
:::

::: retenir
Pour une inéquation, on lit les abscisses où une courbe est au-dessus ou au-dessous de l'autre, puis on contrôle par le calcul sans oublier les valeurs interdites.
:::
