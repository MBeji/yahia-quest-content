# 📜 Résumé : Fonctions de référence

- **Parabole de ax²** : la courbe est une parabole de sommet O et d'axe x = 0 ; tournée vers le haut si a > 0 (minimum 0 en 0, f décroît sur ]−∞ ; 0] puis croît), vers le bas si a < 0 (maximum 0 en 0). Le carré n'est pas croissant sur ℝ : (−3)² > (−1)².
- **Translation de la parabole** : la courbe de a(x − α)² + β est une parabole de sommet S(α ; β) et d'axe x = α, image de celle de ax² par la translation de vecteur αi⃗ + βj⃗. Le sommet de (x − 2)² + 1 est S(2 ; 1), pas S(−2 ; 1).
- **Trinôme ax² + bx + c** : α = −b/(2a), β = f(α), donc f(x) = a(x − α)² + β ; sommet S(α ; β), axe x = α, minimum β si a > 0, maximum β si a < 0. En complétant le carré, le nombre ajouté est multiplié par a.
- **Racine carrée** : √x est définie sur [0 ; +∞[ et croissante ; la courbe de √(x + b) est son image par la translation de vecteur −bi⃗, définie sur [−b ; +∞[, partant de (−b ; 0). √(x + 4) n'est pas √x + 2.
- **Hyperbole de a/x** : définie sur ℝ*, de centre O et d'asymptotes x = 0 et y = 0 ; impaire ; branches où x et y ont le même signe si a > 0 (décroissante sur chaque intervalle), de signes contraires si a < 0 (croissante sur chaque intervalle). Jamais monotone sur ℝ* entier.
- **Hyperbole de a/(x + α) + β** : définie sur ℝ \ {−α}, de centre I(−α ; β), d'asymptotes x = −α (valeur interdite) et y = β (valeur vers laquelle f(x) tend). Dans 1/x + 3, l'asymptote horizontale est y = 3 et x = 3 n'est pas interdit.
- **Fraction (ax + b)/(cx + d)** : avec c ≠ 0 et ad − bc ≠ 0, hyperbole de centre I(−d/c ; a/c), d'asymptotes x = −d/c et y = a/c ; on fait apparaître le dénominateur au numérateur pour s'en assurer. Si ad − bc = 0, f est constante.
- **Comparer et résoudre** : x, x², √x et 1/x se croisent en (1 ; 1) et leur ordre s'inverse de part et d'autre de 1. Pour f(x) > g(x), on lit les abscisses où la courbe de f est au-dessus de celle de g, puis on contrôle par le calcul en discutant le signe ; une valeur interdite n'est jamais solution.
