# 📜 Résumé : Géométrie analytique

- **Milieu et barycentre** : le milieu de [AB] a pour coordonnées les moyennes des coordonnées de A et de B ; le barycentre de (A, α) et (B, β) a pour coordonnées (αxA + βxB)/(α + β) et (αyA + βyB)/(α + β), avec α + β ≠ 0 (même principe à trois points). On divise par la somme des coefficients, pas par 2.
- **Équation cartésienne d'une droite** : D : ax + by + c = 0 avec (a ; b) ≠ (0 ; 0) ; M est sur D si et seulement si ses coordonnées vérifient l'équation, terme constant compris. Pour (AB) : AM⃗ et AB⃗ colinéaires, déterminant nul. Pour tracer, on cherche deux points ; si b = 0 la droite est verticale.
- **Vecteur directeur et parallélisme** : un vecteur directeur de ax + by + c = 0 est (−b ; a), pas (a ; b). D ∥ D′ si et seulement si ab′ − a′b = 0 (strictement parallèles ou confondues : on teste un point) ; sinon les droites sont sécantes, en un point donné par un système.
- **Vecteur normal et perpendiculaires** : en repère orthonormé, (a ; b) est un vecteur normal à ax + by + c = 0, et D ⊥ D′ si et seulement si aa′ + bb′ = 0. La droite passant par A de vecteur normal (p ; q) est p(x − xA) + q(y − yA) = 0. Ne pas confondre avec ab′ − a′b = 0, le parallélisme.
- **Équation réduite et pente** : si b ≠ 0, y = mx + p avec m = −a/b et p = −c/b ; m = (yB − yA)/(xB − xA) par deux points, u⃗(1 ; m) est directeur et tan α = |m|. D ∥ D′ si et seulement si m = m′, D ⊥ D′ si et seulement si mm′ = −1 ; une droite x = k n'a pas de pente.
- **La fonction x ↦ |ax + b|** : égale à ax + b là où ax + b ≥ 0, et à −ax − b ailleurs (tous les termes changent de signe) ; sa courbe est un V dont la pointe (−b/a ; 0) est sur l'axe des abscisses, symétrique par rapport à x = −b/a. Pour résoudre, on traite chaque branche et on vérifie son intervalle.
- **Distance d'un point à une droite** : en repère orthonormé, d(A ; D) = |axA + byA + c| / √(a² + b²), égale à AH où H est le projeté orthogonal de A sur D. La racine ne s'oublie pas, et d = 0 si et seulement si A est sur D.
- **Équation d'un cercle** : le cercle de centre I(a ; b) et de rayon R est (x − a)² + (y − b)² = R² ; comparer (x − a)² + (y − b)² à R² place un point sur, dans ou hors du cercle. x² + y² + px + qy + r = 0 se ramène à cette forme en complétant les carrés. Une droite D coupe le cercle en deux points si d(I ; D) < R, lui est tangente si d(I ; D) = R, et l'évite si d(I ; D) > R.
