# 📜 Résumé : Statistiques

- **Série, effectif, fréquence** : la **population** est l'ensemble étudié, l'**échantillon** la partie observée, le **caractère** ce que l'on note (qualitatif, ou quantitatif discret ou continu). L'effectif nᵢ compte les individus, la fréquence fᵢ = nᵢ / n les rapporte à la taille de l'échantillon ; les fréquences totalisent 1. Bâtons pour un caractère discret, histogramme pour un caractère continu.
- **Série chronologique** : coefficient multiplicateur c = v / v₀ (valeur de l'année divisée par la valeur de base), indice = 100 × c, base à 100. L'écart entre l'indice et 100 donne la variation en % : l'indice 147 veut dire environ +47 %, pas +147 %.
- **Mode et médiane** : le mode est la valeur d'effectif maximal. La médiane se lit sur la série rangée, avec les effectifs cumulés croissants : rang (n + 1) / 2 si n est impair, moyenne des rangs n / 2 et n / 2 + 1 si n est pair.
- **Quartiles et boîte** : Q₁ et Q₃ sont les plus petites valeurs dont le cumul atteint au moins 25 % et 75 % de l'effectif ; Q₂ est la médiane. Le rang calculé (25 % de 20 font 5) n'est pas le quartile : c'est la valeur à ce rang. L'écart interquartile Q₃ − Q₁ mesure la dispersion centrale, l'étendue dépend des extrêmes ; la boîte va de Q₁ à Q₃ avec un trait à la médiane.
- **Classes et interpolation** : pour une série regroupée, on suppose les valeurs régulièrement réparties dans chaque classe. Pour m, on cherche la classe où le cumul atteint N / 2 : m = a + (N / 2 − c) / n_c × (b − a) ; même méthode pour Q₁ (N / 4) et Q₃ (3N / 4). La médiane n'est pas le centre de la classe médiane.
- **Moyenne** : x̄ = (n₁x₁ + … + nₚxₚ) / n, avec les centres pour des classes ; chaque valeur est pondérée par son effectif. Moyennes partielles : z̄ = (p x̄ + q ȳ) / (p + q). Transformation affine : la série (a xᵢ + b) a pour moyenne a x̄ + b. Une valeur isolée tire la moyenne ; la moyenne élaguée l'écarte.
- **Variance et écart type** : V = (n₁x₁² + … + nₚxₚ²) / n − x̄² et σ = √V ; on n'oublie pas de retrancher x̄². Une translation ne change pas σ, un facteur a le multiplie par |a| (la variance par a²). Les intervalles [x̄ − σ ; x̄ + σ] et [x̄ − 2σ ; x̄ + 2σ] se lisent comme des proportions de la série.
- **Effet de structure** : le taux global est une moyenne pondérée des taux des sous-groupes, pesés par leurs effectifs. Il peut baisser alors que chaque taux de détail monte, si la composition de la population change ; ce n'est la moyenne simple des taux que si les effectifs sont égaux (ou les taux égaux).
