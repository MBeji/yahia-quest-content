# ⚔️ Études de fonctions — dresser le portrait d'une courbe

> 💡 «Avant de tracer une courbe, on l'interroge : se répète-t-elle, est-elle symétrique, de quelle droite se rapproche-t-elle ? Chaque réponse économise des calculs.»

Bienvenue, héros de la section Sciences de l'informatique. Ce chapitre réunit tes outils (limites, continuité, dérivée) pour étudier une fonction de bout en bout. Huit notions : la périodicité, l'axe et le centre de symétrie, la décomposition d'une fraction rationnelle, la position d'une courbe par rapport à sa tangente, l'étude complète d'une fonction rationnelle, puis les fonctions x ↦ √(ax² + bx + c) en trois étapes. Une ouverture clôt le chapitre : la méthode d'Euler, qui construit une courbe pas à pas. On suppose acquis les limites, les asymptotes et le critère de symétrie du chapitre 2 ; la dérivée, la dérivée seconde, l'équation d'une tangente et les demi-tangentes servent d'outils (chapitre 4).

## ⏱️ Périodicité : une période suffit

Un minuteur affiche la partie de la minute déjà écoulée : à l'instant x (en minutes), il montre g(x) = x − E(x), où E(x) est la partie entière de x. À x = 2,7 il montre 0,7 ; à x = 5,7 aussi 0,7 ; à x = 100,7 encore 0,7.
Pourquoi retrouve-t-on toujours la même valeur, et que dit la courbe de ce motif qui revient ?

::: definition
Une fonction f définie sur D est **périodique** s'il existe un réel T ≠ 0 tel que, pour tout x de D, x + T appartient à D et f(x + T) = f(x). Le réel T est une **période** de f ; la courbe de f est alors invariante par la translation de vecteur T i⃗.
:::

Le point plein est (n ; 0) et le cercle vide (n + 1 ; 1) : chaque segment commence à 0 et monte jusqu'à 1 sans l'atteindre. La flèche orange est le vecteur T i⃗, ici de longueur T = 1.

::: exemple Montrer que g(x) = x − E(x) est périodique de période 1, puis calculer g(−3,6)
1. Si n ≤ x < n + 1, alors n + 1 ≤ x + 1 < n + 2 : E(x + 1) = E(x) + 1, car décaler x d'un entier décale sa partie entière du même entier.
2. Donc g(x + 1) = x + 1 − E(x) − 1 = x − E(x) = g(x), et x + 1 est défini dès que x l'est : g est 1-périodique.
3. En répétant, g(x + 4) = g(x) : g(−3,6) = g(−3,6 + 4) = g(0,4) = 0,4, car E(0,4) = 0.
4. Contrôle direct : E(−3,6) = −4, donc g(−3,6) = −3,6 + 4 = 0,4. Les deux chemins donnent le même résultat.

:::

::: piege Prendre 2π pour toute fonction construite avec sin ou cos
Les fonctions sin et cos sont 2π-périodiques, et l'on affirme que x ↦ sin(πx/3) a aussi pour période 2π. Cela tente parce que « c'est un sinus ». Mais f(0) = 0 alors que f(2π) = sin(2π²/3) ≈ 0,29 : 2π n'est pas une période. L'argument πx/3 augmente de 2π quand x augmente de T avec πT/3 = 2π, c'est-à-dire T = 6.
:::

::: propriete
Soit f une fonction T-périodique et a, b deux réels avec a ≠ 0.

- La fonction x ↦ f(ax + b) est périodique de période T/|a|. En particulier x ↦ cos(ωx + φ) et x ↦ sin(ωx + φ) ont pour période 2π/|ω|.
- On a f(x + kT) = f(x) pour tout entier relatif k : il suffit d'étudier f sur un intervalle de longueur T, par exemple [0 ; T[, puis de translater la courbe par des vecteurs kT i⃗.

Cas limite : une fonction constante est périodique, et tout réel non nul est une période ; en général on cherche la plus petite période strictement positive.
:::

::: verifie
Un ressort oscille selon y(t) = cos(4πt + π/3), t en secondes. Quelle est la période de y ?

---

On a y(t) = cos(ωt + φ) avec ω = 4π : la période est 2π/|ω| = 2π/(4π) = 1/2 seconde. Contrôle : y(t + 1/2) = cos(4πt + 2π + π/3) = cos(4πt + π/3) = y(t), car cos est 2π-périodique. Le décalage π/3 ne change pas la période.
:::

::: retenir
f est T-périodique si f(x + T) = f(x) sur tout le domaine : on l'étudie sur une période et l'on complète la courbe par translations ; x ↦ cos(ωx + φ) a pour période 2π/|ω|.
:::

La droite orange pointillée x = 3 est le milieu des deux asymptotes verticales x = 1 et x = 5 : c'est le candidat naturel pour l'axe. Il reste à le prouver par le calcul.

::: exemple La droite x = 3 est axe de symétrie de f(x) = (x² − 6x + 10)/(x² − 6x + 5)
1. D = ℝ ∖ {1 ; 5}. Si x ∈ D, alors x ≠ 1 et x ≠ 5, donc 6 − x ≠ 5 et 6 − x ≠ 1 : 6 − x ∈ D. Il faut d'abord vérifier que le symétrique de x reste dans le domaine.
2. (6 − x)² − 6(6 − x) = 36 − 12x + x² − 36 + 6x = x² − 6x : l'expression x² − 6x ne change pas quand on remplace x par 6 − x.
3. Donc f(6 − x) = (x² − 6x + 10)/(x² − 6x + 5) = f(x) pour tout x de D.
4. La droite x = 3 est axe de symétrie (6 = 2 × 3). On peut étudier f sur [3 ; +∞[ privé de 5, puis compléter la courbe par symétrie.

:::

::: piege Rejeter une symétrie parce que f(2a − x) n'est pas égal à f(x)
Soit h(x) = (x − 3)/(x² − 6x + 5). On calcule h(6 − x) = (3 − x)/(x² − 6x + 5) = −h(x), qui n'est pas h(x), et l'on conclut « pas de symétrie par rapport à x = 3 ». Cela tente parce que le test appris en premier est f(2a − x) = f(x). Mais h(6 − x) + h(x) = 0 = 2b avec b = 0 : le point (3 ; 0) est un centre de symétrie. Ce n'est pas la symétrie qui manque, c'est la mauvaise symétrie qu'on testait.
:::

::: propriete
Soit f définie sur D, a et b deux réels.

- **Axe** : la droite x = a est axe de symétrie si, pour tout x de D, 2a − x ∈ D et f(2a − x) = f(x).
- **Centre** : le point Ω(a ; b) est centre de symétrie si, pour tout x de D, 2a − x ∈ D et f(2a − x) + f(x) = 2b.
- Pour a = 0 on retrouve la parité : f est paire (axe des ordonnées) ou impaire (centre O).
- Pour chercher a : le milieu de deux valeurs interdites, de deux racines ou de deux asymptotes verticales. Pour chercher b : calculer (f(x) + f(2a − x))/2 pour une valeur de x, puis le prouver pour tout x.

Cas limite : si D n'est pas symétrique par rapport à a, il n'y a pas de symétrie, même si le calcul algébrique tombe juste : f(x) = (x − 2)² sur [0 ; 3] vérifie f(4 − x) = f(x), mais 4 − 0 = 4 n'appartient pas à [0 ; 3].
:::

Le point I est le milieu de [MM′] : (0 + (−4))/2 = −2 et (−0,5 + 6,5)/2 = 3. L'exemple suivant prouve que tout point de la courbe a son symétrique par rapport à I.

::: exemple Un centre de symétrie : g(x) = (3x − 1)/(x + 2)
1. g est définie sur ℝ ∖ {−2}. L'asymptote verticale est x = −2 et, en ±∞, g(x) tend vers 3x/x = 3 : les asymptotes se coupent en I(−2 ; 3), donc a = −2 et b = 3.
2. Si x ≠ −2, alors −4 − x ≠ −2 : 2a − x = −4 − x appartient à D.
3. g(−4 − x) = (3(−4 − x) − 1)/(−4 − x + 2) = (−3x − 13)/(−x − 2) = (3x + 13)/(x + 2).
4. Or 2b − g(x) = 6 − (3x − 1)/(x + 2) = (6x + 12 − 3x + 1)/(x + 2) = (3x + 13)/(x + 2). Donc g(−4 − x) + g(x) = 6 = 2b : I(−2 ; 3) est centre de symétrie.

:::

::: verifie
Montrer que la droite x = 2 est axe de symétrie de la courbe de k(x) = 1/(x² − 4x + 3).

---

x² − 4x + 3 = (x − 1)(x − 3), donc D = ℝ ∖ {1 ; 3}. Si x ∈ D, alors 4 − x ≠ 3 et 4 − x ≠ 1 : 4 − x ∈ D. Puis (4 − x)² − 4(4 − x) + 3 = 16 − 8x + x² − 16 + 4x + 3 = x² − 4x + 3, donc k(4 − x) = k(x) : l'axe est x = 2, milieu de 1 et 3. On a vérifié le domaine avant le calcul.
:::

::: retenir
Pour prouver un axe x = a ou un centre Ω(a ; b), on vérifie d'abord que 2a − x reste dans le domaine, puis f(2a − x) = f(x) (axe) ou f(2a − x) + f(x) = 2b (centre) ; le milieu de deux valeurs interdites est le candidat naturel pour a.
:::

## ✂️ Décomposer une fraction rationnelle : lire la courbe dans l'écriture

Soit f(x) = (2x² − 3x + 4)/(x − 1). Pour x = 11, f(11) = 213/10 = 21,3 ; pour x = 101, f(101) = 20 103/100 = 201,03. Les valeurs de 2x − 1 sont 21 et 201 : l'écart, 0,3 puis 0,03, fond quand x grandit.
Quelle écriture de f fait apparaître cet écart, et que nous apprend-elle sur la courbe ?

::: definition
**Décomposer** une fonction rationnelle f dont le numérateur a un degré de plus que le dénominateur, c'est l'écrire f(x) = ax + b + r(x), où r(x) est une fraction qui tend vers 0 en +∞ et en −∞, par exemple r(x) = c/(x − x₀). Le plus souvent, on trouve a, b, c par **identification** : deux polynômes égaux pour tout x ont les mêmes coefficients.
:::

L'écart vertical entre la courbe et la droite D est la fraction r(x) = 3/(x − 1) que l'exemple va faire apparaître.

::: exemple Décomposer f(x) = (2x² − 3x + 4)/(x − 1), puis lire la courbe
1. On cherche f(x) = ax + b + c/(x − 1), c'est-à-dire f(x) = ((ax + b)(x − 1) + c)/(x − 1) après réduction au même dénominateur.
2. (ax + b)(x − 1) + c = ax² + (b − a)x + (c − b). On identifie avec 2x² − 3x + 4 : a = 2, b − a = −3 et c − b = 4.
3. D'où b = −1 et c = 3 : f(x) = 2x − 1 + 3/(x − 1). Contrôle : f(11) = 21 + 0,3 = 21,3.
4. f(x) − (2x − 1) = 3/(x − 1) tend vers 0 en +∞ et en −∞ : la droite D : y = 2x − 1 est asymptote oblique. Le signe de 3/(x − 1) donne la position : C est au-dessus de D pour x > 1, au-dessous pour x < 1.
5. En 1, 3/(x − 1) tend vers +∞ à droite et −∞ à gauche : x = 1 est asymptote verticale. Elle coupe D en I(1 ; 1), car 2 × 1 − 1 = 1.

:::

::: piege Lire b dans le coefficient de x du numérateur
Pour (2x² − 3x + 4)/(x − 1), on lit « 2x² − 3x » et l'on écrit b = −3 : f(x) = 2x − 3 + c/(x − 1). Cela tente parce que les coefficients du numérateur semblent se retrouver tels quels. Mais le produit (ax + b)(x − 1) contient −ax + bx : le coefficient de x du numérateur est b − a, pas b. Ici b − a = −3 et a = 2 donnent b = −1. Contrôle : avec b = −3, f(11) devrait être proche de 2 × 11 − 3 = 19, alors que f(11) = 21,3.
:::

::: propriete
Si f(x) = ax + b + r(x) avec r(x) → 0 en +∞ (ou en −∞), la droite y = ax + b est asymptote oblique à C, et le signe de r(x) donne la position : C est au-dessus de la droite quand r(x) > 0, au-dessous quand r(x) < 0.

Si r(x) = c/(x − x₀) avec c ≠ 0, la droite x = x₀ est asymptote verticale et le point I(x₀ ; ax₀ + b), où les deux asymptotes se coupent, est centre de symétrie de C.

Avec deux valeurs interdites x₁ et x₂, on écrit de même f(x) = a + b/(x − x₁) + c/(x − x₂) : on réduit au même dénominateur, on identifie, et chaque valeur interdite donne une asymptote verticale, y = a étant asymptote horizontale.

Cas limite : si c = 0, la fraction se simplifie et f est une fonction affine privée d'un point.
:::

::: exemple Retrouver a, b, c à partir de trois valeurs : f(x) = (ax² + bx + c)/(x + 1) avec f(0) = 4, f(1) = 3 et f(3) = 4
1. f(0) = c/1 = 4 donne c = 4.
2. f(1) = (a + b + c)/2 = 3 donne a + b + c = 6, soit a + b = 2.
3. f(3) = (9a + 3b + c)/4 = 4 donne 9a + 3b + c = 16, soit 9a + 3b = 12, c'est-à-dire 3a + b = 4.
4. En soustrayant les deux équations en a et b : 2a = 2, donc a = 1, puis b = 1.
5. f(x) = (x² + x + 4)/(x + 1). Contrôle : f(3) = (9 + 3 + 4)/4 = 4. Chaque valeur connue de f donne une équation en a, b, c ; trois valeurs donnent un système de trois équations.

:::

::: verifie
Décomposer h(x) = (x² − 3x + 5)/(x − 2), puis donner l'asymptote oblique et la position de la courbe.

---

On écrit h(x) = ax + b + c/(x − 2) : (ax + b)(x − 2) + c = ax² + (b − 2a)x + (c − 2b), donc a = 1, b − 2 = −3 soit b = −1, et c + 2 = 5 soit c = 3. Ainsi h(x) = x − 1 + 3/(x − 2). La droite y = x − 1 est asymptote oblique ; 3/(x − 2) est positif pour x > 2, négatif pour x < 2 : la courbe est au-dessus de la droite à droite de 2 et au-dessous à gauche. On a identifié b − 2a, et non b, avec le coefficient de x.
:::

::: retenir
Écrire f(x) = ax + b + c/(x − x₀) donne d'un coup l'asymptote oblique y = ax + b, sa position par le signe de c/(x − x₀), l'asymptote verticale x = x₀ et le centre de symétrie ; on trouve a, b, c par identification des coefficients.
:::

## 📏 Position d'une courbe par rapport à sa tangente : le signe de l'écart

Pour f(x) = x/(x² + 1), la tangente en l'origine O est la droite T : y = x, car f(0) = 0 et f′(0) = 1. Près de O, la courbe reste-t-elle d'un seul côté de cette droite, ou la traverse-t-elle ?
Et que se passe-t-il en A(1 ; 1/2), où la tangente est horizontale ?

::: definition
Pour une droite D : y = mx + p, la position de la courbe C de f par rapport à D se lit sur le signe de l'**écart** d(x) = f(x) − (mx + p) : C est au-dessus de D là où d(x) > 0, au-dessous là où d(x) < 0, et elle coupe D là où d(x) = 0. Quand D est la tangente en A(a ; f(a)), d(x) = f(x) − f′(a)(x − a) − f(a).
:::

L'écart d(x) est la distance verticale entre la courbe et la droite : à gauche de O la courbe est au-dessus de T, à droite elle est au-dessous ; autour de A elle est au-dessous de T′. Les deux exemples le démontrent.

::: exemple Position de C par rapport à la tangente T : y = x en O
1. f′(x) = (1 − x²)/(x² + 1)², donc f′(0) = 1 et f(0) = 0 : la tangente en O est y = x.
2. d(x) = x/(x² + 1) − x = (x − x(x² + 1))/(x² + 1) = −x³/(x² + 1).
3. Le dénominateur est positif : d(x) a le signe de −x³, positif pour x < 0 et négatif pour x > 0.
4. La courbe est au-dessus de T à gauche de O et au-dessous à droite : elle traverse T en O.

:::

::: exemple Position de C par rapport à la tangente T′ en A(1 ; 1/2)
1. f(1) = 1/2 et f′(1) = (1 − 1)/4 = 0 : la tangente en A est horizontale, T′ : y = 1/2.
2. d(x) = x/(x² + 1) − 1/2 = (2x − (x² + 1))/(2(x² + 1)) = −(x − 1)²/(2(x² + 1)).
3. Un carré est positif : d(x) ≤ 0 des deux côtés de 1 et ne s'annule qu'en 1.
4. La courbe est au-dessous de T′ autour de A et la touche seulement en A : elle ne la traverse pas. A est le maximum de f.

:::

::: piege Croire qu'un zéro de l'écart est un croisement
Dans le second exemple, d(1) = 0 : on écrit « la tangente coupe la courbe en A, donc la traverse ». Cela tente parce que, pour la tangente en O, l'écart s'annulait aussi et la courbe traversait. Mais d(x) = −(x − 1)²/(2(x² + 1)) garde le même signe de part et d'autre de 1 : le carré (x − 1)² ne change pas de signe. Un zéro d'écart donne un point commun ; il faut regarder le signe de chaque côté pour savoir si la courbe traverse.
:::

::: propriete
Soit T la tangente à C en A(a ; f(a)) et d(x) = f(x) − T(x).

- d(a) = 0 : la courbe et sa tangente ont toujours A en commun.
- Si d(x) garde le même signe de part et d'autre de a, la courbe reste du même côté de T : au-dessus si d ≥ 0, au-dessous si d ≤ 0.
- Si d(x) change de signe en a, la courbe traverse sa tangente : A est un point d'inflexion (chapitre 4).

Cas limite : comme d(a) = 0 et que la pente de d s'annule aussi en a, l'écart contient en pratique le facteur (x − a)², toujours positif ; son signe est celui du facteur restant. C'est −x³/(x² + 1) = x² × (−x/(x² + 1)) en O, dont le second facteur change de signe, et −(x − 1)² × 1/(2(x² + 1)) en A, dont le second facteur est de signe constant.
:::

::: verifie
Soit f(x) = x²/(x² + 1). Donner la tangente en O, puis la position de la courbe par rapport à elle.

---

f(0) = 0 et f′(x) = 2x/(x² + 1)², donc f′(0) = 0 : la tangente est T : y = 0. L'écart est d(x) = x²/(x² + 1) − 0 = x²/(x² + 1) ≥ 0, qui ne s'annule qu'en 0 : la courbe est au-dessus de T et la touche seulement en O, sans la traverser. O est un minimum, pas un point d'inflexion. On a regardé le signe de d(x) de part et d'autre de 0.
:::

::: retenir
La position de C par rapport à une droite se lit sur le signe de d(x) = f(x) − (mx + p) ; pour la tangente en A, d(a) = 0 toujours, et la courbe traverse la tangente seulement si d change de signe en a.
:::

Les droites en pointillés x = −2, x = 2, y = 1 et le point (0 ; −2) sont les résultats des étapes 3 et 5 de l'exemple : le dessin est la dernière étape de l'étude, pas la première.

::: exemple Étude complète de g(x) = (x² + 8)/(x² − 4)
1. Domaine : x² − 4 = 0 pour x = ±2, donc D = ℝ ∖ {−2 ; 2}, ensemble symétrique par rapport à 0.
2. Parité : x n'apparaît que par x², donc g(−x) = g(x) : g est paire. On étudie sur [0 ; 2[ ∪ ]2 ; +∞[ et l'on complétera par symétrie par rapport à l'axe des ordonnées.
3. Écriture : g(x) = 1 + 12/(x² − 4), car (x² − 4) + 12 = x² + 8. En +∞, 12/(x² − 4) tend vers 0 : y = 1 est asymptote horizontale (en −∞ aussi, par parité). En 2⁺, x² − 4 tend vers 0⁺ : g tend vers +∞ ; en 2⁻, vers −∞ : x = 2 est asymptote verticale, et x = −2 aussi par symétrie.
4. Position : g(x) − 1 = 12/(x² − 4) est positif pour |x| > 2 et négatif pour |x| < 2 : la courbe est au-dessus de y = 1 à l'extérieur de ]−2 ; 2[, au-dessous à l'intérieur.
5. Dérivée : g′(x) = (2x(x² − 4) − (x² + 8) × 2x)/(x² − 4)² = −24x/(x² − 4)². Sur [0 ; +∞[ privé de 2, g′(x) ≤ 0 et ne s'annule qu'en 0, où g(0) = −2.
6. Tableau de variation sur [0 ; +∞[, donné après cet exemple : chaque intervalle a sa colonne et la valeur interdite 2 est écartée.
7. Tracé : asymptotes d'abord, puis (0 ; −2) et quelques points, g(1) = −3, g(3) = 17/5 = 3,4 et g(4) = 2 ; on dessine la branche de droite, puis on la reflète par rapport à l'axe des ordonnées.

:::

Le tableau de l'étape 6, sur [0 ; +∞[ :

| x | 0 | ]0 ; 2[ | 2 | ]2 ; +∞[ |
| --- | --- | --- | --- | --- |
| g′(x) | 0 | négative | non définie | négative |
| g(x) | −2 | décroît de −2 vers −∞ | interdite | décroît de +∞ vers 1 |

::: piege Réunir deux intervalles séparés par une valeur interdite
Le tableau montre g décroissante sur [0 ; 2[ et sur ]2 ; +∞[, et l'on écrit « g est décroissante sur [0 ; 2[ ∪ ]2 ; +∞[ ». Cela tente parce que la flèche descend des deux côtés. Mais une fonction décroissante sur un ensemble range l'ordre de deux nombres quelconques de cet ensemble : avec 1 et 3, on a 1 < 3 et pourtant g(1) = −3 < g(3) = 3,4. La phrase est fausse ; on énonce la monotonie intervalle par intervalle.
:::

::: methode Le plan d'étude d'une fonction rationnelle
1. Domaine, puis symétries (parité, axe, centre) pour réduire l'intervalle d'étude.
2. Limites aux bornes du domaine, asymptotes verticales, horizontales ou obliques, et position par le signe de f(x) − (ax + b).
3. Dérivée, signe, tableau de variation : un intervalle par colonne, la valeur interdite hors des flèches.
4. Points remarquables : intersections avec les axes, tangentes horizontales, points d'inflexion.
5. Tracé : asymptotes, puis points et tangentes, puis la courbe ; compléter par symétrie.

Cas limite : si l'étude est faite sur la moitié du domaine par symétrie, la limite aux bornes de l'autre moitié se déduit de la symétrie, on ne la recalcule pas.
:::

::: verifie
Pour h(x) = (x² − 5)/(x² − 1), donner la parité, h′(x) et le sens de variation de h sur [0 ; 1[.

---

D = ℝ ∖ {−1 ; 1} est symétrique par rapport à 0 et h(−x) = h(x) : h est paire. On écrit h(x) = 1 − 4/(x² − 1), donc h′(x) = 8x/(x² − 1)², qui est positif pour x > 0 et nul en 0 : h est croissante sur [0 ; 1[, de h(0) = 5 vers +∞ (en 1⁻, x² − 1 tend vers 0⁻ et −4/(x² − 1) vers +∞). On étudie un côté, puis la parité donne l'autre.
:::

::: retenir
Une étude de fonction rationnelle suit un ordre : domaine et symétries, limites et asymptotes, dérivée et tableau intervalle par intervalle, points remarquables, tracé.
:::

Le point (2 ; √3) du dessin est le point le plus bas : la distance minimale à la lampe est √3, quand le coureur est juste en dessous d'elle.

::: exemple Étudier f(x) = √(x² − 4x + 7)
1. Domaine : x² − 4x + 7 = (x − 2)² + 3 > 0 pour tout x, donc D = ℝ.
2. Axe : f(4 − x) = √((4 − x − 2)² + 3) = √((2 − x)² + 3) = f(x), et 4 − x ∈ ℝ : la droite x = 2 est axe de symétrie.
3. Dérivée : le radicande est strictement positif, donc f est dérivable sur ℝ et f′(x) = (2x − 4)/(2√(x² − 4x + 7)) = (x − 2)/√(x² − 4x + 7).
4. Signe : le dénominateur est positif, donc f′ a le signe de x − 2 : f décroît sur ]−∞ ; 2] et croît sur [2 ; +∞[, avec le minimum f(2) = √3.
5. Limites : le radicande tend vers +∞ aux deux extrémités, donc f(x) tend vers +∞ en +∞ et en −∞.

:::

::: piege Croire que le trinôme est positif entre ses racines
Soit g(x) = √(x² − 6x + 5). On factorise (x − 1)(x − 5) et l'on écrit « positif entre les racines, donc D = [1 ; 5] ». Cela tente parce que cette règle est celle des trinômes de coefficient dominant négatif. Mais ici le coefficient de x² est positif : le trinôme est positif à l'extérieur des racines. Contrôle : en x = 3, 9 − 18 + 5 = −4 < 0, alors que 3 ∈ [1 ; 5]. Le domaine est ]−∞ ; 1] ∪ [5 ; +∞[.
:::

::: propriete
Soit f(x) = √(P(x)) avec P(x) = ax² + bx + c et a > 0.

- Domaine : {x : P(x) ≥ 0}. Si P n'a pas de racine (ou une racine double), D = ℝ ; si P a deux racines x₁ < x₂, D = ]−∞ ; x₁] ∪ [x₂ ; +∞[.
- Axe : la droite x = −b/(2a) est axe de symétrie de la courbe, comme pour la parabole de P.
- Variations : là où P(x) > 0, f est dérivable et f′(x) = P′(x)/(2√(P(x))) a le signe de P′(x) = 2ax + b : f décroît avant −b/(2a) et croît après.

Cas limite : f vaut 0 aux racines de P et reste continue sur D, donc ses variations s'étendent aux extrémités fermées de chaque intervalle de D.
:::

::: exemple Variations de g(x) = √(x² − 6x + 5)
1. D = ]−∞ ; 1] ∪ [5 ; +∞[ (a > 0 : à l'extérieur des racines 1 et 5).
2. Axe : −b/(2a) = 3. On a g(6 − x) = g(x), car (6 − x)² − 6(6 − x) + 5 = x² − 6x + 5, et 6 − x ∈ D lorsque x ∈ D (x ≤ 1 équivaut à 6 − x ≥ 5).
3. Sur ]−∞ ; 1[ et sur ]5 ; +∞[, g′(x) = (x − 3)/√(x² − 6x + 5) : négatif sur ]−∞ ; 1[ puisque x − 3 < 0, positif sur ]5 ; +∞[.
4. g est continue en 1 et en 5 : g décroît sur ]−∞ ; 1] de +∞ à g(1) = 0, et croît sur [5 ; +∞[ de g(5) = 0 à +∞.

:::

::: verifie
Donner le domaine, l'axe de symétrie et les variations de h(x) = √(x² − 8x + 12).

---

x² − 8x + 12 = (x − 2)(x − 6), positif à l'extérieur des racines (a > 0) : D = ]−∞ ; 2] ∪ [6 ; +∞[. L'axe est x = −b/(2a) = 4. h′(x) = (x − 4)/√(x² − 8x + 12) est négatif sur ]−∞ ; 2[ et positif sur ]6 ; +∞[ : h décroît sur ]−∞ ; 2] et croît sur [6 ; +∞[, avec h(2) = h(6) = 0. Le signe de h′ est celui de x − 4, mais seule la partie qui est dans le domaine compte.
:::

::: retenir
Pour f = √P avec a > 0, le domaine est là où P ≥ 0 (à l'extérieur des racines), l'axe est x = −b/(2a), et f varie comme P : elle décroît avant l'axe, croît après.
:::

Les deux droites en pointillés se croisent au point (2 ; 0) de l'axe de symétrie : D est la droite de pente 1 à droite, D′ celle de pente −1 à gauche.

::: exemple Les asymptotes de f(x) = √(x² − 4x + 7) = √((x − 2)² + 3)
1. En +∞ : on multiplie par la quantité conjuguée f(x) + (x − 2), non nulle pour x grand : f(x) − (x − 2) = (f(x)² − (x − 2)²)/(f(x) + x − 2) = 3/(f(x) + x − 2).
2. Quand x tend vers +∞, f(x) + x − 2 tend vers +∞, donc f(x) − (x − 2) tend vers 0 : D : y = x − 2 est asymptote oblique en +∞.
3. Position : f(x)² = (x − 2)² + 3 > (x − 2)², donc f(x) > |x − 2| ≥ x − 2 : la courbe est au-dessus de D.
4. En −∞ : f(x) + (x − 2) = 3/(f(x) − (x − 2)), et f(x) − (x − 2) tend vers +∞ : D′ : y = −(x − 2) = −x + 2 est asymptote en −∞, et f(x) > |x − 2| ≥ −(x − 2) : la courbe est au-dessus de D′.

:::

::: piege Croire que la même droite sert en +∞ et en −∞
On a trouvé D : y = x − 2 en +∞ et l'on affirme « D est aussi asymptote en −∞ ». Cela tente parce que √((x − 2)²) ressemble à x − 2. Mais √((x − 2)²) = |x − 2|, qui vaut −(x − 2) pour x < 2. Contrôle : f(−100) = √10 407 ≈ 102,015 alors que −100 − 2 = −102 : l'écart est d'environ 204, la courbe est loin de D. L'asymptote en −∞ est D′ : y = −x + 2.
:::

::: propriete
Soit f(x) = √(ax² + bx + c) avec a > 0, écrit sous forme canonique ax² + bx + c = a(x + β)² + γ, où β = b/(2a).

- En +∞, la droite D : y = √a (x + β) est asymptote oblique ; en −∞, c'est la droite D′ : y = −√a (x + β).
- Position : si γ > 0, la courbe est au-dessus de D et de D′ ; si γ < 0 (deux racines), elle est au-dessous.
- Quand la droite n'est pas donnée, on trouve son coefficient directeur par lim f(x)/x = √a en +∞ (−√a en −∞), puis l'ordonnée à l'origine par lim (f(x) − √a x).

Cas limite : si γ = 0, f(x) = √a |x + β| : la courbe est formée de deux demi-droites, confondues avec leurs propres asymptotes.
:::

::: exemple Une racine avec a ≠ 1 et γ < 0 : f(x) = √(4x² − 8x − 5)
1. Forme canonique : 4x² − 8x − 5 = 4(x − 1)² − 9, donc a = 4, x + β = x − 1 et γ = −9 < 0.
2. √a = 2 : D : y = 2(x − 1) = 2x − 2 en +∞, et D′ : y = −2x + 2 en −∞.
3. En +∞ : f(x) − (2x − 2) = (f(x)² − (2x − 2)²)/(f(x) + 2x − 2) = −9/(f(x) + 2x − 2), qui tend vers 0 par valeurs négatives.
4. Comme γ < 0, f(x) < 2|x − 1| : la courbe est au-dessous de D et de D′ (là où elle est définie, pour x ≤ −1/2 ou x ≥ 5/2).

:::

::: verifie
Donner les asymptotes obliques de h(x) = √(x² + 2x + 10) et la position de la courbe par rapport à elles.

---

x² + 2x + 10 = (x + 1)² + 9 : a = 1, β = 1, γ = 9 > 0. En +∞, D : y = x + 1 ; en −∞, D′ : y = −(x + 1) = −x − 1. Comme γ > 0, h(x) > |x + 1| : la courbe est au-dessus de D et de D′. On change de droite en changeant d'infini.
:::

::: retenir
Pour f = √(a(x + β)² + γ), la droite y = √a (x + β) est asymptote en +∞ et y = −√a (x + β) en −∞ ; la courbe est au-dessus de ces droites si γ > 0, au-dessous si γ < 0.
:::

Les traits violets figurent les demi-tangentes verticales aux deux pieds de l'arche ; la droite orange x = 1 est l'axe de symétrie, et (1 ; 2√2) le sommet.

::: exemple Étudier f(x) = √(−2x² + 4x + 6)
1. Domaine : −2x² + 4x + 6 = −2(x + 1)(x − 3) ≥ 0 équivaut à (x + 1)(x − 3) ≤ 0, c'est-à-dire −1 ≤ x ≤ 3 (a < 0 : le trinôme est positif entre les racines). D = [−1 ; 3].
2. Axe : −2(2 − x)² + 4(2 − x) + 6 = −2x² + 4x + 6, donc f(2 − x) = f(x), et x ∈ [−1 ; 3] équivaut à 2 − x ∈ [−1 ; 3] : la droite x = 1, milieu de −1 et 3, est axe de symétrie.
3. Dérivée sur ]−1 ; 3[ : f′(x) = (−4x + 4)/(2√(−2x² + 4x + 6)) = 2(1 − x)/√(−2x² + 4x + 6), du signe de 1 − x : f croît sur [−1 ; 1], décroît sur [1 ; 3], avec le maximum f(1) = √8 = 2√2 ≈ 2,83.
4. En 3 : f(3) = 0 et, pour x < 3, −2x² + 4x + 6 = 2(x + 1)(3 − x), donc (f(x) − f(3))/(x − 3) = √(2(x + 1)(3 − x))/(x − 3) = −√(2(x + 1))/√(3 − x). Ce taux tend vers −∞ quand x tend vers 3 par la gauche : f n'est pas dérivable à gauche en 3, et la courbe a une demi-tangente verticale en (3 ; 0) ; par symétrie, aussi en (−1 ; 0).

:::

::: piege Chercher des limites en l'infini là où f n'existe pas
Pour f(x) = √(−2x² + 4x + 6), on veut « les asymptotes » comme pour la lampe, et l'on écrit lim x→+∞ f(x) = +∞ « puisque c'est une racine ». Cela tente parce que, pour a > 0, le radicande tend vers +∞. Mais ici a < 0 : le radicande tend vers −∞ et f n'est définie que sur [−1 ; 3]. Il n'y a ni limite en ±∞ ni asymptote ; les seuls bords de la courbe sont les extrémités −1 et 3 du domaine.
:::

::: propriete
Soit f(x) = √(ax² + bx + c) avec a < 0.

- Si le trinôme a deux racines x₁ < x₂, le domaine est D = [x₁ ; x₂] ; s'il n'a pas de racine, il est négatif partout et D est vide.
- La droite x = (x₁ + x₂)/2 = −b/(2a) est axe de symétrie, et f y atteint son maximum.
- En x₁ et en x₂, f n'est pas dérivable : le taux d'accroissement tend vers +∞ en x₁ (à droite) et vers −∞ en x₂ (à gauche), donc la courbe a une demi-tangente verticale en chacun de ces points.
- La courbe est une demi-ellipse (un demi-cercle si a = −1).

Cas limite : si le trinôme a une racine double x₀, le domaine se réduit au seul point x₀.
:::

::: verifie
Donner le domaine, l'axe de symétrie et la demi-tangente en x = 5 de k(x) = √(−x² + 6x − 5).

---

−x² + 6x − 5 = −(x − 1)(x − 5) = (x − 1)(5 − x) ≥ 0 équivaut à 1 ≤ x ≤ 5 : D = [1 ; 5], et l'axe est x = 3, milieu de 1 et 5. Pour x < 5, (k(x) − k(5))/(x − 5) = √((x − 1)(5 − x))/(x − 5) = −√(x − 1)/√(5 − x), qui tend vers −∞ : demi-tangente verticale en (5 ; 0). On a étudié le taux d'accroissement parce que k′(5) n'existe pas.
:::

::: retenir
Pour f = √P avec a < 0, le domaine est le segment entre les racines, la courbe est une demi-ellipse symétrique par rapport à x = −b/(2a), avec des demi-tangentes verticales aux deux racines.
:::

## 🧪 Ouverture : bâtir une courbe pas à pas (méthode d'Euler)

On connaît la pente d'une courbe en chaque point, f′(x) = 2x, et son point de départ f(0) = 2. Peut-on reconstruire la courbe sans connaître la formule de f ?
Une idée : suivre la tangente un petit moment, puis recommencer au nouveau point.

::: definition
La **méthode d'Euler** de pas h approche f(x + h) par la tangente en x : f(x + h) ≈ f(x) + h f′(x). À partir de (x₀ ; y₀) = (a ; f(a)), on pose xₖ₊₁ = xₖ + h et yₖ₊₁ = yₖ + h f′(xₖ) ; yₖ est une valeur approchée de f(xₖ).
:::

Chaque segment vert est tangent à la courbe grise en son point de départ : c'est la pente f′(xₖ) qui le dirige, et la ligne brisée s'écarte peu à peu de la courbe.

::: exemple f(0) = 2 et f′(x) = 2x : valeur approchée de f(1,5) avec h = 0,5
1. On part de x₀ = 0 et y₀ = 2.
2. x₁ = 0,5 et y₁ = 2 + 0,5 × f′(0) = 2 + 0,5 × 0 = 2.
3. x₂ = 1 et y₂ = 2 + 0,5 × f′(0,5) = 2 + 0,5 × 1 = 2,5.
4. x₃ = 1,5 et y₃ = 2,5 + 0,5 × f′(1) = 2,5 + 0,5 × 2 = 3,5.
5. Donc f(1,5) ≈ 3,5. La fonction x ↦ x² + 2 a pour dérivée 2x et vaut 2 en 0 : sa valeur exacte en 1,5 est 4,25. Avec un pas plus petit, h = 0,25, on obtient 3,875 : plus h est petit, plus la ligne brisée serre la courbe.

:::

En pseudo-code, la boucle fait exactement ce calcul (on met y à jour avant x, car il utilise l'ancien x) :

```
x ← 0 ; y ← 2 ; h ← 0,5
tant que x < 1,5 :
    y ← y + h × (2 × x)
    x ← x + h
afficher y
```

Dans un tableur, on range les x dans une colonne (A4 = A3 + h), les pentes f′(x) dans une autre (B4 = 2 × A4) et les y dans une troisième : la cellule D4 = D3 + B3 × h reprend la pente de la ligne précédente.

::: piege Utiliser la pente d'arrivée au lieu de la pente de départ
Pour passer de x₂ = 1 à x₃ = 1,5, on écrit y₃ = y₂ + h × f′(1,5) = 2,5 + 0,5 × 3 = 4. Cela tente parce que la courbe monte de plus en plus vite et que la pente d'arrivée paraît plus juste. Mais la tangente que l'on suit est celle du point connu (x₂ ; y₂) : sa pente est f′(x₂) = f′(1) = 2, et y₃ = 3,5. Avec f′(1,5) on appliquerait une pente que la courbe n'a pas encore atteinte, ce qui change de formule.
:::

::: verifie
On sait que f(0) = 1 et f′(x) = x + 1. Avec h = 0,5, donner la valeur approchée de f(1) par la méthode d'Euler.

---

x₀ = 0, y₀ = 1. y₁ = 1 + 0,5 × f′(0) = 1 + 0,5 × 1 = 1,5 (x₁ = 0,5). y₂ = 1,5 + 0,5 × f′(0,5) = 1,5 + 0,5 × 1,5 = 2,25 (x₂ = 1). Donc f(1) ≈ 2,25. À chaque pas, on utilise la pente au point de départ du pas.
:::

::: retenir
Euler construit la courbe pas à pas : yₖ₊₁ = yₖ + h f′(xₖ), la pente de départ dirigeant chaque segment ; avec f′(x) = 1/x, cette méthode fait naître une fonction nouvelle, que le chapitre 6 va nommer.
:::
