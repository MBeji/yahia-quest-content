# 📜 Résumé : Études de fonctions

- **Périodicité** : f est T-périodique si x + T ∈ D et f(x + T) = f(x) pour tout x de D ; la courbe est invariante par la translation de vecteur T i⃗, on l'étudie sur une période. x ↦ cos(ωx + φ) a pour période 2π/|ω| (et non 2π) ; x − E(x) a pour période 1.
- **Axe et centre de symétrie** : pour tout x de D, 2a − x ∈ D, puis f(2a − x) = f(x) (axe x = a) ou f(2a − x) + f(x) = 2b (centre Ω(a ; b)). Le milieu de deux valeurs interdites est le candidat pour a ; un domaine non symétrique interdit toute symétrie.
- **Décomposer une fraction rationnelle** : f(x) = ax + b + c/(x − x₀), obtenu par identification des coefficients (le coefficient de x du numérateur est b − a, pas b) ; y = ax + b est asymptote oblique, le signe de c/(x − x₀) donne la position, x = x₀ est asymptote verticale et I(x₀ ; ax₀ + b) est centre. Trois valeurs de f donnent un système de trois équations en a, b, c.
- **Tangente et inflexion** : T : y = f′(a)(x − a) + f(a) ; le signe de f(x) − T(x) donne la position, et un changement de signe de cet écart (ou de f″) signale un point d'inflexion. f″(a) = 0 ne suffit pas : x⁴ en 0.
- **Étude d'une fonction rationnelle** : domaine et symétries, limites et asymptotes (position par le signe de f(x) − (ax + b), une asymptote peut être coupée), dérivée et tableau intervalle par intervalle (jamais une réunion de part et d'autre d'une valeur interdite), points remarquables, tracé.
- **√(ax² + bx + c), a > 0** : domaine à l'extérieur des racines (ℝ s'il n'y en a pas), axe x = −b/(2a), f′ du signe de 2ax + b : f décroît avant l'axe et croît après ; le minimum est atteint sur l'axe quand D = ℝ.
- **Asymptotes obliques de √(a(x + β)² + γ)** : y = √a (x + β) en +∞ et y = −√a (x + β) en −∞ (deux droites différentes), par la quantité conjuguée ; la courbe est au-dessus si γ > 0, au-dessous si γ < 0.
- **√(ax² + bx + c), a < 0** : domaine [x₁ ; x₂] entre les racines (vide sans racine), demi-ellipse symétrique par rapport à x = −b/(2a), maximum sur l'axe ; en x₁ et x₂ le taux d'accroissement tend vers ±∞ : demi-tangentes verticales, pas « pas de tangente ».
- **Méthode d'Euler** (ouverture) : xₖ₊₁ = xₖ + h, yₖ₊₁ = yₖ + h f′(xₖ) ; la pente utilisée est celle du point de départ du pas, et plus h est petit, meilleure est l'approximation.
