# 📜 Résumé : Fonctions exponentielles

- **Définition** : exp est la bijection réciproque de ln, notée exp(x) = eˣ, de ℝ sur ]0 ; +∞[. Donc y = eˣ ⟺ x = ln y, ln(eˣ) = x pour tout réel x et e^(ln x) = x pour x > 0 ; eˣ > 0, e⁰ = 1, e¹ = e. **Piège** : e^(ln(x²)) = x², pas x.
- **Règles de calcul** : eᵃ × eᵇ = e^(a+b), e^(−b) = 1/eᵇ, eᵃ/eᵇ = e^(a−b), (eᵃ)ⁿ = e^(na) pour n entier relatif et ⁿ√(eᵃ) = e^(a/n). **Piège** : eᵃ + eᵇ ≠ e^(a+b), une somme se factorise.
- **Équations et inéquations** : eᵃ = eᵇ ⟺ a = b et eᵃ ≤ eᵇ ⟺ a ≤ b ; eˣ = k ⟺ x = ln k si k > 0, aucune solution si k ≤ 0. Pour un trinôme en eˣ, on pose X = eˣ avec X > 0 et l'on rejette X ≤ 0. **Piège** : on isole l'exponentielle avant de prendre ln, jamais terme à terme.
- **Dérivée et primitives** : exp′ = exp, (e^u)′ = u′e^u, et e^u est une primitive de u′e^u. Une primitive de (ax + b)e^(cx) se cherche sous la forme (αx + β)e^(cx) en identifiant les coefficients. **Piège** : oublier le facteur u′, (e^(5x))′ = 5e^(5x).
- **Limites et courbe** : eˣ → +∞ en +∞ et → 0 en −∞ ; pour n entier, eˣ/xⁿ → +∞ en +∞ et xⁿeˣ → 0 en −∞ ; (eˣ − 1)/x → 1 en 0. La courbe de exp est la symétrique de celle de ln par rapport à y = x. Un programme approche eˣ par 1 + x + x²/2! + … jusqu'à un terme au plus égal à ε. **Piège** : une limite se juge à l'infini, pas en une valeur.
- **Puissance rationnelle** : xʳ = e^(r ln x) pour x > 0, avec les règles des puissances entières ; x^(1/n) = ⁿ√x. Comparaisons, pour r > 0 : ln x/xʳ → 0 en +∞, xʳ ln x → 0 en 0⁺, eˣ/xʳ → +∞ en +∞. **Piège** : x^(1/2) est la racine carrée, pas la moitié de x.
- **Exponentielle de base a** : aˣ = e^(x ln a) pour a > 0, (aˣ)′ = (ln a)aˣ, croissante si a > 1 et décroissante si 0 < a < 1 ; les courbes de aˣ et (1/a)ˣ sont symétriques par rapport à l'axe des ordonnées. Un modèle Q₀aᵗ se résout avec ln ; la demi-vie vérifie aᵀ = 1/2. **Piège** : (2ˣ)′ = (ln 2)2ˣ, pas x·2^(x−1).
- **Études de fonctions** : domaine, limites (comparaisons), dérivée factorisée par e^u (le signe de f′ est celui du facteur restant), tableau, asymptotes et branches paraboliques, valeurs intermédiaires pour les zéros ; la courbe de |f| retourne les parties où f < 0. **Piège** : f(x) = 2x − 3 + e^(−x) n'a la droite y = 2x − 3 pour asymptote qu'en +∞.
