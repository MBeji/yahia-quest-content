# 📜 Résumé : Nombres complexes

- **Forme algébrique et calculs** : ℂ contient ℝ et un nombre i tel que i² = −1 ; tout z s'écrit de façon **unique** a + ib, avec Re(z) = a et Im(z) = b, deux **réels**. z est réel si b = 0, imaginaire pur si a = 0, et z = z′ si leurs parties réelles et imaginaires sont égales. On développe comme dans ℝ avec i² = −1 ; iⁿ se lit sur le reste de n par 4. **Piège** : Im(3 − 2i) vaut −2, pas −2i.
- **Plan complexe** : M(a, b) a pour affixe a + ib, notée M(z) ; le vecteur u⃗(a, b) aussi. Aff(AB⃗) = z_B − z_A (arrivée moins départ), le milieu de [AB] a pour affixe (z_A + z_B)/2, Aff(ku⃗) = k Aff(u⃗) et Aff(u⃗ + v⃗) = Aff(u⃗) + Aff(v⃗). Axe réel : z réel ; axe imaginaire : z imaginaire pur. **Piège** : z_A − z_B est l'affixe de BA⃗.
- **Conjugué et division** : le conjugué de a + ib est a − ib ; il commute avec somme, produit, puissance et quotient. z + z̄ = 2Re(z), z − z̄ = 2i Im(z), z z̄ = a² + b². z est réel ⟺ z = z̄, imaginaire pur ⟺ z = −z̄. Symétriques de M(z) : z̄ (axe réel), −z (point O), −z̄ (axe imaginaire). On divise en multipliant par le conjugué du dénominateur. **Piège** : z̄ n'est pas −z.
- **Colinéarité et orthogonalité** : z̄z′ = (aa′ + bb′) + i(ab′ − a′b), produit scalaire plus i fois déterminant. Pour deux vecteurs non nuls : z̄z′ réel ⟺ colinéaires, z̄z′ imaginaire pur ⟺ orthogonaux. **Piège** : ne pas intervertir réel et imaginaire pur.
- **Module et distances** : |z| = √(z z̄) = √(a² + b²) = OM et AB = |z_B − z_A|. |zz′| = |z||z′|, |zⁿ| = |z|ⁿ, |1/z| = 1/|z|, |z′/z| = |z′|/|z|, |z̄| = |−z| = |z|, et |z + z′| ≤ |z| + |z′|. **Piège** : le module d'une somme n'est pas la somme des modules.
- **Lieux de points** : |z − a| = r est le cercle de centre A et de rayon r ; |z − a| = |z − b| est la médiatrice de [AB] ; le quotient (z − b)/(z − a) est réel sur la droite (AB) et imaginaire pur sur le cercle de diamètre [AB], A exclu, B inclus. Avec z = x + iy, on multiplie par le conjugué du dénominateur et l'on étudie Re et Im. **Piège** : |z + 1| = 2 a pour centre le point d'affixe −1.
- **Racines carrées et second degré** : pour d = a + ib, on résout x² − y² = a, x² + y² = |d| et on choisit le signe de xy d'après celui de b ; il y a deux racines opposées. Pour az² + bz + c = 0, Δ = b² − 4ac et δ une racine carrée de Δ donnent z = (−b ± δ)/(2a), même à coefficients complexes ; avec a, b, c réels et Δ < 0, z = (−b ± i√(−Δ))/(2a). **Piège** : ne pas garder les quatre combinaisons de signes.
- **Factoriser, poser Z** : z′ + z″ = −b/a et z′z″ = c/a ; a + b + c = 0 donne les solutions 1 et c/a. Avec une solution z₀ de degré 3, on écrit P(z) = (z − z₀)(az² + bz + c) et l'on identifie. z³ = 1 a pour solutions 1, j et j̄ (j = (−1 + i√3)/2, j³ = 1, j² = j̄). Équation bicarrée ou à expression répétée : on pose Z, puis on revient à z. **Piège** : −3 ± 4i sont les valeurs de z², pas de z.
