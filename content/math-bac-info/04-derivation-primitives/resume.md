# 📜 Résumé : Dérivation et primitives

- **Nombre dérivé et tangente** : f est dérivable en x₀ si lim x→x₀ (f(x) − f(x₀))/(x − x₀) = f′(x₀) est un réel (ou lim h→0 (f(x₀ + h) − f(x₀))/h) ; la tangente est y = f′(x₀)(x − x₀) + f(x₀), pas y = f′(x₀)x + f(x₀). Dérivable en x₀ implique continue en x₀ (admis), la réciproque est fausse (|x| en 0). Un programme approche f′(x₀) par le taux pour h de plus en plus petit.
- **Droite, gauche, intervalle** : f est dérivable en x₀ si et seulement si f′g(x₀) = f′d(x₀) (finis) ; sinon point anguleux avec deux demi-tangentes, ou demi-tangente verticale si le taux tend vers ±∞ (√x en 0). Pour deux formules, on vérifie d'abord la continuité, puis on compare les taux ; comparer seulement les dérivées des formules est une erreur.
- **Dérivées usuelles et opérations** : (λf)′ = λf′, (f + g)′ = f′ + g′, (fg)′ = f′g + fg′, (1/g)′ = −g′/g², (f/g)′ = (f′g − fg′)/g² (g ≠ 0), ((ax + b)/(cx + d))′ = (ad − bc)/(cx + d)² ; (xⁿ)′ = nxⁿ⁻¹, (1/x)′ = −1/x², (√x)′ = 1/(2√x) sur ]0 ; +∞[. Le numérateur du quotient commence par f′g.
- **Composée** : (g∘f)′ = f′ × (g′∘f) ; (uⁿ)′ = nu′uⁿ⁻¹, (√u)′ = u′/(2√u) pour u > 0, (sin(ax + b))′ = a cos(ax + b), (cos(ax + b))′ = −a sin(ax + b), (tan(ax + b))′ = a(1 + tan²(ax + b)). Ne jamais oublier la dérivée de l'intérieur.
- **Dérivée d'une réciproque** : si f′(x₀) ≠ 0, (f⁻¹)′(f(x₀)) = 1/f′(x₀), c'est-à-dire (f⁻¹)′(y) = 1/f′(f⁻¹(y)) : on cherche d'abord l'antécédent de y. Si f′(x₀) = 0, f⁻¹ n'est pas dérivable en f(x₀) (tangente verticale).
- **Accroissements finis** : f continue sur [a ; b] et dérivable sur ]a ; b[ donne c de ]a ; b[ avec f(b) − f(a) = (b − a)f′(c) (c n'est pas toujours le milieu) ; m ≤ f′ ≤ M donne m ≤ (f(b) − f(a))/(b − a) ≤ M ; |f′| ≤ k sur I donne |f(b) − f(a)| ≤ k|b − a|.
- **Variations et extrémums** : sur un intervalle, f′ > 0 donne f strictement croissante, f′ < 0 strictement décroissante, f′ = 0 constante ; f croissante si et seulement si f′ ≥ 0. Un extrémum local d'une fonction dérivable annule f′ ; f′ qui s'annule en changeant de signe donne un extrémum (x³ : f′(0) = 0 sans extrémum).
- **Dérivée seconde et inflexion** : f″ = (f′)′ ; M₀(x₀ ; f(x₀)) est un point d'inflexion (la tangente traverse la courbe) si et seulement si f″ s'annule et change de signe en x₀ ; f″(x₀) = 0 sans changement de signe ne suffit pas (x⁴ en 0).
- **Primitives** : F est une primitive de f sur I si F′ = f sur I ; toute fonction continue sur un intervalle en admet (admis) ; deux primitives diffèrent d'une constante, et il existe une unique primitive avec F(x₀) = y₀. On valide une primitive en la dérivant, et la constante ne s'oublie pas.
- **Primitives usuelles et linéarité** : k ↦ kx, xⁿ ↦ xⁿ⁺¹/(n + 1) (n entier, n ≠ −1), 1/√x ↦ 2√x, √x ↦ (2/3)x√x, cos ↦ sin, sin ↦ −cos, 1 + tan²x ↦ tan x, cos(ax + b) ↦ (1/a) sin(ax + b), sin(ax + b) ↦ −(1/a) cos(ax + b) ; αF + βG est une primitive de αf + βg, mais aucune règle pour un produit ou un quotient.
- **Formes pratiques** : u′uⁿ ↦ uⁿ⁺¹/(n + 1) (n ≠ −1), u′/√u ↦ 2√u (u > 0), v′/v² ↦ −1/v (v ≠ 0), (u′∘v)v′ ↦ u∘v. On pose u, on calcule u′, on compense un facteur constant manquant (jamais un facteur en x), puis on dérive pour contrôler.
- **Réécrire avant de primitiver** : une forme donnée (ax + b + c/(x + 1)², a/(3x + 2)² + b/(3x + 2)³, (ax + b)/(x² + x + 2)) s'identifie par une limite, une valeur en un point ou l'égalité des numérateurs ; on primitive ensuite terme à terme, jamais numérateur et dénominateur séparément.
