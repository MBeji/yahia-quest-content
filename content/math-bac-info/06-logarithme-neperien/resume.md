# 📜 Résumé : Logarithme népérien

- **Définition** : ln est la primitive de x ↦ 1/x sur ]0 ; +∞[ qui s'annule en 1, donc (ln)′(x) = 1/x et ln 1 = 0. Elle est strictement croissante : ln x < 0 sur ]0 ; 1[ et ln x > 0 sur ]1 ; +∞[. Pour a > 0 et b > 0, ln a = ln b ⟺ a = b et ln a < ln b ⟺ a < b. **Piège** : le signe de ln x se lit par rapport à 1, pas à 0.
- **Propriété fondamentale** : ln(xy) = ln x + ln y ; on en tire ln(1/x) = −ln x, ln(x/y) = ln x − ln y, ln(xⁿ) = n ln x (n entier) et ln √x = ½ ln x. Preuve : ln(kx) et ln x ont la même dérivée. **Piège** : ln(x + y) ≠ ln x + ln y.
- **Courbe, limites, e** : lim x→0⁺ ln x = −∞ (asymptote x = 0) et lim x→+∞ ln x = +∞ ; ln est une bijection de ]0 ; +∞[ sur ℝ. L'unique solution de ln x = 1 est e ≈ 2,718281828, et ln x = n ⟺ x = eⁿ (n entier). **Piège** : croître lentement n'est pas être borné.
- **Équations et inéquations** : conditions d'existence d'abord (chaque argument de ln est > 0), puis ln A = ln B ⟹ A = B ou la croissance de ln, puis rejet des solutions hors domaine ; poser X = ln x pour un trinôme en ln x ; un système x + y = s, ln x + ln y = ln p devient xy = p. Inconnue en exposant : on prend ln, et diviser par ln a < 0 renverse l'inégalité.
- **Encadrer ln(1 + x)** : pour x > 0, x − x²/2 ≤ ln(1 + x) ≤ x − x²/2 + x³ et x/(1 + x) ≤ ln(1 + x) ≤ x, par l'inégalité des accroissements finis. Une valeur approchée à ε près exige une amplitude d'encadrement d'au plus ε. **Piège** : l'écart x³ grandit vite, l'encadrement n'est fin que près de 0.
- **Limites de référence** : lim x→1 (ln x)/(x − 1) = lim h→0 ln(1 + h)/h = 1 ; lim x→+∞ (ln x)/xⁿ = 0 (n ≥ 1) et lim x→0⁺ xⁿ ln x = 0 (n ≥ 1) ; lim x→+∞ (ln x)/√x = 0 et lim x→0⁺ √x ln x = 0. Méthodes : changement de variable, factorisation du terme dominant. **Piège** : en 0⁺, (ln x)/x → −∞.
- **ln(u)** : (ln u)′ = u′/u là où u > 0 ; les primitives de u′/u sont ln|u| + k là où u ne s'annule pas. Étude d'une fonction à logarithme : domaine (argument > 0), limites, dérivée u′/u, tableau ; quand le signe de f′ ne se lit pas, on étudie une fonction auxiliaire. On a ln x ≤ x − 1 pour tout x > 0. **Piège** : ne pas oublier le facteur u′.
- **Logarithme décimal** : log x = ln x/ln 10 ≈ 0,4343 ln x, avec log(10ᵖ) = p. Si x = a × 10ᵖ (1 ≤ a < 10), p est la partie entière de log x ; un entier N a (partie entière de log N) + 1 chiffres ; d = 10 log(I/I₀) en décibels, et multiplier l'intensité par 2 ajoute environ 3 dB. **Piège** : la partie entière de log 0,0073 ≈ −2,137 est −3.
