# 📜 ملخّص: القيمة المطلقة

- **التعريف**: |x| هو بُعد العدد x عن الصفر على المستقيم المدرّج. ⚠️ **لا تكون سالبة أبدًا** — هي مسافة، لا جهة.
- **الحساب حسب الإشارة**: x موجب أو معدوم ⟹ |x| = x ؛ x سالب ⟹ |x| = −x.
- ⚠️ **الكتابة −x ليست سالبة بالضرورة**: مع x = −13 نجد −x = 13.
- **عبارة لا تظهر إشارتها**: اختبر الإشارة بقيمة تقريبية **قبل** حذف الأقواس. |√6 − 3| = 3 − √6 لأنّ √6 ≈ 2,45 < 3.
- ⚠️ **|a − b| = b − a ليست قاعدة**: هي صحيحة فقط إذا كان a − b سالبًا.
- **المساواة**: |x| = a (مع a > 0) لها **حلّان** متقابلان ؛ |x| = 0 حلّ وحيد ؛ و a سالب: لا حلّ.
- **البعد بين نقطتين**: AB = |b − a| — الفرق ثمّ القيمة المطلقة، والترتيب لا يهمّ.
- **الجذاء والقسمة**: |a × b| = |a| × |b| و |a/b| = |a|/|b|. ⚠️ **لا قاعدة للمجموع**: |7 + (−7)| = 0 بينما |7| + |−7| = 14.
