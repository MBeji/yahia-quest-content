# 🗺️ المعلّم في المستوي — خريطة الهندسة التحليلية

> 💡 «المعلّم هو نظام الإحداثيّات الذي يحوّل الهندسة إلى حساب — كلّ نقطة في المستوي لها عنوانها الخاصّ!»

## 🏰 المعلّم المتعامد والمتجانس

على خريطة، لا يكفي أن تقول « المدرسة هناك ». تحتاج مرجعًا ثابتًا وطريقة موحّدة لقياس المسافة
منه. المعلّم هو هذا المرجع في المستوي: نقطة أصل، ومحوران، ووحدة — وثلاثتها معًا تعطي كلّ نقطة
عنوانًا لا يشاركها فيه أحد.

::: definition
**المعلّم المتعامد والمتجانس** (repère orthonormé)، ويُرمز له بـ (O ; i ; j)، يتكوّن من:

- **النقطة الأصل O**: نقطة تقاطع المحورين.
- **محور الفاصلات** (axe des abscisses): المستقيم الأفقي، اتّجاهه الشعاع i.
- **محور الترتيبات** (axe des ordonnées): المستقيم العمودي، اتّجاهه الشعاع j.

:::

::: exemple كلمتان، وشرطان مختلفان

1. **متعامد** يعني أنّ المحورين يصنعان زاوية **90°** — لا أكثر ولا أقلّ.
2. **متجانس** يعني أنّ الوحدة لها **نفس الطول** على المحورين — المقياس موحَّد.
3. معلّم قد يكون متعامدًا دون أن يكون متجانسًا: محوران عموديّان لكنّ وحدة أحدهما ضعف الأخرى.
4. وحينها يتشوّه الشكل في الرسم: دائرة تبدو بيضاوية، ومربّع يبدو مستطيلًا.

:::

> ⚠️ **الخطأ الشائع**: الخلط بين الكلمتين، أو الظنّ أنّ إحداهما تستلزم الأخرى. **متعامد** يخصّ
> الزاوية، و**متجانس** يخصّ الوحدة — وصيغ المسافة والمنتصف (milieu) تحتاج **الاثنين معًا**.

::: verifie
معلّم محوراه عموديّان، لكنّ الوحدة على المحور الأفقي 1 cm وعلى العمودي 2 cm. أهو متعامد؟ أمتجانس؟

---

**متعامد نعم** (الزاوية 90°)، لكن **غير متجانس**: الوحدتان مختلفتان.
:::

::: retenir
متعامد = الزاوية ؛ متجانس = الوحدة. الصيغ تحتاج الاثنين.
:::

## ⚡ إحداثيّات نقطة

المعلّم جاهز. يبقى أن نقرأ عنوان نقطة: عددان مرتّبان، الأوّل يقول كم نمشي أفقيًّا والثاني كم
نصعد. والترتيب بينهما ليس تفصيلًا — عكسه يعطي نقطة أخرى تمامًا.

::: definition
كلّ نقطة M في المستوي تُعرَّف بزوج ترتيبي **(x ; y)**:

- **الفاصلة** (abscisse) x: الإسقاط على محور الفاصلات.
- **الترتيبة** (ordonnée) y: الإسقاط على محور الترتيبات.

ونكتب M(x ; y).
:::

| ------ | ------- | -------- | ------------------ |
| O | 0 | 0 | الأصل |
| A | 3 | 2 | الربع الأوّل (+,+) |

1. إشارة الفاصلة تقول يمين الأصل أم يساره ؛ وإشارة الترتيبة تقول فوقه أم تحته.
2. الربع الثاني هو (−,+): يسارًا وفوق — لا (+,−).
3. وإذا كانت إحدى الإحداثيّتين **معدومة**، فالنقطة على أحد المحورين ولا تنتمي إلى أيّ ربع.

:::

> ⚠️ **الخطأ الشائع**: قلب الإحداثيّتين. A(3 ; 2) ليست A(2 ; 3) — الفاصلة أوّلًا، دائمًا.

> ⚠️ **وخطأ الأرباع**: حفظ ترتيب الإشارات دون معناها. استنتجها من الرسم في كلّ مرّة: سالب في
> الفاصلة ⟹ يسار ؛ سالب في الترتيبة ⟹ تحت.

::: verifie
في أيّ ربع تقع النقطة P(−5 ; −2) ؟ وأين تقع Q(0 ; −3) ؟

---

P فاصلتها سالبة وترتيبتها سالبة ⟹ **الربع الثالث**.
Q فاصلتها معدومة ⟹ **على محور الترتيبات**، ولا تنتمي إلى أيّ ربع.
:::

::: retenir
(الفاصلة ; الترتيبة) بهذا الترتيب. وإحداثيّة معدومة ⟹ على محور، لا في ربع.
:::

## 🛡️ إحداثيّات شعاع من نقطتين

النقطة لها عنوان. والشعاع؟ هو **رحلة** من نقطة إلى أخرى — فعنوانه ليس موضعًا بل **فرقًا**: كم
تقدّمنا أفقيًّا، وكم صعدنا. ومن هنا الطرح، لا الجمع.

::: propriete
إذا كانت A(xA ; yA) و B(xB ; yB)، فإنّ إحداثيّات الشعاع AB هي:
$$ AB = (xB − xA ; yB − yA) $$
أي: **فاصلة الطرف ناقص فاصلة المنشأ**، وكذلك للترتيبة.
:::

::: exemple A(1 ; 3) و B(5 ; −1)

1. المنشأ هو A (الحرف الأوّل) والطرف هو B (الحرف الثاني).
2. المركّبة الأولى: 5 − 1 = **4** — تقدّمنا 4 وحدات يمينًا.
3. المركّبة الثانية: −1 − 3 = **−4** — نزلنا 4 وحدات، ومن هنا الإشارة السالبة.
4. إذن AB = **(4 ; −4)**.

:::

> ⚠️ **الخطأ الأشهر**: جمع الإحداثيّات بدل طرحها. الشعاع فرق، لا مجموع: (5 + 1 ; −1 + 3) خطأ.

> ⚠️ **وخطأ الاتّجاه**: الطرح في الاتّجاه المعكوس، أي المنشأ ناقص الطرف. ذلك يعطي BA لا AB —
> شعاعًا معاكسًا. « طرف ناقص منشأ »، دائمًا.

::: verifie
احسب إحداثيّات الشعاع MN حيث M(−2 ; 4) و N(3 ; 1).

---

MN = (3 − (−2) ; 1 − 4) = **(5 ; −3)**.
:::

::: retenir
شعاع = طرف ناقص منشأ. جمعٌ هنا يعني خطأ مضمونًا.
:::

## 🧭 تساوي شعاعين — إيجاد الرأس الرابع

عرفنا في فصل الأشعّة أنّ ABCD متوازي أضلاع إذا وفقط إذا AB = DC. في المعلّم، هذا التكافؤ يصير
معادلتين — وبهما نُوجد رأسًا مجهولًا دون أن نرسم شيئًا.

::: propriete
شعاعان متساويان إذا وفقط إذا كانت لهما **نفس المركّبتين**:
$$ AB = DC ⟺ xB − xA = xC − xD و yB − yA = yC − yD $$
:::

::: exemple A(1 ; 2)، B(4 ; 3)، C(6 ; 7) — أوجد D ليكون ABCD متوازي أضلاع

1. نحسب الشعاع المعلوم: AB = (4 − 1 ; 3 − 2) = **(3 ; 1)**.
2. ونكتب الشعاع المجهول: DC = (6 − xD ; 7 − yD).
3. نساوي المركّبة الأولى: 6 − xD = 3، ومنه xD = **3**.
4. ثمّ الثانية: 7 − yD = 1، ومنه yD = **6**. إذن D**(3 ; 6)**.
5. **التحقّق**: DC = (6 − 3 ; 7 − 6) = (3 ; 1) = AB ✓.

:::

> 🗡️ يكافئ ذلك الصيغة المباشرة: xD = xA + xC − xB و yD = yA + yC − yB — هنا 1 + 6 − 4 = 3
> و 2 + 7 − 3 = 6، وهي النتيجة نفسها.

> ⚠️ **الخطأ الشائع**: كتابة AB = CD بدل AB = DC. ترتيب الرؤوس يتبع دوران الشكل ؛ الخطأ هنا
> يعطي رأسًا رابعًا في مكان آخر تمامًا.

::: verifie
A(0 ; 0)، B(2 ; 1)، C(5 ; 3). أوجد D ليكون ABCD متوازي أضلاع.

---

xD = xA + xC − xB = 0 + 5 − 2 = **3** ؛ yD = 0 + 3 − 1 = **2**. إذن D(3 ; 2).
التحقّق: AB = (2 ; 1) و DC = (5 − 3 ; 3 − 2) = (2 ; 1) ✓.
:::

::: retenir
AB = DC يعطي معادلتين — وبهما يُوجد الرأس الرابع بالحساب.
:::

## 🌀 الانسحاب في المعلّم

الانسحاب ينقل كلّ نقطة بالشعاع نفسه. في المعلّم، « النقل بشعاع » يصير أبسط ما يكون: نضيف
مركّبتَي الشعاع إلى إحداثيّتَي النقطة. الهندسة تتحوّل إلى جمع.

::: propriete
إذا كانت للشعاع u المركّبتان (a ; b)، فإنّ صورة النقطة M(x ; y) بالانسحاب ذي الشعاع u هي:
$$ M'(x + a ; y + b) $$
وللعودة من الصورة إلى **السابقة** نطرح: M(x' − a ; y' − b).
:::

::: exemple صورة وسابقة بالشعاع u = (3 ; −2)

1. **الصورة**: M(1 ; 4) ⟹ M'(1 + 3 ; 4 + (−2)) = M'**(4 ; 2)**.
2. لاحظ أنّ المركّبة الثانية سالبة، فالنقطة **نزلت** وحدتين.
3. **السابقة**: N'(5 ; 0) ⟹ N(5 − 3 ; 0 − (−2)) = N**(2 ; 2)**.
4. والتحقّق: صورة N(2 ; 2) هي (2 + 3 ; 2 − 2) = (5 ; 0) = N' ✓.

:::

> ⚠️ **الخطأ الشائع**: طرح مركّبات الشعاع لإيجاد الصورة، أو جمعها لإيجاد السابقة. الصورة
> **تُضاف** والسابقة **تُطرح** — والتحقّق بالعودة يكشف الخطأ فورًا.

::: verifie
الشعاع u = (−1 ; 4). أوجد صورة P(2 ; 3) ثمّ سابقة Q'(0 ; 0).

---

الصورة: P'(2 − 1 ; 3 + 4) = **(1 ; 7)**.
السابقة: Q(0 + 1 ; 0 − 4) = **(1 ; −4)**.
:::

::: retenir
الصورة تُضاف، والسابقة تُطرح — والتحقّق بالعودة مجّاني.
:::

## 🔮 إحداثيّات منتصف قطعة

المنتصف يقع على البعد نفسه من الطرفين. فما العدد الذي يقع في منتصف عددين؟ معدّلهما. والمنتصف
في المعلّم ليس أكثر من ذلك: معدّل على كلّ محور.

::: propriete
إذا كانت A(xA ; yA) و B(xB ; yB)، فإنّ المنتصف I للقطعة [AB] له إحداثيّات:
$$ I = ((xA + xB)/2 ; (yA + yB)/2) $$
أي **المعدّل الحسابي** للفاصلتين، والمعدّل الحسابي للترتيبتين.
:::

::: exemple A(2 ; 6) و B(8 ; 2)

1. الفاصلة: (2 + 8)/2 = 10/2 = **5**.
2. الترتيبة: (6 + 2)/2 = 8/2 = **4**. إذن I**(5 ; 4)**.
3. **التحقّق بالأشعّة**: AI = (5 − 2 ; 4 − 6) = (3 ; −2)، و IB = (8 − 5 ; 2 − 4) = (3 ; −2).
4. الشعاعان متساويان، إذن I منتصف [AB] فعلًا ✓.

:::

> ⚠️ **الخطأ الشائع**: جمع الإحداثيّات ونسيان القسمة على 2. (2 + 8 ; 6 + 2) = (10 ; 8) ليست
> المنتصف بل نقطة بعيدة تمامًا — **المعدّل، لا المجموع**.

::: methode المسألة العكسية — إيجاد طرف من المنتصف
نعزل الطرف المجهول في الصيغة: من (xA + xC)/2 = xI نستخرج xC = 2xI − xA، وكذلك yC = 2yI − yA.
:::

::: exemple I(4 ; 1) منتصف [AC] حيث A(2 ; 5)

1. الفاصلة: xC = 2 × 4 − 2 = 8 − 2 = **6**.
2. الترتيبة: yC = 2 × 1 − 5 = 2 − 5 = **−3**. إذن C**(6 ; −3)**.
3. **التحقّق**: منتصف [AC] = ((2 + 6)/2 ; (5 + (−3))/2) = (4 ; 1) = I ✓.

:::

> 🗡️ **مماثل نقطة بالنسبة إلى نقطة**: مماثل A بالنسبة إلى B هو M حيث B منتصف [AM] — أي
> xM = 2xB − xA و yM = 2yB − yA، وهي الصيغة نفسها.

::: verifie
احسب منتصف [AB] حيث A(−3 ; 2) و B(7 ; −4).

---

I = ((−3 + 7)/2 ; (2 + (−4))/2) = (4/2 ; −2/2) = **(2 ; −1)**.
:::

::: retenir
المنتصف = معدّل الإحداثيّات. والقسمة على 2 هي ما يُنسى.
:::

## 🧪 المسافة بين نقطتين

بين نقطتين لا يقع إحداهما فوق الأخرى ولا بجانبها، الطول ليس فرقًا بسيطًا. لكن ارسم المثلّث
القائم الذي ساقاه أفقية وعمودية: المسافة هي وتره — وفيثاغورس يعرف الوتر.

::: propriete
إذا كانت A(xA ; yA) و B(xB ; yB)، فإنّ:
$$ AB = √((xB − xA)² + (yB − yA)²) $$
وهي **نظرية فيثاغورس** مطبّقة على المثلّث القائم الذي ساقاه (xB − xA) و (yB − yA).
:::

::: exemple A(1 ; 2) و B(5 ; 5)

1. الساق الأفقية: xB − xA = 5 − 1 = **4**.
2. الساق العمودية: yB − yA = 5 − 2 = **3**.
3. نربّع ونجمع: 4² + 3² = 16 + 9 = **25**.
4. نأخذ الجذر: AB = √25 = **5**.
5. ولاحظ أنّه المثلّث 3-4-5 الكلاسيكي — وهو يعود كثيرًا في الامتحان.

:::

> ⚠️ **الخطأ الشائع**: نسيان الجذر والإجابة بـ 25. المسافة هي **جذر** المجموع، لا المجموع.

> ⚠️ **وخطأ المربّعات**: جمع الفرقين دون تربيعهما (4 + 3 = 7). فيثاغورس يجمع **المربّعات**.

::: verifie
احسب المسافة بين A(−1 ; 0) و B(2 ; 4).

---

الساقان: 2 − (−1) = 3 و 4 − 0 = 4. إذن AB = √(3² + 4²) = √25 = **5**.
:::

::: retenir
ربّع الفرقين، اجمع، ثمّ جذّر. الجذر هو الخطوة المنسيّة.
:::

## 🧮 تطبيقات مجتمعة — إثبات خاصيّة هندسية بالحساب

كلّ صيغة وحدها سهلة. قوّة المعلّم تظهر حين تجتمع: نحسب أطوالًا بالصيغة، ثمّ نستنتج منها أنّ
مثلّثًا متساوي الساقين أو أنّ زاوية قائمة — دون منقلة ولا مسطرة.

::: methode الترتيب الذي لا يخيب
احسب أوّلًا **كلّ** الأطوال أو الأشعّة المطلوبة بالصيغ، ثمّ قارنها، ثمّ استنتج الخاصيّة
الهندسية. لا تستنتج من الرسم: الرسم يوحي، والحساب يُثبت.
:::

::: exemple مثلّث متساوي الساقين — A(0 ; 0)، B(6 ; 0)، C(3 ; 4)

1. AB = √((6 − 0)² + (0 − 0)²) = √36 = **6**.
2. AC = √((3 − 0)² + (4 − 0)²) = √(9 + 16) = √25 = **5**.
3. BC = √((3 − 6)² + (4 − 0)²) = √(9 + 16) = √25 = **5**.
4. بما أنّ AC = BC = 5، فالمثلّث **متساوي الساقين رأسه C** — لأنّ الضلعين المتساويين يلتقيان في C.
5. ومنتصف [AB] هو I = ((0 + 6)/2 ; 0) = (3 ; 0)، و CI = √(0 + 16) = **4**.

:::

::: exemple زاوية قائمة بعكس فيثاغورس — A(1 ; 1)، B(4 ; 1)، D(1 ; 5)

1. AB = √((4 − 1)² + 0) = √9 = **3**.
2. AD = √(0 + (5 − 1)²) = √16 = **4**.
3. BD = √((4 − 1)² + (1 − 5)²) = √(9 + 16) = √25 = **5**.
4. الأطول هو BD، فنضعه وحده: AB² + AD² = 9 + 16 = **25** = BD².
5. بعكس فيثاغورس، المثلّث ABD قائم في A — أي الزاوية BAD **قائمة** ✓.

:::

::: verifie
A(0 ; 0) و B(3 ; 0) و C(0 ; 4). ما طبيعة المثلّث ABC؟

---

AB = 3، AC = 4، BC = √(9 + 16) = 5.
والأطول BC يحقّق 3² + 4² = 25 = 5²، إذن المثلّث **قائم في A**.
:::
