# 📜 ملخّص: الدوال الخطية والتآلفية

- **الدالة الخطية**: f(x) = ax (مع a ≠ 0). تناسبٌ مباشر، تمرّ دائمًا بالأصل O(0 ; 0)، ومعاملها a هو صورة العدد 1.
- **الدالة التآلفية**: f(x) = ax + b (مع a ≠ 0). جزء ثابت + جزء متناسب؛ القطع b هو صورة الصفر، والخطية حالتها الخاصّة b = 0.
- **التمثيل البياني**: مستقيم. a هو الميل وإشارته تقول أصاعد هو (a > 0) أم نازل (a < 0)؛ b هو الارتفاع عند x = 0؛ نقطتان تكفيان لرسمه.
- **التوازي**: مستقيمان متوازيان ⟺ لهما معامل التوجيه نفسه مع قطعَين مختلفَين.
- **الصورة والسابقة**: الصورة بالتعويض؛ السابقة بحلّ المعادلة ax + b = k أي x = (k − b)/a، وهي موجودة ووحيدة لأنّ a ≠ 0.
- ⚠️ **سابقة الصفر ليست القطع**: سابقة الصفر هي حلّ ax + b = 0 أي x = −b/a؛ أمّا b فهو صورة الصفر.
- **تحديد a و b من نقطتَين**: a = (y₂ − y₁)/(x₂ − x₁) — فرقٌ لا مجموع — ثمّ b = y₁ − a × x₁.
- **تقاطع مستقيمَين**: نحلّ f(x) = g(x) ثمّ نحسب الترتيب؛ الجواب زوج إحداثيات (x ; y)، لا عدد.
