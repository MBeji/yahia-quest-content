# 📜 ملخّص: الحساب الحرفي والمتطابقات الشهيرة

- **الحدود المتشابهة**: لها نفس الجزء الحرفي؛ نجمعها بجمع معاملاتها: 4x + 3x = 7x. ⚠️ 5x + 3y لا تُبسَّط.
- **التوزيع**: k(a + b) = ka + kb — العامل يضرب **كلّ** حدّ. ⚠️ إشارة السالب: −(a − b) = −a + b.
- **نشر جداء ثنائيّين**: (a + b)(c + d) = ac + ad + bc + bd — **أربعة** جداءات، عُدّها.
- **المتطابقات الشهيرة الثلاث**: (a + b)² = a² + 2ab + b²؛ (a − b)² = a² − 2ab + b²؛ (a − b)(a + b) = a² − b².
- ⚠️ **الحدّ الأوسط لا يسقط**: (3 + 4)² = 49 لا 25. و b² **موجب دائمًا**: (a − b)² = a² − 2ab **+** b².
- ⚠️ **لا تخلط** a² − b² (جداء مجموع في فرق) بـ (a − b)² (مربّع): مع 5 و 3 نجد 16 مقابل 4.
- **الحساب الذهني**: 102² = (100 + 2)² = 10404؛ 51 × 49 = (50 + 1)(50 − 1) = 2499.
- **التعميل بعامل مشترك**: 4x² − 8x = 4x(x − 2)، وقد يكون العامل قوسًا: (x + 1)(x − 3) + (x + 1)(2x + 5) = (x + 1)(3x + 2). ⚠️ تحقّق **بالنشر**: 4x(x − 8) خطأ.
- **التعميل بالمتطابقات**: a² − b² = (a − b)(a + b)؛ a² ± 2ab + b² = (a ± b)² — ⚠️ افحص الحدّ الأوسط قبل أن تعلن مربّعًا.
- **التعميل التامّ**: عامل مشترك أوّلًا ثمّ متطابقة: 2x² − 8 = 2(x − 2)(x + 2).
