# 📜 Résumé : Travailler pour s'épanouir

- **Le groupe nominal** — un **nom propre** seul (majuscule : _Hédi_, _Paris_) ou un **déterminant** (_le, la, l', les, un, une, des_) + un **nom commun** (_le comptoir_). Un verbe n'accepte jamais de déterminant devant lui.
- **Les pronoms personnels** — _je, tu, il, elle, nous, vous, ils, elles_ remplacent un GN ; le pronom reprend tout le groupe, et un groupe mixte donne _ils_.
- **Les trois temps** — **présent** (maintenant), **passé composé** (_a_ ou _est_ + un participe : _a aidé, a pris, est sorti_ ; l'action est faite), **futur** (_r_ + terminaison : l'action est à venir).
- **Verbe conjugué ou infinitif** — le conjugué change avec la personne et le temps ; l'**infinitif** garde sa forme de dictionnaire (_aller, finir, apprendre_). Dans _vous avez appris_, l'infinitif est _apprendre_.
- **L'infinitif après à, de, par, pour, sans** — le verbe s'écrit à l'infinitif : _par casser_, _pour mélanger_, jamais _par cassé_ ni _par casse_.
- **Éviter les répétitions** — on remplace un nom par un **pronom** ou par un autre GN qui désigne la même personne ou chose, sans créer de doute entre deux personnages.
- **Raconter** — un récit a un **début**, une **suite** et une **fin** ; on relit pour que le métier, le lieu, le moment et les personnes ne se contredisent pas.
- **Les mots du travail** — un métier se retient avec ce que fait la personne ; _brusquement, soudain, tout à coup_ annoncent un événement rapide ; _toujours, souvent, parfois, jamais_ disent combien de fois ; _peu_ est le contraire de _beaucoup_.
