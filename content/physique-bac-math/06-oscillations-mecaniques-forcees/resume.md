# 📜 Résumé : Les oscillations mécaniques forcées

- **Régime forcé** : le moteur à excentrique (excitateur) impose sa fréquence N au pendule élastique (résonateur) ; en régime permanent x = X_m sin(2πNt + φ), à la fréquence N et non à N₀ = (1/2π)√(k/m). X_m se lit de l'axe à la crête, T entre deux crêtes, et φ se tire de x(0) et du sens de variation.
- **Équation différentielle** : la relation fondamentale de la dynamique, avec T = −k(x − x_B) et f = −h·v, donne m·d²x/dt² + h·dx/dt + k·x = k·x_B = F_m sin ωt, avec F_m = k·(X_B)_m ; le second membre n'est pas nul (il l'est seulement si B est immobile : oscillations libres amorties).
- **Construction de Fresnel** : kX_m, hωX_m et mω²X_m se composent en vecteurs, d'où X_m = F_m / √(h²ω² + (k − mω²)²) avec ω = 2πN (et non N), cos φ = (k − mω²)X_m/F_m et sin φ = −hωX_m/F_m. Pour h > 0, x est en retard de phase sur F : −π/2 < φ < 0 si ω < ω₀, φ = −π/2 si ω = ω₀, −π < φ < −π/2 si ω > ω₀.
- **Résonance d'élongation** : X_m est maximale pour N_r = √(N₀² − h²/(8π²m²)), légèrement inférieure à N₀ ; elle n'existe que si h² < 2mk, soit h < h_l = √(2mk) ; l'écart N₀ − N_r croît avec h ; pour N tendant vers 0, X_m tend vers F_m/k ; pour h = 0, X_m deviendrait infinie (cas idéal).
- **Amortissement** : plus h est faible, plus la résonance est aiguë ; plus h est grand, plus elle est floue, plus le pic est bas et plus N_r s'éloigne de N₀ ; pour h ≥ √(2mk) il n'y a plus de résonance d'élongation ; avec un amortissement très important, le régime forcé est dit linéaire.
- **Impédance et résonance de vitesse** : par analogie avec le circuit RLC (R ↔ h, L ↔ m, 1/C ↔ k, U_m ↔ F_m, I_m ↔ V_m), V_m = F_m/Z avec Z = √(h² + (mω − k/ω)²) en kg/s ; V_m est maximale à N₀ pour toute valeur de h, avec Z = h et V_m = F_m/h ; v est alors en phase avec F et x en retard de π/2 ; tan(φ_v − φ_F) = (k/ω − mω)/h.
- **Puissance moyenne** : P = ½·F_m·V_m·cos φ = ½·h·V_m² en watt, avec cos φ = h/Z ; elle est maximale à N₀, où P₀ = F_m²/(2h) ; ne pas oublier le facteur ½ ni le facteur de puissance.
- **Vitesse critique** : un véhicule qui franchit des bosses espacées de d à la vitesse v subit l'excitation de période T = d/v ; la résonance a lieu pour T = T₀ = 2π√(m/k), soit v_c = d/T₀ (× 3,6 pour les km/h) ; les amortisseurs rendent la résonance floue ; on cherche la résonance (caisse d'un instrument, marées) ou on l'évite (pont, machine tournante).
