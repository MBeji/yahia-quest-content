# 📜 Résumé : Fonction exponentielle

- **Définition** : exp est la **réciproque de ln**, définie sur ℝ à valeurs dans ℝ*₊, notée e^x. Pour x réel et y > 0 : **y = e^x ⟺ x = ln y** ; ln(e^x) = x pour tout réel x ; e^(ln x) = x pour x > 0 seulement ; e^0 = 1, ln e = 1, e ≈ 2,71828. C_exp et C_ln sont **symétriques par rapport à y = x**, et une exponentielle est toujours strictement positive.
- **Règles de calcul** : e^(a+b) = e^a × e^b ; e^(a−b) = e^a/e^b ; e^(−a) = 1/e^a ; e^(na) = (e^a)^n ; e^(a/q) = q√(e^a) ; e^((p/q)a) = q√(e^(pa)). Réflexe : tout ramener à e^α et **additionner les exposants**. **Piège** : e^(a+b) n'est pas e^a + e^b, et 2e^(x+y) n'est pas e^(2x+2y).
- **Équations et inéquations** : e^A = e^B ⟺ A = B ; e^A ≤ e^B ⟺ A ≤ B ; e^A = k n'a de solution que si k > 0, alors A = ln k. Avec e^(2x) et e^x, on pose **X = e^x > 0** et l'on rejette toute racine X ≤ 0. On peut diviser une inéquation par une exponentielle (elle est > 0), jamais par une expression de signe inconnu.
- **Étude de exp** : **(e^x)′ = e^x**, exp est strictement croissante et bijective de ℝ sur ℝ*₊ ; lim_{−∞} e^x = 0 (asymptote y = 0), lim_{+∞} e^x = +∞ ; lim_{+∞} e^x/x = +∞ (branche parabolique de direction (Oy)) ; lim_{x→0} (e^x − 1)/x = 1. Tangente en 0 : **T : y = x + 1**, et **e^x ≥ x + 1** pour tout x : C est au-dessus de T.
- **Limites usuelles** : pour m et n entiers non nuls, lim_{x→+∞} e^(nx)/x^m = +∞ et lim_{x→−∞} x^m e^(nx) = 0. Méthode : **factoriser par l'exponentielle** (x² − e^(2x) = e^(2x)(x²/e^(2x) − 1) → −∞). **Piège** : x e^x tend vers 0 en −∞, pas vers −∞.
- **Fonction x ↦ e^(u(x))** : **(e^u)′ = u′e^u** ; les primitives de u′e^u sont **e^u + k**. Primitives types : e^(−3x) → −(1/3)e^(−3x) ; x e^(x²) → ½e^(x²) ; sin x · e^(cos x) → −e^(cos x). Reconnaître u′e^u **avant** de penser parties : ∫₀¹ x e^(x²)dx = (e − 1)/2 se fait par primitive, ∫₀¹ x e^x dx = 1 exige une intégration par parties.
- **Exponentielle de base a** (a > 0) : **a^b = e^(b ln a)** ; a^(c+d) = a^c a^d, (a^c)^d = a^(cd), a^(−d) = 1/a^d, a^c b^c = (ab)^c ; **(a^x)′ = (ln a)a^x** — jamais x a^(x−1). Toutes les courbes passent par (0 ; 1) ; a > 1 : croissante, lim_{+∞} = +∞ et lim_{−∞} = 0 ; 0 < a < 1 : décroissante, limites échangées. Pour résoudre, on ramène à la même base ou l'on prend ln.
- **Fonctions puissances** (r rationnel, x > 0) : **x^r = e^(r ln x)** ; **(x^r)′ = r x^(r−1)** ; primitive x^(r+1)/(r + 1) + k pour r ≠ −1 ; **ⁿ√x = x^(1/n)**. Limites : r > 0 ⟹ x^r → +∞ en +∞ et → 0 en 0⁺ ; r < 0 ⟹ l'inverse. **Croissances comparées** : ln x ≪ x^r ≪ e^x en +∞, et x^r ln x → 0 en 0⁺.
- **Étude type bac** : limites par croissances comparées, dérivée par u′e^u, **fonction auxiliaire** pour le signe de f′, asymptote et position par le signe de f − droite, aire par primitive. **Suite u_{n+1} = φ(u_n)** : intervalle I stable (φ(I) ⊂ I), solution α de φ(x) = x par le théorème des valeurs intermédiaires, puis |φ′| ≤ k < 1 sur I donne |u_n − α| ≤ kⁿ|u₀ − α| → 0 ; avoir un point fixe ne suffit pas à assurer la convergence.
