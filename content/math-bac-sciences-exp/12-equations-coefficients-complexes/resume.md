# 📜 Résumé : Équations à coefficients complexes

- **Racines nièmes de l'unité** : zⁿ = 1 a exactement n solutions e^(i2kπ/n), k = 0, …, n − 1, sommets d'un polygone régulier inscrit dans le cercle trigonométrique ; leur somme est nulle ; avec kπ/n au lieu de 2kπ/n, on sort des racines. Le nombre j = e^(i2π/3) = (−1 + i√3)/2 vérifie j³ = 1, j² = j̄ et 1 + j + j² = 0, donc j^(3n+k) = j^k.
- **Racines nièmes d'un complexe** : zⁿ = a, avec a non nul d'argument θ, a exactement n solutions r e^(i(θ/n + 2kπ/n)), où r > 0 vérifie rⁿ = |a| (jamais |a|/n) ; ce sont les sommets d'un polygone régulier inscrit dans le cercle de rayon r, et l'on se ramène à zⁿ = 1 en divisant par une solution.
- **Racines carrées** : z² = a + ib avec z = x + iy donne x² − y² = a, 2xy = b et x² + y² = |d| ; un complexe non nul a exactement deux racines carrées opposées, et le signe de 2xy dit si x et y sont de même signe ou de signes contraires ; on ne garde jamais les quatre couples de signes.
- **Second degré dans ℂ** : Δ = b² − 4ac est un complexe sans signe ; on en cherche une racine carrée δ et z = (−b ± δ)/(2a) ; si Δ = 0 les deux solutions sont confondues ; az² + bz + c = a(z − z₁)(z − z₂) ; dans Δ, (1 − i)² = −2i et non 2.
- **Somme et produit** : z₁ + z₂ = −b/a (avec le signe moins) et z₁z₂ = c/a (divisé par a) ; connaissant une solution, on trouve l'autre sans Δ ; deux complexes de somme S et de produit P sont les solutions de z² − Sz + P = 0.
- **Degré 3** : si z₀ est un zéro de P, alors P(z) = (z − z₀)g(z) ; on cherche z₀ entier simple ou imaginaire pur z = iy (la partie réelle ET la partie imaginaire doivent s'annuler pour la même valeur de y), puis on identifie les coefficients de g et l'on résout le second degré.
- **Changement d'inconnue** : pour z⁴ ou z⁶, on pose Z = z² ou Z = z³, on résout en Z puis on revient à z (quatre solutions pour un degré 4, pas deux) ; z⁶ = −1 donne x⁶ + 1 = (x² − √3x + 1)(x² + 1)(x² + √3x + 1) ; quand z et z̄ se mêlent, on compare les modules et l'on pense à z = 0.
- **Paramètre θ et lieux** : on résout en gardant θ constant, on écrit z = c + r e^(iθ) pour lire |z − c| = r (et non |z| = r), on borne θ pour savoir si l'on décrit un cercle entier ou un arc, et l'on calcule milieux et distances avec les affixes.
