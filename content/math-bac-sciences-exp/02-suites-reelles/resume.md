# 📜 Résumé : Suites réelles

- **Rangs pairs et impairs** : lim uₙ = a ⟺ lim u₂ₙ = a et lim u₂ₙ₊₁ = a ; une suite convergente est bornée, mais une suite bornée peut diverger.
- **Opérations** : somme, produit et quotient se combinent comme pour les fonctions ; pour ∞/∞ ou ∞ − ∞, on met le terme dominant en facteur ; ∞/∞ ne vaut pas 1 d'office.
- **Suites géométriques** : qⁿ → +∞ si q > 1, → 0 si |q| < 1, sans limite si q ≤ −1 ; pour uₙ₊₁ = a uₙ + b, la suite uₙ − α (avec α = aα + b) est géométrique de raison a.
- **Composition** : si f est définie sur un intervalle ouvert I contenant les uₙ, si uₙ → ℓ et si f a une limite L en ℓ, alors f(uₙ) → L ; on vérifie toujours que f a une limite en ℓ.
- **Comparaison** : uₙ ≤ vₙ donne a ≤ b (large) ; vₙ ≤ uₙ ≤ wₙ avec la même limite donne les gendarmes ; |uₙ| ≤ vₙ → 0 donne uₙ → 0 ; une minoration par une suite qui tend vers +∞ suffit.
- **Suites monotones** : croissante et majorée, ou décroissante et minorée, converge (limite ≠ majorant en général) ; croissante non majorée → +∞ ; décroissante non minorée → −∞ ; Σ k=1→n aₖ = a₁ + … + aₙ.
- **Suites récurrentes** : on prouve d'abord la convergence (encadrement et monotonie), puis la limite ℓ vérifie f(ℓ) = ℓ si f est continue en ℓ ; le point fixe seul ne prouve jamais la convergence.
- **Suites adjacentes** : uₙ ≤ vₙ, (uₙ) croissante, (vₙ) décroissante et vₙ − uₙ → 0 ⟹ même limite, comprise entre uₙ et vₙ.
