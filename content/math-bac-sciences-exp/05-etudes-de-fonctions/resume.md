# 📜 Résumé : Études de fonctions

- **Branche infinie et asymptotes** : une coordonnée de M(x ; f(x)) tend vers l'infini ; limite infinie en a ⟹ asymptote verticale x = a ; lim f(x) = L en ±∞ ⟹ asymptote horizontale y = L ; lim [f(x) − (ax + b)] = 0 ⟹ asymptote oblique y = ax + b ; lim = L en +∞ ne donne jamais x = L.
- **Étude par f(x)/x** (f(x) → ∞) : f(x)/x infinie ⟹ branche parabolique de direction (Oy) ; f(x)/x → 0 ⟹ direction (Ox) ; f(x)/x → a ≠ 0 puis f(x) − ax → b ⟹ asymptote y = ax + b ; f(x) − ax infinie ⟹ direction asymptotique y = ax, sans asymptote.
- **Fraction rationnelle** : on décompose f(x) = ax + b + c/(x − α) ; asymptotes x = α et y = ax + b ; la position vient du signe de c/(x − α) ; avec (x − α)², pas de changement de côté.
- **Nombre de solutions de f(x) = k** : points communs de la courbe et de la droite y = k ; une solution par intervalle de stricte monotonie dont l'image contient k ; à un extremum, une solution double comptée une fois.
- **Axe de symétrie** : x = a est axe de C ⟺ f(2a − x) = f(x) pour tout x de D, avec 2a − x ∈ D ; le symétrique de x est 2a − x, jamais a − x ; a = 0 redonne la parité.
- **Centre de symétrie** : W(a ; b) est centre de C ⟺ f(2a − x) = 2b − f(x), avec 2a − x ∈ D ; centre du polynôme de degré 3 : son point d'inflexion ; centre de ax + b + c/(x − α) : le point (α ; aα + b) ; un point d'inflexion n'est pas toujours un centre.
- **Fonctions irrationnelles** : f = √u est définie où u ≥ 0 ; (√u)′ = u′/(2√u) ; taux d'accroissement infini en un zéro de u ⟹ demi-tangente verticale ; en −∞, √(x²) = −x ; asymptote par f(x)/x puis f(x) − ax (quantité conjuguée).
- **Fonctions trigonométriques** : tester f(−x) = ±f(x) et f(x + 2π) = f(x) ; f impaire (centre O) ou paire (axe (Oy)) et 2π-périodique ⟹ [0 ; π] suffit, sinon une période entière ; dérivées (sin x)′ = cos x et (cos x)′ = −sin x.
