# 📜 Résumé : Équations différentielles

- **y′ = ay** : une solution est une fonction dérivable sur ℝ qui vérifie l'égalité **pour tout x** ; vérifier une candidate = la dériver et la réinjecter. Les solutions sur ℝ sont les fonctions x ↦ **ke^(ax)**, k ∈ ℝ (preuve : h = ge^(−ax) a une dérivée nulle, donc est constante). On isole y′ pour lire a, qui est le coefficient **dans l'exposant** : x ↦ −5e^(3x) est solution de y′ = 3y, et x ↦ 2^x de y′ = (ln 2)y.
- **Condition initiale** : pour a ≠ 0, l'unique solution de y′ = ay valant y₀ en x₀ est x ↦ **y₀e^(a(x−x₀))** ; la valeur imposée est f(x₀) = ke^(ax₀), pas k. L'équation relie f′(x₀) = af(x₀) : une donnée sur f′ devient une donnée sur f. Le signe de f′ est celui de ak : avec a < 0 et k < 0, f est croissante.
- **y′ = ay + b (a ≠ 0)** : la constante **−b/a** est solution (elle annule ay + b), et toutes les solutions sont x ↦ **ke^(ax) − b/a** ; celle qui vaut y₀ en x₀ est x ↦ (y₀ + b/a)e^(a(x−x₀)) − b/a. Piège : c'est −b/a, jamais +b/a. Si la condition initiale tombe sur −b/a, k = 0 et f est constante.
- **Modèle en trois temps** : traduire en y′ = ay + b, écrire ke^(ax) − b/a, fixer k à l'instant 0 ; si a < 0, la grandeur **tend** vers −b/a sans l'atteindre. Bobine : i(t) = 0,1(1 − e^(−500t)) → E/r. Condensateur : q → CU mais i = q′ → 0. Newton : f(t) = T_air + (f(0) − T_air)e^(at) ; une question « quand atteint-il T_air ? » est un piège, seul un seuil a une réponse.
- **Désintégration** : N′ = −λN et N(0) = N₀ donnent N(t) = **N₀e^(−λt)** ; la **demi-vie** T₀.₅ = **(ln 2)/λ** ne dépend pas de N₀, et il reste N₀/2ⁿ après n demi-vies (jamais zéro). Carbone 14 : T₀.₅ = 5730 ans ⟹ λ ≈ 1,21 × 10⁻⁴ ; 60 % restants ⟹ t ≈ 4223 ans.
- **y″ + ω²y = 0 (ω ≠ 0)** : les solutions sont x ↦ **A sin(ωx) + B cos(ωx)**, (A, B) ∈ ℝ² ; f(0) = x₀ et f′(0) = y₀ donnent l'unique f(x) = (y₀/ω)sin(ωx) + x₀cos(ωx), et la solution nulle est la seule avec f(0) = f′(0) = 0. **ω est la racine** du coefficient de y (y″ + 9y = 0 ⟹ ω = 3) ; les conditions peuvent être données en un point x₀ ≠ 0, on résout alors un système en A et B.
- **Forme amplitude-phase** : A sin(ωx) + B cos(ωx) = **r cos(ωx − φ)** avec r = √(A² + B²), cos φ = B/r, sin φ = A/r, φ ∈ ]−π, π] ; on vérifie toujours le couple (cos φ, sin φ). La **période 2π/ω** vient de l'équation, l'**amplitude r** des conditions initiales (mobile : x(t) = 2 sin(πt/2), période 4 s ; circuit L-C : ω = 1/√(LC)).
- **Se ramener à un cas connu** : pour un second membre non nul, trouver une **solution particulière** g de la forme imposée (trinôme, a cos x + b sin x), alors f est solution ⟺ f − g est solution de l'équation sans second membre, et la condition initiale porte sur f = ke^(ax) + g en entier ; pour y″ = ay′ + b, poser **z = y′**, résoudre en z, puis primitiver ; si l'énoncé impose un changement de fonction (g = 1/f, f = e^(ax)g), on résout en g puis on revient à f.
