# 📜 Résumé : Logarithme népérien

- **Définition** : ln x = ∫₁ˣ dt/t pour x > 0 — c'est **la primitive de x ↦ 1/x qui s'annule en 1**. Elle est continue, dérivable et strictement croissante sur ]0, +∞[, avec ln′(x) = 1/x et ln 1 = 0. Pour x > 1, ln x est l'aire sous l'hyperbole y = 1/t entre 1 et x ; pour 0 < x < 1, ln x est négatif. L'unique réel e de ]2, 3[ vérifie ln e = 1 (e ≈ 2,71828).
- **Comparaison et résolution** : pour a > 0 et b > 0, ln a > ln b ⟺ a > b ; ln a = ln b ⟺ a = b ; ln a = 0 ⟺ a = 1 ; ln a > 0 ⟺ a > 1 ; ln a < 0 ⟺ 0 < a < 1. Méthode : conditions d'existence, puis ln A et ln B, puis équivalence ou croissance. Une valeur hors du domaine est une fausse solution.
- **Propriétés algébriques** (a > 0, b > 0) : ln(ab) = ln a + ln b ; ln(a/b) = ln a − ln b ; ln(1/b) = −ln b ; ln(aᵖ) = p ln a pour p entier ; ln(ᵖ√a) = (1/p) ln a pour p ≥ 2. Usage type : le plus petit n avec (1/2)ⁿ ≤ 10⁻⁴ est n = 14. **Piège** : ln(a + b) ≠ ln a + ln b, et ln(x²) = 2 ln|x|.
- **Limites de référence** : lim_{x→+∞} ln x = +∞ ; lim_{x→0⁺} ln x = −∞ (asymptote verticale x = 0) ; lim_{x→+∞} (ln x)/x = 0 ; lim_{x→1} (ln x)/(x − 1) = 1 (c'est ln′(1)). **Piège** : « ln monte lentement » ne veut pas dire « ln est bornée ».
- **Variation et bijection** : ln croît strictement de −∞ à +∞ en s'annulant en 1 ; c'est une bijection de ]0, +∞[ sur ℝ, donc ln x = k a une unique solution pour tout réel k. Un nombre dérivé donne souvent la limite : lim_{x→0} ln(1 + ax)/x = a.
- **Croissances comparées** : pour n et m entiers non nuls, lim_{x→+∞} (ln x)ⁿ/xᵐ = 0 et lim_{x→0⁺} xᵐ(ln x)ⁿ = 0 — ln perd contre toute puissance de x. **Piège** : lim_{x→0⁺} (ln x)/x = −∞ (ce n'est pas un produit xᵐ lnⁿx), et lim_{x→0⁺} (ln x + 1/x) = +∞.
- **ln(u) et ln|u|** : ln(u) est définie là où u > 0, ln|u| là où u ≠ 0 ; dans les deux cas la dérivée est la même, **f′(x) = u′(x)/u(x)**. Toujours résoudre le signe de u avant de dériver. Exemple : (ln(−x))′ = 1/x sur ]−∞, 0[.
- **Primitives et intégrales** : toute fonction u′/u a pour primitives **ln|u| + k** sur un intervalle où u ne s'annule pas ; **x ln x − x est une primitive de ln** sur ]0, +∞[. Pour une intégrale, on décompose (1/(t(t + 1)) = 1/t − 1/(t + 1)) ou l'on intègre par parties avec f = ln ; pour une aire sous l'axe, on change le signe. On a ln x ≤ x − 1 pour tout x > 0.
- **Étude d'une fonction à logarithme** : limites par croissances comparées, dérivée par u′/u, **fonction auxiliaire g** dont le signe commande celui de f′ (g(1) = 0 par exemple), tableau, asymptote et position par le signe de f − droite, branche parabolique si f(x)/x → ±∞. La dérivabilité en 0 d'une fonction prolongée se juge par le taux d'accroissement : x² ln²x est dérivable en 0, x ln x ne l'est pas.
