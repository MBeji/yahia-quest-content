# 📜 Résumé : Équations de droites, de plans et de sphères

- **Droite** : passant par A(x₀, y₀, z₀) de vecteur directeur u⃗(a, b, c), x = x₀ + αa ; y = y₀ + αb ; z = z₀ + αc ; un point en fait partie si un même α convient aux trois équations ; pour deux droites on prend deux paramètres α et β.
- **Plan et équation cartésienne** : le plan passant par A et dirigé par u⃗ et v⃗ non colinéaires est {M ; det(AM⃗, u⃗, v⃗) = 0}, qui se développe en ax + by + cz + d = 0 ; deux plans de mêmes vecteurs directeurs sont parallèles.
- **Vecteur normal** : dans un repère orthonormé, n⃗(a, b, c) est normal au plan ax + by + cz + d = 0 ; n⃗ = AB⃗ ∧ AC⃗ est normal à (ABC), AM⃗.n⃗ = 0 décrit le plan passant par A, et une droite dirigée par n⃗ lui est perpendiculaire.
- **Distance point-plan** : d(M, P) = |ax₀ + by₀ + cz₀ + d| / √(a² + b² + c²) ; le projeté orthogonal est H = M + kn⃗ avec H dans P.
- **Plans et droites** : plans parallèles si les normaux sont colinéaires, perpendiculaires si les normaux sont orthogonaux, sinon sécants suivant une droite ; pour une droite et un plan, kα + h = 0 donne un point, aucun point ou tous les points.
- **Sphère** : (x − x₀)² + (y − y₀)² + (z − z₀)² = R² est la sphère de centre I et de rayon R ; x² + y² + z² + ax + by + cz + d = 0 est une sphère, un point ou le vide, selon le signe de a²/4 + b²/4 + c²/4 − d.
- **Diamètre et plan médiateur** : la sphère de diamètre [AB] est l'ensemble des M tels que MA⃗.MB⃗ = 0 ; le plan médiateur de [AB] est l'ensemble des M tels que MA = MB.
- **Sphère et plan** : h étant la distance du centre au plan, l'intersection est vide (h > R), le point H (h = R, plan tangent) ou le cercle de centre H et de rayon √(R² − h²) (h < R) ; le plan tangent en A a pour vecteur normal IA⃗.
