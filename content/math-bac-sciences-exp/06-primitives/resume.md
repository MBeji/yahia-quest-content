# 📜 Résumé : Primitives

- **Définition et existence** : F est une primitive de f sur l'intervalle I si F est dérivable sur I et F′(x) = f(x) pour tout x de I ; toute fonction **continue** sur un intervalle y admet au moins une primitive (théorème admis) ; on valide toujours une primitive en la **dérivant**. Le signe de f donne les variations de F : f > 0 ⟹ F croissante, f < 0 ⟹ F décroissante, changement de signe de f ⟹ extremum de F.
- **Famille et condition initiale** : deux primitives de f sur un **intervalle** diffèrent d'une constante (courbes translatées verticalement) ; pour x₀ ∈ I et y₀ réel, il existe une **unique** primitive F telle que F(x₀) = y₀ — on écrit F + c, puis on calcule c. Sur une réunion d'intervalles, rien de tel.
- **Primitives usuelles** : xⁿ → x^(n+1)/(n+1) ; 1/xⁿ (n ≥ 2) → x^(−n+1)/(−n+1) ; √x → (2/3)x√x ; 1/√x → 2√x ; cos x → sin x ; sin x → −cos x ; cos(ωx + φ) → (1/ω) sin(ωx + φ) ; sin(ωx + φ) → −(1/ω) cos(ωx + φ) ; 1 + tan²x → tan x. Attention au signe de 1/x² (primitive −1/x) et au facteur 1/ω.
- **Linéarité** : F + G primitive de f + g, λF primitive de λf — on primitive terme à terme. Aucune formule pour un produit ou un quotient : F × G n'est pas une primitive de f × g.
- **Formes composées (1)** : u′uⁿ → u^(n+1)/(n+1) ; u′/uⁿ (u ≠ 0) → u^(−n+1)/(−n+1) ; u′/√u (u > 0) → 2√u ; u′√u (u ≥ 0) → (2/3)u√u. Méthode : poser u, calculer u′, ajuster par une **constante** multiplicative, dériver pour contrôler. Un facteur manquant qui dépend de x signale l'absence du motif.
- **Formes composées (2)** : u′v + v′u → u·v ; (u′v − v′u)/v² (v ≠ 0) → u/v ; u′(w′∘u) → w∘u. Piège : x ↦ F(2x) n'est **pas** une primitive de x ↦ f(2x) (sa dérivée vaut 2f(2x)) ; la bonne primitive est x ↦ F(2x)/2.
- **Réécrire avant de primitiver** : décomposition d'une fraction rationnelle (f(x) = ax + b + c/(x − 2)²), linéarisation (sin²x = (1 − cos 2x)/2), découpage de sin³x = sin x(1 − cos²x) et de cos³x = cos x(1 − sin²x), passage par tan (tan²x = (1 + tan²x) − 1).
- **Applications** : un taux instantané est une dérivée, donc la grandeur est une primitive — débit ou taux de production → quantité, accélération → vitesse → position ; chaque primitivation consomme une condition initiale (deux remontées = deux données).
- **Étudier une primitive sans l'écrire** : si m ≤ f ≤ M sur [0, x] et F(0) = 0, alors mx ≤ F(x) ≤ Mx (accroissements finis) ; f > 0 donne F strictement croissante, donc bijective sur l'image ; la réciproque définit des suites x_m = F⁻¹(m). Une limite de f ne donne pas la limite de F : lim f = 1 n'entraîne pas lim F = 1.
