أنواع التّشبيه، الكناية، المجاز المرسل، الجناس…

## معنى «النخبة» في عربية التاسعة

- **التّحليل الوظيفيّ**: الحكم على عنصر أو جملة بمعيار الكتاب (جملة اعتراضيّة مقابل حال جملة؛ استئناف
  مقابل عطف؛ مفعول فيه مقابل خبر)، لا بالإعراب وحده.
- **الدّلالة على الزّمان**: قراءة زمان الحدث من تآلف الصّيغة والحرف المقترن بها والنّاسخ والمفعول فيه
  والحال (حدث منقضٍ / غير منقضٍ؛ تزامن / أسبقيّة / لاحقيّة).
- **الأعمال اللّغويّة**: المعنى السّياقيّ للأمر والنّهي والاستفهام والنّداء والدّعاء، والشّرط بين
  الإمكان والافتراض والاستنتاج.
- **الصّرف**: معنى صيغة المزيد في سياقها؛ تثنية المقصور والممدود وجمعهما؛ التّصغير والنّسبة في حالاتهما
  الحدّيّة.
- **الحجاج**: صياغة الأطروحة المثبتة والمدحوضة، تمييز الحجّة من المثال، نوع الحجّة ووظيفة المؤشّر
  اللّغويّ — على نصّ قصير أصيل يحمله السّؤال.
- **صيد الخطأ**: تحليلٌ «تلميذيّ» فيه خطأ واحد يُطلب تحديده.

## معجم الأخطاء — كلّ مُشتِّت ينفّذ خطأً واحدًا حتى نهايته

| الباب              | الأخطاء التي تُنفَّذ (الناتج الخاطئ = المُشتِّت)                                                                                |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| العلاقات بين الجمل | الحكم على الجملة المنسوخة بأنّها فعليّة؛ الاستئناف مقابل العطف؛ الواو «بلا معنى»؛ «إذ» سببيّة (والكتاب لا يعلّمها إلّا فجائيّة) |
| النّداء والطّلب    | تخطئة «حكم المنادى الرّفع»؛ نسيان الهمزة أداةً لنداء القريب؛ قراءة الأمر بصيغته دون معناه السّياقيّ                             |
| الاستفهام والشّرط  | الاستفهام عن المضمون مقابل الاستفهام عن عنصر؛ الإمكان مقابل الافتراض؛ الجواب المقترن بالفاء                                     |
| دلالة الزّمان      | قراءة الزّمان من الصّيغة وحدها دون الحرف المقترن بها؛ الحال المنقضية مقابل المزامنة؛ الحدث الرّئيسيّ مقابل الحدث الثّاني        |
| العدد والمعدود     | مطابقة العدد (3–10) للمعدود بدل مخالفته؛ تمييز 11–99 مجموعًا؛ العدد التّرتيبيّ                                                  |
| الصّرف             | تثنية المقصور دون ردّ ألفه إلى أصلها؛ همزة الممدود (أصليّة / منقلبة / للتّأنيث)؛ معنى المزيد من الوزن وحده                      |
| الحجاج             | الأطروحة المدحوضة مقابل المثبتة؛ المثال مقابل الحجّة؛ نوع الحجّة؛ الإقناع مقابل التّأثير                                        |
| الصّورة            | التّشبيه بأركانه مقابل الاستعارة؛ الحقيقة مقابل المجاز؛ الطّباق مقابل السّجع                                                    |

## دقّة اللغة

جُمل الأسئلة فصيحة لا لحن فيها؛ المُشتِّتات جُملٌ سليمة التركيب لكنّها خاطئة في النقطة المدروسة —
لا كلام مُبهم. اشكل أواخر الكلمات المُعرَبة عند الحاجة لرفع اللبس. تحقّق من الشواهد (الآيات ⟵ رواية
قالون حصريًّا، cf. content-ecole-tn) واذكر المصادر في `chapter.json` `sources[]`.

## سير العمل

1. الفصل/الفصول → **تدقيق السلّم الموجود** (`content/arabic/<NN>/exercices/*.json`) — لا تكرار،
   وفوق السقف الحالي دائمًا.
2. ‏6 أسئلة فأكثر، ‏≥ 3 نماذج (`expert-exercises.md`)، تدرّج داخليّ 2→3.
3. المُشتِّتات = أخطاء الجدول مُنفَّذة؛ الشرح = القاعدة + تطبيقها + «الخطأ الشائع…» (إلزاميّ في d4).
4. الملفّات: إكمال `02-boss`/`04-defi`، أو `06-defi-concours.json` فوق الموجود؛ نماذج المناظرة في
   `11-annales-subur` (بالتّنسيق مع الدّراسة 36).
5. حلّ مزدوج + تمريرة تفنيديّة → `npm run content:check` → `npm run content:qa:strict` → تقرير —
   **ملفّات فقط، دون build/apply/push إلّا بطلب**.
