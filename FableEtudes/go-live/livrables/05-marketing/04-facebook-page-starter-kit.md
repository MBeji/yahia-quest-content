## 5. Règles d'or (pour ne pas griller la page)

- **Valeur d'abord, pas de spam.** Dans les groupes de parents : apporte une astuce / une question
  type concours / un mini-quiz, et signe discrètement → le pull convertit mieux que la pub.
- **Double message** : chaque post doit rassurer le parent ET donner envie à l'enfant.
- **FR + derja** : le derja (comme dans les posts ci-dessus) crée la proximité ; l'arabe standard
  pour le sérieux. L'anglais reste un argument produit, pas un canal de comm.
- **Répondre vite** aux messages (WhatsApp/Messenger) — c'est le canal de conversion.
- **Micro-boosts** (5-30 TND) seulement sur les posts qui marchent déjà en organique, ciblés
  parents Tunis/Sfax/Sousse.
