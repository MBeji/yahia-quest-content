## Règles

- **ID** : `GAP-NNN`, séquentiel, jamais réutilisé.
- **Sévérité** : `P0` bloquant go-live · `P1` requis rapidement après lancement · `P2` important · `P3` confort.
- **Statut** : 🔴 à faire · 🟡 en cours · 🟢 fait · ⚪ abandonné (motif en note).
- Les remédiations **techniques** se font dans le repo `yahia-quest-arena/` (branche + PR conventionnelles, DoD du repo applicable) ; reporter ici la référence (branche/PR/commit).
- Une session d'implémentation = un ou plusieurs GAP cohérents ; mettre à jour statut + note en fin de session.
